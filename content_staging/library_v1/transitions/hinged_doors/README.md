# X10 hinged_doors —— 合页双门 2D 投影（L14）

> 状态：**component_ready**（暂存 CPU 核；未接宿主）。
> 台账：L00 §2 X10 行——2D 投影双门 + 遮挡/背面/阴影模型，无等价实现；
> 先单帧 2D 投影实现（不做真 3D 引擎）。

## 算法（简化确定性模型，2D 投影）

```
门剩余宽度 W(p) = 1 - 0.999·p   （0.999：门宽不精确归零，防除零；p=1 端点
                                  走 early return，不受影响）
hinge=Left（单门，铰链 x=0 固定）：
  x ≤ W   → 门区：门内归一坐标 m = x/W
            源采样 s = m·(1+persp·m)/(1+persp)   （persp=0 → s=m，精确退化为
              任务钉住的线性模型 A(x/(1-p·0.999))）
            out = A(s)·(1 - shadow·p)
  x > W   → 露 B（B 在 A 后方整幅**原位**采样）
hinge=Both（双门，铰链在外侧边）：
  x ≤ W/2         → 左门：m = x/(W/2)，源 s·0.5（A 左半幅）
  x ≥ 1 - W/2     → 右门：m = (1-x)/(W/2)，源 1-s·0.5（A 右半幅镜像）
  W/2 < x < 1-W/2 → 中缝露 B 原位
```

- **透视重参数化推导（冲突记录）**：任务原文透视式 `x' = 1-(1-x)/(1-p·f(x))`
  （f 线性）不能同时满足"铰链点不动"与"门边=1-0.999p"（f(铰链)≠0 时铰链
  移动；f(1)=0 时门边解出 pk/(1+pk)）。本核用门内二次重参数化
  `s = m(1+persp·m)/(1+persp)`：s(0)=0 铰链精确、s(1)=1 门边精确、
  persp=0 精确线性；ds/dm = (1+2·persp·m)/(1+persp) 随 m 增 → **越远（自由
  边侧）压得越快**，persp=1 时自由边压缩率是铰链侧 3×。这是 2D 投影近似，
  非物理相机模型（README 钉住声明）。
- **shadow**：整门**均匀**乘暗 (1-shadow·p)（任务钉住公式；非逐点光照——
  透视暗角不在此模型内，声明）。
- **界内**：门内采样 s∈[0,1]（Left 门 [0,1] 源全域；Both 门 [0,0.5]/
  [0.5,1] 半幅）恒在源界内；B 原位恒界内 → in-bounds-by-construction。
- **端点**：p=0 → W=1、m=x、s=x → A 全幅恒等（early return 比特级）；
  p=1 → W=0.001，中心像素 u≥0.1 > W 全露 B（early return B 比特级）。
- **单调**：门边 W(p) 随 p 单调左移 → B 露出面积单调不减。

## 参数

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| hinge | Both | Left/Both | 单门 / 双门（铰链在外侧） |
| perspective | 0.5 | 0..1 | 门内透视压缩（0=线性均匀压缩） |
| shadow | 0.5 | 0..1 | 门体随开度均匀乘暗 |
