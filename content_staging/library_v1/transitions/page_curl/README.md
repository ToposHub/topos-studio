# X12 page_curl —— 非线性卷页（L15 批次协同项，本批交付）

> 状态：**component_ready**（暂存 CPU 核；未接宿主）。
> 台账：L00 §2 X12 行——非线性曲面 UV/卷边，无 UV 弯曲类等价（grep 0 命中）；
  不以线性翻转替代。

## 算法（简化圆弧模型推导）

```
direction=Left 为规范向（卷起线自右缘 x=1 扫向左，出画于 x=-r）；Right 为
t = 1-x 镜像（t 为规范坐标）。

卷起线：x_c(p) = 1 - p·(1+r)
区域：
  t < x_c - r   平铺区：A 原位采样
  t ∈ [x_c-r, x_c] 卷曲区（圆弧投影覆盖在平铺页上方）：
      弧参数 φ = ((x_c - t)/r)·(π/2) ∈ [0, π/2]
      弧长 s = r·(2/π)·φ            （四分之一圆弧，半径 R = 2r/π，
                                       总弧长恰为 r → 卷区宽度=剥离材质长度）
      源材质 x_src = x_c + s         （已剥离侧；采样坐标随 t 减小而增大
                                       → 屏上纹理**镜像**，即"A 翻转"）
      背面值 = mix(A(x_src), back_color, sin φ)   （卷得越多越显纸背）
      卷边 shadow：乘 (1 - shadow·sin φ)          （卷边最暗）
  t > x_c       已剥离区：B 原位采样（"back 区显示 B"）
```

- **冲突记录 1（卷起线公式）**：任务原文 `x_c = 1-(1-p)·(1+r)` 在 p=0 得
  x_c=-r（无平铺区、全图非 A）违反自身端点要求；按区域指派反推应为
  `x_c = 1-p·(1+r)`（p=0→1 右缘、p=1→-r 出画），采纳后者。
- **冲突记录 2（卷区位置）**：任务原文卷区 [x_c, x_c+r] 在 B 侧且源映射
  x_src=x_c-r+sin(…) 与平铺区在 x_c 处不连续（A(x_c-r) vs A(x_c) 跳变）。
  本核把可见弧影覆盖在**平铺侧** [x_c-r, x_c]：φ=0（卷起线处）显 A(x_c)
  与平铺页物理连续；x>x_c 即显 B。镜像采样语义保留。
- **连续性**：卷区两端各有一条参数语义的硬边（x_c-r 处卷页外缘离地、
  x_c 处页表面/B 交界）——物理页边，不羽化（声明）。
- **采样域**：平铺/B 原位恒界内；卷区 x_src ≤ x_c+r 在小 p 大 r 时可越界
  → 双线性 clamp（clamp-half-texel 声明；端点帧走 early return 不受影响）。
- **端点**：p=0 → x_c=1：卷区 [1-r,1] 大部越界、可见区几乎全平铺（early
  return A 比特级）；p=1 → x_c=-r：卷区/平铺区全出画（early return B 比特级）。
- **back_color**：scene-linear 3 元组，逐通道防御钳 [0,1]（NaN/非 3 元回退
  默认）；单通道输入时取 Rec.709 luma 折算。

## 参数

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| direction | Left | Left/Right | 卷起线扫动方向 |
| radius | 0.25 | 0.05..0.5 | 卷曲区宽=剥离材质长（归一） |
| back_color | (0.85,0.82,0.78) | scene-linear | 纸背颜色 |
| shadow | 0.5 | 0..1 | 卷边随 sinφ 压暗 |
