# AI Gen Expand 生成式扩展/填充

云端生成式扩图与局部填充（火山引擎 Ark 适配，走 shared provider 契约）。

## 适用场景（重要）

**静帧/逐帧独立生成**——延展画幅、生成空镜、静帧修复。视频逐帧独立生成会闪烁（i2v 视频生成列后续版本）。

## 输入与参数

- `image`：底图；`mask`（可选）：填充区域
- **向左/上/右/下扩展**：各边扩展比例（0-1），自动生成外扩 mask
- **提示词 / 反向提示词 / 模型 / 种子 / 强度**
- 结果内容寻址缓存（prompt+seed+模型+输入 revision）：重复求值/导出不重复计费

## 密钥与成本（约束 12）

- 密钥只从偏好设置/环境变量读取，不入图、不入缓存
- 无密钥或未配置 provider 时节点处于可见的 NEEDS_CONFIG 状态并直通输入——不崩溃、不静默
- 每批调用前弹一次成本确认（不是每张一次）

## 已知边界

- 求值为同步 MVP（ai_compute_manager 后台队列接线为后续项）；无 GL 上传通道时结果只入缓存、画面保持直通
