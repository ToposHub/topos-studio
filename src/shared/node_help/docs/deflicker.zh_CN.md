# Deflicker 去闪烁

时域亮度稳定：以滑动窗口内各帧亮度平面的分位数（默认中值）为参考，对当前帧做逐像素增益校正（仅亮度模式保留色度）。延时摄影、老素材、屏幕录制的亮度闪烁修复。

## 行为（重要）

- **因果（trailing）窗口**：以当前帧结尾的 N 帧窗口。顺序播放/顺序导出时窗口自然填满。
- **跳帧/冷启动降级**：窗口不完整时节点**直通输出**并在节点上显示 warming 提示——绝不拿不完整窗口假装成功。保存重开后首帧也是 warming 直通。
- 缓冲是运行态：不入图 schema、不序列化、不参与 undo。

## 参数

- **窗口**：3/5/7/9 帧。
- **分位数**：0.5=中值（默认），越接近 1 越保守。
- **仅亮度**：默认开——只校正亮度比例，保留色度（抗闪烁更稳）。
- **模式**：逐像素 / 全局增益（整帧单一增益，备选）。
