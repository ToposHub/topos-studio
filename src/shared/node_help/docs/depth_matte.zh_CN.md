# Depth Matte 深度遮罩

按 Z 区间 `[区间起点, 区间终点]` 输出白色 matte，边界按 `羽化` 做 smooth 过渡，可接任意下游 mask 输入（Keyer、Merge mask、调色遮罩等）。

## 输入

- `image`：参考图（决定输出画幅/元数据）
- `depth`：深度图（R 通道）

## 参数

- **区间起点 / 区间终点**：归一化深度窗口。
- **羽化**：边界过渡带宽。
- **深度单位**：`归一化` / `世界距离`（配合 `近/远平面` 线性化）。

纯逐像素，padding 0；输出为预乘白色 matte（RGB=A=覆盖度）。深度缺失时无输出。
