# God Rays 体积光（丁达尔光束）

屏幕空间径向采样：每个像素向光源位置步进，累加穿过的遮挡（α），按 `decay^i` 衰减；输出 `image + rays × 权重 × 密度 × 光色`（linear 域叠加）。

## 输入

- `image`：底图（遮挡源 = 输入 alpha）
- `mask`（可选）：显式遮挡遮罩——连接后用遮罩的 alpha 代替输入 alpha

## 参数

- **光源 X / Y**：屏幕空间 UV（0-1，可超出画幅），可动画/表达式。
- **光色 / 密度 / 权重 / 衰减**：能量控制；衰减 1.0 时无距离衰减。
- **采样数**：16-64；预览模式自动减半（draft 档降级路径）。

## 特性

- 全帧后处理节点：径向采样是全局的，本节点豁免 ROI 裁剪（始终全帧求值），tile padding 为 0。
- 与 Blur/Grade 等组合时注意：体积光在 ROI 裁剪下不会丢光束。
