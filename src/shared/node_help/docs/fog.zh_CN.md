# Fog 深度雾

按深度做指数大气雾（Beer–Lambert）：`out = mix(image, 雾色, 1 - exp(-浓度 × t))`，`t = clamp((Z-start)/(end-start), 0, 1)`。start 之前无雾，end 处雾量趋于饱和。

## 输入

- `image`：原图
- `depth`：深度图（R 通道）

## 参数

- **雾颜色 / 浓度**：linear 域混合；浓度 0 为无雾。
- **起始深度 / 结束深度**：归一化深度区间。
- **深度单位**：`归一化` / `世界距离`（配合 `近/远平面` 线性化）。

纯逐像素运算，无空间采样，padding 为 0。深度缺失时无输出（不断链直通）。
