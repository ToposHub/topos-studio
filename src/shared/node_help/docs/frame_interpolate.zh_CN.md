# 帧插值 (Frame Interpolate)

基于 RIFE（ONNX）的真实运动补帧：给定 `frame_a`、`frame_b` 与可动画的位置参数
`t`（0 = A，1 = B），输出合成出的中间帧——物体真正移动到半程位置，而不是
交叉淡化。配合时间重映射可做变速：把 `t` 动画到 retime 比例，并接上相邻的
两帧源画面。

## 行为说明

- **端点精确**：`t = 0` / `t = 1` 原样返回输入帧（不重采样、不推理）。
- **模型管理**：RIFE 模型经共享 model_manager 解析，绝不静默下载——请先本地
  转换（见 `tools/convert_rife_to_onnx.py`）并注册。
- **优雅降级**：无可用模型时回退为线性混合，并通过 `used_fallback` 上报
  质量档位，图始终可渲染；降级可见、不隐藏。
- **hd_mode** 对大于 1280px 的帧做分块推理以控制内存（分块无重叠，超大
  画面可能出现细微接缝）。
- 确定性：相同输入与 `t` 永远产出相同帧。

## 参数

- **t**：插值位置 0..1，可动画。
- **hd_mode**：大帧分块推理。
