# 场景剪切探测

场景剪切探测用于分析视频中的镜头切换点，并在加入媒体池前进行人工确认。

## 基本流程

1. 点击 **自动场景检测**，等待分析完成。
2. 在图表或场景列表中选择一个候选切点。
3. 通过上方三联预览检查切点前、当前和切点后的画面。
4. 确认无误后接受候选点；误检可以拒绝。
5. 点击 **添加剪辑到媒体池**，将有效切点生成虚拟子剪辑。

## 播放与定位

- **左键 / 右键**：向前或向后移动一帧，适合精确定位。
- **空格键**：播放或暂停预览。
- **上键 / 下键**：跳转到上一个或下一个检测候选点。
- **上一帧 / 下一帧按钮**：与左右键相同。
- 播放到素材末尾会自动停止。

## 场景列表

- **Decision**：接受、待定或拒绝当前候选点。
- **Score**：候选切点的检测置信度。
- **Type**：候选点的类型，例如硬切、转场或闪光。
- 点击候选行可同步更新图表、预览和当前帧位置。

## 图表与批量操作

- 拖动图表中的阈值线可以调整当前审核边界。
- 通过底部的批量操作菜单，可以接受高置信度候选点、拒绝警告候选点或重置全部决策。
- 场景检测只提供候选结果，最终是否加入媒体池由你确认。
