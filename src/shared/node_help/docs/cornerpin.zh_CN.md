# CornerPin 四角透视变形

CornerPin 通过 4 组角点控制对图像做透视变换（单应变换），常用于屏幕替换、匹配移动（match-move）和透视矫正。

## 核心概念

节点有两组角点，均为 0-1 归一化坐标（原点在左上、Y 向下）：

- **源角 from1-4（灰色手柄）**：定义"取图像的哪块区域"。
- **目标角 to1-4（金色手柄）**：定义"这块区域映射到哪里"。

角序固定：**1=左上、2=右上、3=右下、4=左下**，两组角都必须按此顺序围成凸四边形，交叉连线会导致画面镜像或错乱。

## 视图窗口操作

选中节点后，视图窗口显示 8 个角点手柄：

| 操作 | 效果 |
|---|---|
| 拖金色角 | 移动目标角，画面实时变形 |
| **Alt + 拖灰色角** | **对齐模式：源角和对应目标角一起移动，画面保持不变形**（把角点钉到画面中某个物体的四角上） |
| Alt + Shift + 拖灰色角 | 只移动源角（重新定义取样区域） |
| Shift + 拖金色角 | 冻结模式：画面停住、只有角点框跟手，松手后一次性生效 |

## 常用工作流

### 1. 把控制点钉到画面中物体的四角（如电视屏幕）

1. 选中 CornerPin 节点（初始状态画面无变形）；
2. **Alt + 拖**灰色角，逐个放到电视屏幕的 4 个角上——对齐过程中画面完全不变形；
3. 对齐完成后，拖金色角即可对该区域做位置/透视调整。

### 2. 只取画面中间的一块区域

把源角收缩到目标区域。例如取正中央 50% 的区域：

- from1 (0.25, 0.25)、from2 (0.75, 0.25)、from3 (0.75, 0.75)、from4 (0.25, 0.75)
- to 角保持默认满幅 → 中央区域被放大填满整个画幅。

也可以在属性面板直接输入 `from1_x` ~ `from4_y` 数值（归一化值 = 像素位置 ÷ 图片宽高）。

### 3. 透视矫正

把源角贴合倾斜平面（如画面里的一块屏幕）的四角，目标角设为规整矩形，即可把该平面"摆正"。

## 注意事项

- CornerPin 在固定画布内变形（画布尺寸不变），变形后超出画布的部分被裁为透明。
- 源四边形之外的画面内容不会被硬切除，而是沿投影几何延伸到目标四边形之外。若只想显示取样区域，请在后面接 Mask 或 Crop 节点。
- `interpolation` 参数控制采样质量：bilinear（快）/ bicubic（更细腻）。
- 所有角点参数支持关键帧动画。
