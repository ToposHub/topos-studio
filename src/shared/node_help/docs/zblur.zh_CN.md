# ZBlur 深度模糊（景深）

按深度图做景深：焦点平面保持清晰，偏离焦点的像素按圆圈半径（CoC）逐渐虚化。半径公式 `r = max_radius × smoothstep(0, 1, |Z-焦点|/景深范围)`。

## 输入

- `image`：要虚化的图像
- `depth`：深度图（Scene3D `depth` 输出直连，或 Shuffle 出的 Z 通道；取 R 通道）

## 参数

- **焦点距离 / 景深范围**：归一化深度（0=最近，1=最远）。
- **最大模糊半径**：完全失焦处的采样盘半径（像素），也是 tile padding 依据。
- **光圈盘采样**：关闭时用高斯型软采样，打开时用光圈盘形采样（散景边更硬）。
- **深度单位**：`归一化` / `世界距离`（世界距离需配合 `近/远平面` 线性化）。
- **质量**：采样数（快速 8 / 正常 16 / 高 32）；预览模式自动减半。

## 注意

- 深度输入缺失时节点无输出（可见的断链），不会静默直通。
- 变半径模糊 MVP 为单趟螺旋盘采样，先保证正确性；极端大半径（>40px）预览模式会自动降半径。
