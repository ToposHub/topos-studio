## 1. 窗口置前与应用切换（R-13 核心，仅手工可证）

- [ ] 打开含视频 + MG layer 的工程，双击 MG layer：编辑器出现在项目窗口**前方**，标题与 Preview 正常。
- [ ] 切到 Safari/VS Code，再切回项目窗口，最后点按 MG 编辑器：编辑器按产品规则回到前台（不永久霸占置顶）。
- [ ] 重复上一条 10 次，记录任何一次“编辑器跑到项目后面”的情况。
- [ ] 编辑器最小化 → 恢复；进入 Mission Control → 返回；外接屏拖动 → 布局正常。
- [ ] 全屏项目窗口下打开编辑器：层级与可聚焦性正常。

## 2. 面板与布局

- [ ] Parameters / Layers / Scenes / Source / DevTools / Library 标签切换，无标签被压缩成不可读省略号。
- [ ] 隐藏右侧面板 → 菜单栏下方“参数面板/显示面板”恢复；重复 5 次，状态不丢。
- [ ] 窄窗口（拖到 ~1000px 宽）与宽窗口（>1800px）各截图一张；关键按钮（DevTools、播放控制、时间码）均可见可点。
- [ ] 中文 / 英文各跑一遍第 1–2 节，无关键文案变成 key 原文或空白按钮。

## 3. 编辑与素材库（自动化已证，抽查）

- [ ] 素材库选 "Particle Flow Background" 模板卡：名称、描述、GIF 预览、Insert 全部可用；tooltip 无绝对路径。
- [ ] 单击 Insert、双击卡片、拖放到画布三种路径都创建 HTML layer。
- [ ] 拖入模板后在画布绘制矩形 / 文字 / SVG：背景粒子仍在运动（画布不冻结）。

## 4. DevTools 与撤销（自动化已证 D1–D5，抽查）

- [ ] 打开 DevTools，改一个元素的文字与颜色，Apply：一次撤销即可整体回退（R-07 单一撤销步）。
- [ ] 对原生（场景）元素改位置，Apply：场景属性更新；一次 undo 精确还原。
- [ ] 修改白名单外 CSS（如 filter）：状态栏出现“回退到整层应用”的原因提示，不静默丢失。
- [ ] Discard：未应用改动消失；关闭重开编辑器：图层、页面、参数恢复。

## 5. 播放控制与时间线

- [ ] 空格播放/暂停；上一页/下一页、Marker 增删、循环开关、时间码跳转全部可用。
- [ ] 拖动播放头时画布持续重绘，无长时间白屏。
