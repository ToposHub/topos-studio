# Files 的 Topos 原生播放

Files 的视频预览经 `NativePlayerHost` 把 Topos MOV 和 `.topos` 视频交给共享的 `ToposPlayer`。`ToposMovieSession` 使用 Studio 的 `libtopos_codec`，按独立播放器 ToposKit 的单帧预取方式组织预览。Qt 画布继续接收 10/12-bit YUV 或 CPU 转换的 RGB。

| 路径 | 读包和解码方式 |
| --- | --- |
| 常规预览 | 读整帧包并用 `AUTO_2K` 解码 |
| V7-B 预览 | 只读文件里的基础层，按基础层原生尺寸解码 |
| 快照和封面 | 用独立缓冲解码整帧，输出源分辨率 |

顺序播放时，正在出图的帧和下一帧各占一个平面缓冲，单个原生解码上下文串行执行读包和解码。定位会取消排队的旧帧，或等已开始的旧帧退出再解码新位置。画布接收的帧独立于两个缓冲，因此后续预取可以安全复用它们。

关闭会话时停止提交预取，等在途任务退出后再归还解码线程预算并销毁原生上下文。音频用独立文件句柄，继续由现有播放器管理。单帧缩略图会话按需解码。

同一台机器做 A/B 时，可在进程启动前通过 `TOPOS_DISABLE_PREFETCH=1` 和 `TOPOS_DISABLE_BASE=1` 分别关闭预取和基础层直读。RGB 出图吞吐和画布接收帧率应分别记录。
