# Files 原生四布局

2026-11-17。布局交互参考本机 Eagle 的实际界面；实现继续使用 Topos 的 PyQt6 模型、选择和服务边界。

## 组件与数据流

```text
Files service / transport → FilesEntryModel → FilesFilterModel
                                              ├─ FilesGalleryView + FilesCardDelegate
                                              └─ FilesDetailView + FilesListDelegate
                                                   ↑
                                       共享 QItemSelectionModel

thumbnail_ready → panel.set_thumbnail → bounded QImage cache
                                      ├─ 局部重绘
                                      └─ 缺少尺寸时回填 gallery aspect hint
```

`native_files_gallery_view.py` 只接受 DTO/缩略图比例，不读磁盘、不探测媒体、不操作GPU；完整解码与文件命令仍走既有服务。切换布局不重建模型、选区、预览会话或导入状态。

## 排布规则

| 模式 | 几何 | 呈现 |
| --- | --- | --- |
| 自适应 `adaptive` | 按原比例累积行，接近目标高度并铺满可用宽度；末行不强放大 | 原画幅、单行名称、格式/时长角标 |
| 瀑布流 `masonry` | 等宽列，每项进入当前最短列，高度按原比例 | 极端比例有界单元格，图片仍完整适应 |
| 网格 `grid` | 等大正方形图片区、对齐的名称区 | 默认适应；“显示选项→网格填充方式”可显式选择填充裁切 |
| 列表 `list` | QTreeView属性列，固定行高由密度滑杆调整 | 懒加载真实缩略图；名称、尺寸、扩展名、类型、大小、修改日期、评分；表头可排序/调宽 |

前三种共享虚拟 view 和 delegate；只缓存项目矩形及256px垂直分桶，按可见桶命中/绘制，不创建逐项QWidget。尺寸优先使用服务技术元数据，缺少时用已到达缩略图比例；晚到数据合并到下一事件循环布局。resize/密度变化保留顶部可见素材及像素偏移，跨列表/画廊保留可见素材锚点。

布局缓存不可变元数据快照：仅模型数据或结构变动时重新读取，resize/切布局复用快照重算几何。缩略图大小范围96～320，保留旧180默认值。横向全宽变化仍须O(n)计算项目矩形；10000条合成数据的离屏resize实测中位约40～55ms，只绘15～19个可见项，该结果不承诺真实IO/GPU/播放并行时达到60FPS。

所有模式共用多选、框选、方向键、空格预览、Enter打开、复制、上下文菜单及本地URL拖拽入口；命令和元数据写入仍通过原有panel信号。新增列表尺寸/扩展名列追加在模型末尾，原类型/大小/时间/评分列索引保持兼容，视觉顺序由表头控制。

灯箱先使用当前路径已有的卡片像素，同时请求按视口和屏幕像素密度适配的清晰图，并预热相邻卡片。适配图按文件版本缓存，最多八张、总量 64 MiB。滚轮以指针处为锚点缩放，中键拖动缩放后的画面。绘制只读取已缓存的源像素；放大超过当前预览的像素密度或按 F 查看原尺寸时，按需请求原图细节。相机 RAW 读取内嵌浏览 JPEG，再交给既有解码线程，原尺寸调色走 Color 的原图路径。

Home 等普通目录双击图片或视频会打开灯箱。图片工作区在调色集中双击照片会打开 Color。空格打开的灯箱可用空格关闭，所有灯箱都可按 Esc 或点击右上角关闭。顶部文件名和预览信息默认显示两秒。指针移到顶部后显示信息和当前格式可用的工具，移离顶部两秒后收起。左右切换和关闭保留在灯箱上。调色图标通过与调色集相同的照片加载流程打开 Color。素材库的灯箱打开时隐藏主工具栏，关闭时恢复。

文件筛选共用代理模型，按文件类型、旗标、颜色标签、文字标签及已调色状态组合筛选已加载的结果。已调色状态由后台分批核对原图关联的 `.topos` 工程，可见卡片另外请求缓存预览。显示选项中的尺寸、文件大小、标签和星级评分可独立开启，并保存在用户偏好。默认显示评分角标，当前任一已评分卡片放不下完整星级时，卡片角标统一隐藏。开启星级评分显示选项后，评分移到卡片底部。尺寸优先读索引，无索引时按需探测可见源媒体的尺寸。色标、文字标签和备注写入本地目录数据库，首次编辑时登记未建索引的文件，后续扫描会把这些标记带入所属素材库。

## 偏好与兼容

用户级QSettings新增 `layout_mode` 稳定字符串，避免四种模式插入后把旧索引误解为另一种布局。旧 `view_index=0` 迁为网格、`1` 迁为列表；从未保存过布局的新用户默认自适应。`grid_fill` 单独保存，裁切仅作用于网格。工程包不保存这些偏好或机器路径。

信息栏独立滚动：封面→名称/路径→标记→适用的技术字段；封面resize只重算显示像素，不重新回填正在编辑的标签/备注。常用位置前置，目录树仍通过原有树信号展开；黑色1px面板边界、侧栏和信息栏自动开合继续保留。「位置」栏按可见行分批读取目录的直属可见文件数量，在行右侧显示。应用内文件操作、目录刷新和挂载变化会使相应数量失效。调色集沿用集合成员数量。

## 验证边界

三模式几何/10000条虚拟化、共享选择/鼠标/键盘、布局迁移、真实缩略图像素和信息栏编辑行为由focused测试覆盖。用户目录的137图片和49视频条目读取结果、四模式真实素材截图及未支持/超时格式见[本轮验证](../validation/files_eagle_layout_20261117/README.md)。截图是只读展示快照，不等同于无旧扩展、真实GPU/HDR/声卡、文件安全或连续播放验收。

## 素材库分享

在左侧右键单个素材库，可以导出 `.toposlibrary`。右键「素材库」分组或其中一个库，可以导入，接收方选择存放副本的目录。导入使用新的库 ID，目录同名时保留已有目录并为副本加编号。

版本 1 使用 ZIP 封装可见文件、空目录和 UTF-8 清单。清单以库内相对路径记录评分、颜色标签、旗标、备注、文本标签及所属库的集合。相邻的 `.topos` 调色工程随原文件保存。工作区级调色集、回收站、索引缓存和库外依赖各有独立存储范围。传输在 FilesFacade 的后台执行，文件归档或解包完成后，同卷原子发布目标。
