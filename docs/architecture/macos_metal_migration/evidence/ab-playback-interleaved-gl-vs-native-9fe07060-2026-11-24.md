# 播放：原生视口配置与 GL 配置交替对照

- 时间: 2026-11-24 04:11–04:24（本机时间）；显示器清醒（八个会话全部在显示器约 04:28 休眠之前完成）。
- 机器: i9-9900K + AMD Radeon RX 6900 XT，macOS 15.3.1，3840×2160 @ 60 Hz，DPR = 1；期间另有程序在用这台机器（负载约 4.5）。
- 提交: `9fe07060`。对照双方只差配置：`gl` = `TOPOS_BACKEND_GRAPHICS=opengl`（Metal 预览关）；
  `native` = `TOPOS_BACKEND_GRAPHICS=metal` 加 `TOPOS_EDIT_METAL_VIEWPORT=1`。
- 方法: 两种配置交替启动同一会话（启动 → Edit 页 → 四条 4K 时间线各播一遍 → 退出），各 4 轮，每轮交换先后。
  脚本为 `bench_out/metal-ab.2026-11-23/topos_bench.py playback --repeat 1`，每条时间线分母 399 帧。
  表中是呈现帧数（`frame_presented`）。

| 时间线 | `gl`（四轮） | `native`（四轮） | 中位数之差 |
|---|---:|---:|---:|
| h264 Original | 388, 392, 390, 393 | 394, 395, 395, 396 | +4.0 |
| h264 LUT | 378, 377, 379, 384 | 398, 396, 397, 398 | +19.0 |
| dnxhr Original | 334, 335, 334, 334 | 326, 323, 323, 332 | -9.5 |
| dnxhr LUT | 294, 334, 338, 334 | 340, 322, 321, 327 | -9.5 |

16 组的呈现帧数总和：`gl` 5718，`native` 5783（+1.1%）。

**读法**：

- H.264 两条时间线走原生图层，原生配置更高（Original +1%，LUT +5%）。
- DNxHR 两条时间线是 CPU 合成帧、仍由 GL Viewer 呈现：原生配置每一轮都低于 GL 配置的每一轮（Original：原生最高 332，GL 最低 334），差约 10 帧（−2.8%）。四轮区间不重叠，这不是轮间波动。
- 原生配置同时改变了两个变量（Metal 后端、原生视口）。**这 3% 出在哪一个上尚未分清**：把 `metal`（Metal 后端、无原生视口）
  与 `native` 交替的对照在做到第三个会话之后显示器休眠了（约 04:28），之后的数据不可比，已弃用；
  休眠前的两轮里没有看到这个差（`metal` 325 / 323，`native` 335 / 325、350 / 385），但每边只有两轮，不足以下结论。
