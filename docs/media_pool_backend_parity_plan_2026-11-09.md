# 媒体池：DaVinci Resolve 对齐后的后端交接计划

日期：2026-11-09。项目：topos-studio。

本轮仅修改 `src/features/edit/ui/media_pool_panel.py`，新增 UI 绘制委托 `media_pool_presentation.py`、矢量图标 `media_pool_icons.py`、只读信息弹层 `media_pool_info.py`，并更新相关前端测试。没有修改 core、渲染线程、媒体解码服务、工程 schema、AI controller 或存储格式。下表是后续后端工作的核对与实施计划，所有未勾选项均未在本轮实现。

## 对照依据与前端结果

直接查看了本机已打开的 DaVinci Resolve Studio 20，在当前项目的 **Edit 页 Media Pool** 中切换 Thumbnail / Metadata / List 与搜索行，记录了工具栏、Master、Smart Bins、当前素材箱标题、16:9 缩略图和元数据分组结构。没有改动参考项目中的素材、时间线或工程内容。

前端已完成：

- 紧凑工具栏：Bin List、Clip Color、Relink、保留的 Topos AI 开关、尺寸滑块、Metadata / Thumbnail / List、搜索与范围、排序、更多操作。
- Master 映射既有 root_bin_id；普通素材箱与 Smart Bins 在可调节的上下分区，当前路径始终显示，支持返回与祖先跳转。
- Thumbnail 使用 16:9 预览、独立名称和细选中边框；移除整张彩色卡片。Timeline 使用已有异步缓存预览、类型图标和激活角标。
- Metadata 顶部单独排列素材箱与时间线，下方是已有素材数据的缩略图与详情行；两部分共用模型、选择和既有操作。
- 三视图统一素材/文件夹/时间线与名称排序，保留多选及当前项；切换和刷新不额外触发单项预览。
- 搜索支持 Selected Bin / All Bins 和 All Fields / File Name / Codec / Resolution / FPS。所有列可按现有字段排序；列表支持列移动、宽度调节和右键显隐。
- 拖入素材箱、文件导入、重命名、Delete、剪贴板、Quick Look、悬停预览及原有右键业务入口继续使用项目已有实现；Metadata 顶部区域使用自己的坐标命中目标。
- Clip Color 使用已有 `BatchUpdateAssetLogCommand`，批量操作可撤销；AI 开关、状态点、分析/取消/重试/清除结果与 AI 附件候选接口保留。全范围搜索不会扩大“分析当前素材箱”的实际范围。
- 面板颜色引用全局 `src.shared.ui.style_sheet.C`；滑槽、手柄与 `QScrollBar` 沿用项目全局样式；仅将缩略图滑块的控件底层设为透明，消除独立矩形底色。

这不是对所有 Resolve 媒体功能均已实现的声明。当前仍使用 Topos 已有的 metadata 字段、引用式素材箱、异步缩略图、媒体服务和 AI 能力。后端未提供的数据不伪造显示，未实现的操作也没有添加可点击的假入口。现有完整右键业务菜单继续保留，尚未将 Resolve 的全部原生命令及其业务语义逐项重建。

## 后端接入约定

1. 不从 UI 同步解码、扫描全盘、生成代理、运行 AI 或操作 GPU。使用已有队列/worker，事件回主线程更新状态。
2. 所有可修改工程的操作复用 `ProjectCommandStack` / command / service，保证 Undo、revision、持久化和渲染引用一致；只读查询不伪造工程修改。
3. 异步结果携带 `project_id`、稳定 `asset_id`、来源 revision/generation 和 request_id；旧工程、删除素材、换源后的回调一律拒绝。
4. 新持久化字段需声明 schema 版本与迁移；保留未知字段，避免写入 secret、机器绝对缓存路径或不可重建大缓存。
5. 若增加前端入口，应由 capability / registry 声明真实可用性。显示进度、取消、失败与重试，不能先落一个“成功”提示再等待后端补齐。
