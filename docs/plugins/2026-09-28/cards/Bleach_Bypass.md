# Bleach Bypass ／ 漂白旁路

| | |
|---|---|
| 插件 ID | `Bleach_Bypass`（`plugins/Bleach_Bypass.tglsl`，v1.0） |
| 类别 | 胶片风格 · 色调 |
| 一句话 | 高对比、低饱和的银盐胶片质感：阴影深挖、高光泛银、色彩仅存残余。 |
| 预览成本 | low（纯点操作：0 纹理采样、0 循环、2 次 pow） |
| 色彩空间 | scene-linear 进 / scene-linear 出；HDR 安全（输出不 clamp） |

## 参数

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| 强度 Strength | 0.6 | 0–1 | 整体效果混合量，0 完全直通（带早退出） |
| 对比度 Contrast | 0.4 | 0–1 | 以 18% 灰为锚的 S 曲线强度：阴影下压、高光扩张 |
| 饱和保留 Saturation Retention | 0.35 | 0–1 | 1.0 保留原始色度，0.0 完全银灰 |

## 视觉签名

- 黑位保持，10% 灰下压约 14%，18% 灰锚点几乎不动，显示白扩张约 ×1.8；
- HDR 高光持续增长并叠加有界的无彩银色提亮（+0.25 封顶）；
- 彩色像素（如饱和红）被推向"褪色染料 + 银版"的低饱和响应。

## 适用场景

- 战争/纪实/回忆段落的冷峻银灰调；
- 时尚与黑白介于之间的"去色但保留痕迹"造型；
- 高反差物料（金属、玻璃、雨夜）的银质高光强化。

## 叠加建议

- **后接 Film_Halation**：银版确定基调后再给高光加暖色晕染，层次更立体；
- **前接 bilateral_skin_smooth**：先磨皮再漂白，避免银版放大皮肤瑕疵；
- 与 warm_tint 叠加可做"暖染 + 银底"的混合工艺感；放在调色链末端效果最稳定。

## 技术备注

经典 bleach bypass 近似：luma 锚点 S 曲线（overlay 侧）+ 有界银色提亮
（screen 侧，混合键有界化、信号不 clamp）+ 色度按饱和保留缩放。
确定性点操作，支持 video/LUT 导出（`@export_support all`）。
详见 `docs/plugins/2026-09-28/specs/Bleach_Bypass.md`。
