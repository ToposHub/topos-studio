# Cross Process ／ 交叉冲洗

| | |
|---|---|
| 插件 ID | `Cross_Process`（`plugins/Cross_Process.tglsl`，v1.0） |
| 类别 | 胶片风格 · 色调 |
| 一句话 | 反转负冲风格曲线族：三通道有理密度曲线交叉 + 染料雾交叉曝光（G→R 泄漏为签名），青蓝阴影对撞黄绿高光。 |
| 预览成本 | low（纯点操作：0 纹理采样、0 循环、0 次 clamp，仅 1 次 pow 用于强度曲线） |
| 色彩空间 | scene-linear 进 / scene-linear 出；HDR 安全（曲线全实轴单调外推、无极点、不 clamp） |

## 参数

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| 预设 Preset | Classic | Classic / Green Shift / Warm | 三组风格曲线族（select，索引 0..2） |
| 强度 Strength | 0.7 | 0–1 | 感知曲线混合回原值，0 完全直通（带早退出） |

## 预设一览（满强度，scene-linear）

| 预设 | 18% 灰 → | 显示白 → | 签名 |
|---|---|---|---|
| Classic 经典 | (0.186, 0.190, 0.233) | (1.197, 1.076, 0.947) | 青蓝阴影 × 黄绿高光，G→R 0.12 泄漏 |
| Green Shift 绿偏移 | (0.179, 0.204, 0.161) | (1.027, 1.158, 0.939) | 病感绿罩染中高调，G 同时再曝光 R 与 B |
| Warm 暖调 | (0.221, 0.179, 0.127) | (1.206, 1.043, 0.747) | 琥珀暖影调，蓝色两端压扁漂白 |

## 视觉签名

- 黑位严格保持纯黑（曲线过原点），暗部染色来自各通道黑端增益差（如 Classic B 通道 1.32 对 R 0.85）；
- 高光端各通道趋于不同渐近斜率（m/v），交叉出高光色偏，HDR 输入沿渐近线持续增长不折叠；
- 染料雾交叉曝光让纯绿画面渗出 R 分量（Classic 下 G=0.5 → R≈0.059），绿色富集区漂黄绿而非纯绿。

## 适用场景

- 时尚 MV / 摄影集的 E6 负冲反转质感（Classic）；
- 惊悚、废土、荧光灯叙事的病感绿罩（Green Shift）；
- 沙漠、回忆、暖阳段的琥珀漂染（Warm）；
- 与漂白旁路互为表里：一个去色提银，一个撞色交叉，按叙事取舍。

## 叠加建议

- **后接 Film_Grain**：交叉曲线定型后叠颗粒，负冲质感更完整；
- **前接 Three_Way_Tint**：先做一级校色定曝光，再交给本插件撞色；
- 建议放在调色链后段；其后如接 Color_Space_Transform 做输出 gamma，顺序无耦合。

## 技术备注

每通道曲线为有理近似 `f(x) = x(a + m·x²)/(1 + v·x²)`（无查表）：
黑端增益 a、渐近增益 m/v、过渡中心 ~1/√v；分母恒 ≥ 1（无极点无除零），
`a·v ≤ 9·m` 时在全实轴严格单调（可证，验证器断言 9 条曲线全部满足）。
染料雾为小权重非负加性交叉（对角为 0），HDR 保持线性、负值保持负。
确定性点操作，支持 video/LUT 导出（`@export_support all`）。
