# Fake Infrared ／ 假红外

| | |
|---|---|
| 插件 ID | `Fake_Infrared`（`plugins/Fake_Infrared.tglsl`，v1.0） |
| 类别 | 创意风格 · 通道映射 |
| 一句话 | 假红外艺术效果：植被化为发光的红品红、天空沉入深青蓝，再罩一层暗区加权的红色梦幻光晕。 |
| 预览成本 | low（纯点操作：0 纹理采样、0 循环、1 个 pow 调用点） |
| 色彩空间 | scene-linear 进 / scene-linear 出；HDR 安全（信号通路 0 处 clamp） |

## 参数

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| 通道映射 Channel Map | Classic | Classic / Amber / Sky Swap | Classic＝假彩色记录位移（植被红）；Amber＝暖橙红植被；Sky Swap＝R↔B 交换类（天空火红、植被钢蓝） |
| 发光强度 Glow Strength | 0.45 | 0–1 | luma 反比加权的暗区/植被红色光晕；遮蔽型眩光，会轻微抬升黑位 |
| 对比度 Contrast | 0.35 | 0–1 | 18% 灰锚点逐通道 S 曲线：阴影下压、高光扩张 |

## 视觉签名

- 植被 (0.02, 0.12, 0.02) → (0.355, 0.040, 0.142)：明亮红品红 + 光晕，
  蓝天 (0.25, 0.45, 0.90) → (−0.054, 0.287, 0.628)：深青蓝，luma 几乎减半；
- 中性灰三档映射下都保持灰（灰阶不染色），18% 灰锚点默认仅 +8%；
- HDR 绿 (0, 10, 0) 的红外记录增长到 R=126.7：高光持续增长、从不折叠；
- 黑位默认抬升 (0.054, 0.023, 0.028)：有意设计的红外眩光底色。

## 适用场景

- 梦境/异世界/时尚大片：树木草地转品红或钢蓝的超现实植物景观；
- Sky Swap 模式的火红天空：末日感、火星感段落；
- 纪实段落中的"红外侦察"风格插叙（军事/科考语境）。

## 叠加建议

- **后接 Soft_Glow_Bloom**：本插件光晕是逐像素眩光，叠空间 bloom 后
  植被高光获得真正的扩散辉光，层次更立体；
- **前接 bilateral_skin_smooth**：Classic/Amber 模式下肤色会向绿色位移
  （真红外特性），先磨皮并考虑在下游用 HSL 类工具回收肤色；
- 与 Film_Grain 叠加：红外胶片颗粒感更完整；放在调色链中段
  （映射之前先做曝光/白平衡）效果最稳定。

## 技术备注

启发式合成红外记录 `ir = luma + 植被线索×1.6 − min(天空线索, luma)×1.2`
（天空削减以 luma 封顶，下探有界 −0.2·lum）；select 早返回链分发三档
通道映射；18% 灰锚点逐通道 S 曲线（signedPow 保负值、保 HDR 增长）；
luma 反比权重光晕（1/(1+luma×6)）有界 ≤ glow×0.3。
确定性点操作，支持 video/LUT 导出（`@export_support all`，按模式）。
详见 `docs/plugins/2026-09-28/specs/Fake_Infrared.md`。
