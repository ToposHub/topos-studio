# H4 评估：Topos 图片灰度（GRAY）原生支持

状态：**评估结论（未立项）** · 2026-09-21 · 计划表 H4（P3）
结论先行：**建议暂不立项**——体积收益有限（≈2.7× 于 GBR 三等平面，但
实际灰度素材经 rans2 后差距收窄到 ≈1.6–2.0×），YUV444/GBR 折中方案
已可承载灰度工作流；新载体代际的全链成本（native 枚举代 + IDSC 交叉
规则 + Python 注册名 + 渲染/导出双链）显著高于收益。若未来灰度批量
扫描/中间片成为真实负载，按本评估 §3 的落点单独立项。

## 1. 现状

- IDSC `channel_model=2`（GRAY）已占位但整链不可达（spec §6 注记
  "2 = GRAY；其余 reserved" 中 2 为预留值，writer/reader 均未实现）。
- IDSC `channel_count` 域 = {3,4}；无 1 平面载荷模型；无 pf → GRAY
  映射（内层 TPIC pixel_format 无 GRAY 枚举——新增属载体代际变更）。
- 灰度素材当前路径：导入侧转 GBR 三等平面（灰度值复制 3 份）→
  3 平面编码，或以 YUV444 载荷走 Y 链（无原生入口，需手工构造）。

## 2. 体积收益测算

| 方案 | 每像素容器 | 1080p 单帧（近似） | 说明 |
| --- | ---: | ---: | --- |
| GBR 三等平面（现状） | 3×12-bit = 36 bit | 2.99 MB（raw） | 三平面同值，变换/熵按 3 份计 |
| GRAY 单平面（目标） | 1×12-bit = 12 bit | 1.00 MB（raw） | 理论 2.99× 收益 |
| GRAY 实码率（估计） | — | ≈1.5–1.9 MB | 现状三平面 rans2 对冗余平面压缩良好，实际差 < 2× |

关键事实：rans2 上下文模型对"三份相同的平面"有极高的跨带相关性捕获
（同值平面的残差几乎全零、token 极少），因此**真实压缩比远低于理论
位深比**。实测锚点需立项后补（评估阶段以相关性推断）。

## 3. 若立项：实施落点清单

1. **载体代际**：内层 TPIC pixel_format 新枚举（建议 4 = GRAY，
   单平面）——帧头校验/几何推导（plane_count=1、无色度）/negotiation
   全链；minor 代门控照 H1 先例。
2. **IDSC 交叉规则**：channel_model=2 ⇔ channel_count∈{1,2} ⇔
   pixel_format=4；alpha（channel_count=2）v1 建议不做。
3. **Python 面**：注册名 `topos_gray{bd}le`（frame.py）+ 图像序列
   编码器/图片源/缩略图/预览链（GRAY→RGB 显示复制）。
4. **导出面**：save_image 灰度 numpy/灰度 PNG/TIFF → GRAY 直入。
5. **验收**：编解码 roundtrip + 体积报告（vs GBR 三等平面实测）+
   golden 增补。

## 4. 折中方案（现状即可用，建议优先）

- 灰度 PNG/TIFF/PSD 导入已走 GBR 复制路径，工作流正确（无颜色损害，
  仅体积/带宽 ×3）。
- 体积敏感场景可用 **4:4:4 YUV 载荷 + U/V 中性面**：U/V 全 512（10-bit
  中性）后残差极小，实码率接近单平面；需宿主侧构造（U/V 常量面），
  无需任何格式变更——**若立项前确有体积痛点，这是零成本过渡**。

## 5. 决策请求（若评审）

仅当满足其一建议立项：(a) 灰度中间片批量入库 ≥ 常态负载；
(b) 8K+ 灰度源存储成本成为计价项；(c) YUV 中性面折中被证实在真实
语料上不达标。否则维持现状。
