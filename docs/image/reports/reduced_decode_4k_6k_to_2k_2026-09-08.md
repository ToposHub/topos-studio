# Fixed-ratio reduced decode benchmark（2026-09-08）

本次比较使用同一进程、同一编码包、同一目标 2048×1080，比较旧的 target-size 路径和新的固定比例低频路径。测试配置为 Image Preview / YUV422 / 10-bit / VLC / QP58 / RDO off，预热 2 次，采样 6 次。

| 源素材 | 路径 | p50 | p95 | p50 FPS |
| --- | --- | ---: | ---: | ---: |
| 4K 4096×2160 | 旧 target-size | 92.16 ms | 98.71 ms | 10.85 |
| 4K 4096×2160 | 新 1/2 reduced | 75.18 ms | 76.60 ms | 13.30 |
| 6K 6144×3240 | 旧 target-size | 118.31 ms | 118.54 ms | 8.45 |
| 6K 6144×3240 | 新 1/3 reduced | 117.25 ms | 117.44 ms | 8.53 |

结论：

- 4K→2K 的低频裁剪和 AVX2 采样逆变换在这组素材上约带来 22.6% 的 p50 改善；
- 6K→2K 几乎没有改善，说明瓶颈已转移到完整熵码流消费、CRC、slice 调度和仍需解析的高频 `(run, level)` 码字；
- 因此目前不能宣称“6K 以 2K 解码负载播放”。真正跳过高频熵解码需要新的可分层/独立长度码流，不能仅靠解码器端猜测跳过可变长码字；
- 新 API 已提供 `/2、/3、/4、/8`，其中精确可整除的 6K→2K 使用专用 `1/3` 块采样映射。

完整数据见同名 JSON。基准环境、素材生成和版本信息应与 JSON 一起保存，不能把该结果推广为所有 CPU/素材的固定 FPS 承诺。
