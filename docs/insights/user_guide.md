# 洞察（Insights）用户指南

> 入口：**Edit → Insights → Insights**（菜单 `edit.insights.open`，需 Edit 特性启用）。
> 窗口为独立非模态窗口；重复点击菜单会激活同一窗口，不会重复打开。
> 当前版本：只读。全部功能不改工程、不进 Undo、不触发 ASR/外部模型。

---

## 三条核心用户路径

### 路径一：跨序列找一句对白并定位

1. 打开 Edit → Insights → Insights。
2. 首次打开或工程有新改动时，点 **刷新捕获**（显式生成新捕获；窗口
   状态栏显示捕获 ID 与序列数）。
3. 在搜索框输入对白文本（默认大小写不敏感；中文直接可用），
   回车或点 **搜索**：
   - 例：`你好` 会同时命中"主时间线"与另一条含相同台词的序列——
     跨序列重复各自独立成条；
   - 受限前缀语法：`type:cue`（只搜字幕）、`type:marker`、
     `type:asset`、`timeline:名称片段`（按序列名称过滤）。未知前缀
     （如 `foo:bar`）按普通文本处理，不会丢字。
4. 结果表：类型 / 序列 / 轨道 / 名称 / 入出点 TC（按各序列 fps 的
   DF/NDF 精确显示）。同名序列以 `名称 · id前8位` 区分。
5. **双击命中行** → 定位：宿主切换到该序列并把播放头移到命中点
   （走既有序列切换与播放头路径）。定位被拒（换工程/目标被删/序列
   revision 漂移）时状态栏给出原因，重新刷新捕获即可。
6. 顶部"全部已加载序列"可换成单序列范围再搜。

注意：未加载的序列会显示" N 个序列未加载（已排除）"——不会把它们
算成"零结果"。搜索结果超过上限会显示"结果已截断"。

### 路径二：导出镜头/对白/marker 总表

1. 刷新捕获后进入 **总表** 页签，点 **导出 CSV / JSON / HTML …**，
   选择导出目录。
2. 生成三个文件（同一份报告数据，三种格式行数/ID/区间一致）：
   - `report.csv`：utf-8-sig，Excel/Numbers 直接打开；中文、引号、
     多行字幕按 CSV 标准转义，原文完整；
   - `report.json`：结构化原始数据（文本不做转义损失）；
   - `report.html`：静态页面（无脚本），可离线打开。
3. 行语义：每个 clip（视频+音频轨）独立一行；多轨重叠各自成行，
   **各行时长之和不等于节目时长**（统计页有覆盖并集口径）。
   复杂变速（冻结/速度点等）行会标 `source_mapping=unknown`——
   源区间是记录值，工具不推导逐帧映射。
4. 导出先写临时文件再原子发布；失败/取消不会覆盖旧文件。

### 路径三：查看素材使用与剪辑节奏统计

1. 刷新捕获后进入 **统计** 页签（自动异步填充，不卡 UI）。
2. 上表：每个序列的镜头数、镜头长度均值/中位、每分钟切点
   （分母=该序列时长与 fps，显式携带）、时长与加载状态。
3. 下表：每个素材的使用次数与出现序列；`类型` 列区分 video/audio。
4. 口径声明（同时写入导出的 stats）：
   - 使用=直接 clip 引用（与媒体池"使用位置"同语义）；外录绑定/
     嵌套展开等间接依赖**不**在内（那属于归档依赖闭包能力）；
   - 嵌套序列/生成器算一次直接使用，内部时间线不展开；
   - 禁用轨包含与否在口径说明中标注；
   - 本页只描述计数与分布，**不输出任何"节奏质量分"**（质量评估是
     另一个既有能力，且不阻断导出）。

## 第二批功能（窗口页签入口已就绪）

- **联系表**（Contact Sheet 页签）：选择序列（或全部）→ 生成联系表。
  为序列镜头生成代表帧格（PNG 网格 + 本地 HTML），输出到所选目录的
  `contact_sheet_<序列>/` 子目录。每格标注源缩略图与捕获 revision——
  源缩略图**不是**带调色/合成/字幕的最终画面。复杂变速镜头显示占位
  与原因。当前缩略图供应未接线（G1 待接），全部占位属预期。
- **审片资料包**（Review Package 页签）：一键把同一次捕获的总表/
  统计/联系表/音频 cue CSV/完整快照打成一个目录（勾选可同时 ZIP），
  含 manifest（文件清单+sha256+完整性声明）。生成期间继续编辑不影响
  包内容；失败不覆盖旧包。音频 cue 表复用既有 CueSheet 导出（供外部
  DAW 对齐）。包是只读资料，不能恢复工程。
- **对照**（Compare 页签）：保存当前捕获为资料快照文件；打开快照
  A/B；比较两份快照的编辑内容差异（片段增删改/字幕/marker/素材改名/
  统计差值，只读 Markdown 呈现）。捕获时间与 revision 计数不参与比较；
  未加载序列列入"未比较"，不会误报大量删除。结果只读可导出，不恢复/
  不合并工程。

## 结果导航

- 结果表支持三种等价定位方式：**双击命中行**、**行选中后按 Enter**、
  （宿主实现侧的）菜单入口。定位一律经宿主导航回调切换序列并移动
  播放头；被拒（换工程/目标被删/序列 revision 漂移）时状态栏给出
  原因，重新刷新捕获即可。

## 取消与错误恢复

- 后台搜索/统计作业支持 **取消**（按钮/窗口关闭）；窗口关闭后迟到
  的旧结果不会回写 UI；
- 刷新捕获后，旧捕获的所有后台结果自动作废拒收；
- 无工程/捕获失败：状态栏显示原因（如 `no project loaded`），
  正常加载工程后刷新即可；
- 定位失败（见路径一第 5 步）按原因提示，刷新捕获后重试。

## 已知限制（如实声明）

- 复杂变速/VFR 的源帧映射尚未在核心验收（对应 M 线工作）：相关镜头
  源区间按记录展示，逐帧映射标 `unknown`，联系表对这类镜头只给占位；
- 命名工程版本/评论重定位（M02/M15）未接入：快照对照只在同一工程
  重建后 ID 一致时逐行对齐，否则提示不可直接一一对应；
- 缩略图供应待 G1 接线（接线前联系表全部占位，属预期降级而非缺陷）；
- 统计的"每分钟切点"等比率只在序列有时长与 fps 时给出；分母不可得
  显示 `—`（未收集，不冒充 0）。
