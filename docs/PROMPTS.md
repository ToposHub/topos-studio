## 💡 提示与技巧

### 提高 Agent 效率
1. **提供充分上下文**：每次调用 agent 时说明项目技术栈（PyQt6 + ModernGL + GLSL）
2. **引用示例代码**：指出参考文件（如"参考 src/ui/xxx_panel.py"）
3. **明确约束**：提醒 agent 遵循 `.clinerules` 规范
4. **分步执行**：复杂任务拆分为多个 prompt，每步确认后再继续
5. **使用绝对路径**：引用文件时使用完整路径

### 避免常见问题
1. ❌ 不要让 agent 直接修改核心渲染逻辑（先审查）
2. ❌ 不要在不提供上下文的情况下调用 agent
3. ❌ 不要一次性给 agent 过多不相关的任务
4. ✅ 修改渲染管线后必须运行 `/review`
5. ✅ 生成 GLSL 代码后立即自检浮点数类型
