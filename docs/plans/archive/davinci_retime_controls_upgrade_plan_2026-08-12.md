# 达芬奇式片段变速控件升级计划（2026-08-12）

## 参考行为

依据 Blackmagic Design 的 DaVinci Resolve 编辑教学指南与 Retime Controls
工作流，片段变速应在时间线内完成：显示片段内控件、在播放头处添加速度点、
通过每段的百分比下拉菜单修改速度，并可在右键菜单中清除或恢复控制点。
速度点必须跟随素材位置而非屏幕位置，且所有改变必须进入 Undo/Redo、预览、
导出和工程序列化的同一条数据链。

## 实施顺序

1. 将 `SpeedParams` 扩展为不可变的分段速度模型；速度点使用素材相对帧保存。
2. 让 `ClipInstance.timeline_to_source_frame()`、时间线时长、命令栈和项目序列化
   共用这套模型，避免预览与导出在变速后错帧。
3. 在 `ClipItem` 叠加 Retime Controls：蓝色分段条、黄色速度点、百分比标签，
   点击标签打开 10%–800% 的速度菜单。
4. 在片段右键菜单加入 `Retime Controls`、`Add Speed Point` 和
   `Clear Speed Points`；速度点位置从当前播放头推导。
5. 用分段帧映射、序列化、撤销/重做和 Qt 离屏绘制烟测覆盖回归。

## 本次交付

- 已完成步骤 1–5。
- 片段常量速度菜单的预设更新为 Resolve 常用的 10%、25%、50%、75%、100%、
  110%、150%、200%、400%、800%。
- 已保留原有 `reverse` 与插值字段；速度点是项目文件向后兼容的可选字段。

## 后续增强（独立于本次控件）

- Retime Curve 的贝塞尔速度坡道与入/出坡度手柄。
- Optical Flow/Speed Warp 的逐段渲染策略、冻结帧，以及保持音调的逐段音频伸缩。

这些属于渲染和音频引擎能力，不能只在 UI 中伪造；实现时必须继续保持
preview/export 和音频的同源时间映射。
