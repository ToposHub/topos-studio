## 10. AUD-18213 [Major/bug] — FIXED

**问题**：`process` 首行 `if not enabled: return samples` 直通，而
`_gain_db` 可能停留在 -6dB → 上一块已衰减、下一块 0dB，瞬时增益阶跃

duck 电平（无 0dB 跳变）、块内最大相邻差 < 0.01（无阶跃）；完全释放后禁用
为位级直通。

## 14. AUD-18302 [Major/bug] — FIXED

**问题**：`_warp_rgba_to_canvas` 扫描区是旋转后 bbox 的 AABB，四边形外像素
被 clamp 到最近边缘 texel 并直接写回——字形 bbox 边缘必含不透明像素 →
旋转字幕向 AABB 边界拖出不透明条纹，与预览（QPainter 按四边形光栅化）不一致。

**修复**：反向映射求出 `(lx, ly)` 后先算 inside mask
（`0<=lx<=tex_w-1 and 0<=ly<=tex_h-1`），采样后将 mask 外像素整体置 0
（straight-alpha 全 0 = 全透明）再写回。rotation=0 时 mask 全真，行为不变。

**测试**：`TestAud18302RotationEdgeMask`（2 例）——45° 旋转时 AABB 四角
alpha=0、中心 alpha=1；0° 时不透明样本数恰为 tex_w×tex_h（回归保护）。

## 16. AUD-18321 [Major/risk] — FIXED

**问题**：源纹理缓存"淘汰即释放"（`_SOURCE_CACHE_MAX=3`），而
`get_timeline_clip_texture` 返回的 `_TexResult` 无引用保护——同一复合图
第 4 个不同素材上传会淘汰并释放第 1 个节点尚未采样的纹理名 → 悬垂采样
（黑帧/闪变）。

**修复**：新增 `_source_texture_retired: list[int]` + 两个方法：
- `_retire_source_texture(tex_id)`：淘汰/替换/清缓存路径不再立即
  `_release_owned_texture`，改为入 retired 队列（cache 已不可达，但本帧
  已返回的纹理名仍可采样）；
- `_flush_retired_source_textures()`：在 `get_timeline_clip_texture`
  渲染线程入口（`_drain_pending_source_cache_clear` 之后）flush——此时上一次
  求值的 draw 命令已在同一 GL 线程发出，纹理不再被新的采样工作引用
  （GL delete 语义本身也保证已入队命令安全）。
三条原释放路径（`_cache_source_texture` 的 stale 替换与 LRU 淘汰、
`_clear_source_cache_unlocked`）全部改走 retired；`clear_debug_cache` 的
硬拆除保持立即释放。

**测试**：`TestAud18321DeferredEvictionRelease`（3 例）——第 4 个纹理入缓存
后第 1 个被移出账本但未释放、flush 后释放；stale 替换同样延迟；
`clear_source_cache` retired→flush 全链路。
