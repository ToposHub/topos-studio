## AUD-37601 — `_value_from_position` 滑轨零长度除零

**问题**：widget 高/宽被压到恰好等于 knob 高/宽（`_update_size` 的最小尺寸）
时 `bottom - top == 0`，`mousePressEvent`/`mouseMoveEvent` 路径抛
ZeroDivisionError（PyQt6 事件处理器未捕获异常按 qFatal 处理，可致进程退出）。

**修复**（audio_fader.py `_value_from_position`）：垂直分支 `bottom <= top`、
水平分支 `right <= left` 时直接返回 `min_val`（与既有 `range_val <= 0` 守卫
同风格），并附注释引用 AUD-37601。

**验证**（TestAud37601ZeroLengthTrack，4 用例）：零长度几何下取值不抛异常且
返回 `minimum()`；press/move/release 事件链直接调用不抛；正常几何映射不受
影响（顶端=最大、底端=最小）。
