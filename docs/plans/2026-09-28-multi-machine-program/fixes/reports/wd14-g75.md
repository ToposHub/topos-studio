## FIXED 明细

### AUD-29805 — `_measure_gpu_effect` GL 资源泄漏（benchmark.py:498-528）
- 根因：`gl_context.texture(...)`/`source.write`/`CompositeEffectBridge(...)` 在第二个 try/finally 之前执行，任一步抛异常则 context/texture 不释放。
- 修复：texture/bridge 构造全部移入统一的 try/finally；`source`/`bridge` 以 None 哨兵初始化，finally 中按已创建对象逐个释放（bridge.cleanup → source.release → gl_context.release）。
- 测试：3 项（texture 失败释放 context；bridge 失败释放 texture+context；成功路径 bridge/texture/context 全释放且 passed）。

### AUD-29808 — ffprobe 无 timeout（bitrate_probe.py:70-84, 122-131）
- 根因：两处 `subprocess.run` 无 timeout，`subprocess.TimeoutExpired` 非 OSError 子类，病态文件可无限挂起，击穿"Never raises / 退化为 unknown"契约。
- 修复：新增模块常量 `_FFPROBE_TIMEOUT_S = 30.0`（带注释），两处 run 均传 `timeout=`；主探测的 except 元组补 `subprocess.TimeoutExpired`（→ return None），`-count_packets` 二次探测补捕（→ nb_frames=0）。
- 测试：2 项（主探测超时返回 None 且断言 timeout 实参存在；计数探测超时降级 nb_frames=0 仍返回 VideoMetrics）。

### AUD-29810 — 逐帧全量资产哈希（cache.py:17-18, 97-110）
- 根因：`build_cache_manifest` 每帧调用（build 确认后同帧再调一次），`_file_hash` 每次 `read_bytes()+sha256` 全量重算。
- 修复：`_file_hash` 按 `(str(path), st_size, mtime_ns)` 模块级 memoize（`threading.Lock` 保护，512 条上限整体清空防病态增长）；stat 失败时回退直接哈希，保留原 raise-on-missing 行为。缓存键一致性不受影响：内容变化必改变 size/mtime_ns，memo 命中值恒等于现场 sha256。
- 测试：2 项（memo 命中不再重哈希——monkeypatch hashlib.sha256 断言不被调用；size 变化强制重哈希且值正确）。

### AUD-29903 — 非数值 `opacity` 裸 float()（evaluator.py:203）
- 根因：`float(effective.style.get("opacity", 1.0))` 无防护，`"50%"`/`null`/列表使整帧 evaluate() 抛异常。
- 修复：元素循环内统一 `style_map = effective.style if isinstance(..., Mapping) else {}`，opacity 改 `_float_or(style_map.get("opacity", 1.0), 1.0)`（与 212 行既有防护同款，含有限性检查）。附带：`style=None` 也不再在 `.get` 上 AttributeError。
- 测试：参数化 3 项（None/"50%"/[1] 均降级 1.0）+ 1 项合法 0.25 正常生效。

### AUD-29904 — `base_style` None 时 dict(None) TypeError（evaluator.py:274-277）
- 根因：防御分支 `dict(base_style)` 恰对最常见脏值（`"style": null`）自身抛 TypeError；且该脏值实际在 203 行 `.get` 处先崩。
- 修复：非 Mapping 一律前置归一为 `{}`（274 行处 `if not isinstance(base_style, Mapping): base_style = {}`；同函数 160 行 style-update 合并分支同样加固）。
- 测试：1 项（`style=None` 求值成功、merged style 为 dict、opacity 1.0）。

### AUD-29908 — QApplication 无锁 check-then-act（frame_adapter.py:44-55）
- 根因：`QApplication.instance() or QApplication([])` 在多渲染 worker 线程无锁并发执行，可双实例创建（Qt fatal）或与主线程竞态。
- 修复：模块级 `_QT_APPLICATION_LOCK = threading.Lock()`，check-then-create 整体入锁（双检由 QApplication.instance() 天然承担）；仍优先复用既有实例。AUD-29909（environ 副作用）为 Suggestion 且不在本批，未动。
- 测试：1 项（4 线程并发 `_svg_to_rgba` 全部成功、进程内恰一个 QApplication、模块缓存一致）。

### AUD-30001 — measure_dom fail-open（budget.py:62-69）
- 根因：宽泛 `except Exception: pass` 吞掉解析错误后仍以部分 node_count/max_depth 出具预算报告，超大页面可被静默判为达标。
- 修复：`DomStats` 新增 `count_complete: bool = True` 与 `count_error: str = ""`；解析异常记录类型+消息；`enforce_budget` 对 `count_complete=False` 追加结构化违例 `BudgetViolation("dom_count_incomplete", 1, 0)` —— fail-closed，质量门（check_css_budget 泛化遍历 exceeded）自动透出。宽泛 except 不再静默（错误上浮进报告），符合铁律。
- 测试：1 项（monkeypatch feed 抛错 → not ok + dom_count_incomplete + count_error 含原因）。

### AUD-30002 — data URI 求和对单条上限（budget.py:79, 102-103）
- 根因：`data_uri_bytes = sum(...)` 与 `ResourceBudget.max_data_uri_bytes`（注释明确 individual payload）语义错位，40×1KB 合法图标合计 40KB 触发单条 32KB 限。
- 修复：`max((len(m) for m in ...), default=0)` —— 取最大单条 data URI 长度，与 ResourceBudget 注释语义对齐；measure_dom docstring 同步说明。
- 测试：1 项（40×1KB 不触发；单条 40KB 触发）。

### AUD-30005 — REPLACE_TEXT 不校验 edit_mode（html_patch.py:135-140；node_identity.py:69-72）
- 根因：`text_slot` 全库恒 True（提取器从不传该字段）→ `if not node.text_slot` 死代码，token_only 节点可被改写文本，违反 FH-13。
- 修复（全在白名单文件 html_patch.py 内）：REPLACE_TEXT 分支增加 `node.edit_mode == "token_only"` → `EDIT_MODE_FORBIDS`。node_identity.py 不在白名单未动，但 edit_mode 由提取器真实携带，该检查即可闭环。
- 测试：3 项（validate 层拒绝；apply 层拒绝；content 节点仍可正常改写——防回归）。

### AUD-30006 — duration_ms 无类型/非负校验（html_patch.py:165-169；html_patch_apply.py:254）
- 根因：校验端只查键存在，apply 端 `int()` 裸调用，`"abc"`/`[1]` 抛裸 ValueError/TypeError 逃出 HtmlPatchError 契约，负数静默产出 `animation: -0.5s`。
- 修复：validate_patch 增加 `isinstance(duration, bool) or not isinstance(duration, int) or duration < 0` → `ILLEGAL_VALUE`（非负 int、拒 bool）；apply 端注释改为与事实一致（`patch.value["duration_ms"]`）。
- 测试：参数化 6×2 项（"abc"/[1]/-5/1.5/True/None 及其包裹 dict 均结构化拒绝）。

### AUD-30009 — animation 简写整体替换（html_patch_apply.py:261-272）
- 根因：规则与行内回退均对 `animation:`/`animation-duration:` 的整个值做替换，`animation: slide 2s ease-in infinite` 变 `animation: 0.5s`，动画名/迭代/缓动被抹掉。
- 修复：新增 `_replace_animation_duration(prop, value, seconds)`：长属性整体替换；简写用 `_CSS_TIME_RE`（`(\d*\.?\d+)(ms|s)` 带词边界，避免 steps()/easing 数字误伤）只换第一个时间分量（=duration，第二个是 delay 保持）；简写无时间分量则追加。规则正则改为捕获属性名 `(animation(?:-duration)?)`，行内回退同款处理。
- 测试：5 项（简写保 name/easing/iteration 且换时长；`2s 1s` delay 保持；`animation-duration` 长属性整体替换；行内 style 回退同构；时长 2s 消失断言）。

### AUD-30010 — 补丁后 source_hash 语义错误（html_patch_apply.py:342-349）
- 根因：`source_hash` 与 `sanitizer_hash` 都写成已净化 HTML 的哈希（且同一 sha256 算两遍），违反 core/html_layer.py FH-01 契约（source_hash=authored 预净化 / sanitizer_hash=净化后），补丁链的审计面与 authored 侧缓存键反应能力失真。
- 修复：`source_hash = sha256(new_html)`（handler 输出、进 sanitizer 之前的文本），`sanitizer_hash = sha256(sanitized.html)`，各算一次。与全部其它生产者（build_html_layer、build_html_layer_from_source、ReplaceHtmlSourceCommand）对齐；补丁链 precondition 全库均取 `layer.source_hash`（motion_graphic_editor_window.py:2074、测试），链式校验不受影响。
- 测试：2 项（source_hash==sha256(authored)、sanitizer_hash==sha256(sanitized)；二段补丁链在 revision+1 后仍通过校验）。

### AUD-30011 — set_slot_attr 全文 find 定位（html_patch_apply.py:230-242）
- 根因：`html.find('data-topos-editable="x"')` 先命中 `<style>` 内的 `[data-topos-editable="x"]` 选择器，rfind("<") 落到 `<style>` 上把属性插进样式区并破坏输出；同名槽位只改第一个。
- 修复：改用 `_TAG_RE` 标签遍历 + `_parse_attrs` 在标签属性内定位（CSS 文本天然不在标签内被扫描），命中该槽位的全部元素统一更新；未命中仍抛 `UNKNOWN_SLOT`。引用注释更新。
- 测试：4 项（style 选择器先行命中场景下真实元素被改且样式区原样；多元素全部更新；未知槽结构化错误；apply 全链含再净化）。

### AUD-30014 — CSS 自定义属性绕过 url() 白名单（sanitizer.py:747-757, 764-774）
- 根因：`prop.startswith("--")` 分支在 url() 白名单检查之前无条件 `continue`，`--x: url(https://…)` 原样保留，配合 `background: var(--x)` 绕过 URL 策略。
- 修复：抽出 `_carries_unsafe_css_url(value, *, ...)` helper（含 `_safe_css_url` 白名单复用）；自定义属性与常规属性走同一 url() 检查（违规记 `css_url:{prop}` 剥除），常规属性路径行为等价重构。topos-asset:// 与显式 network profile 的 url 仍按原策略放行。
- 测试：4 项（`--evil:url(https://…)` 剥除而 `--ok` 保留；`--bg:url(topos-asset://…)` 保留；allow_network_resources=True 时 https url 保留；常规属性 url 策略不回归）。
