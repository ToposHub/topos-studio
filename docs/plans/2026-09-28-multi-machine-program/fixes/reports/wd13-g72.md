## 修复明细

### AUD-27303 — 预览模式缺失文件资产零诊断 [FIXED]

- 位置：`core/asset_provider.py` `AssetProviderRegistry.preflight`（原 194-197 行仅
  `for_delivery` 时报告 license）。
- 根因：`LocalAssetProvider.resolve` 对不可解析路径返回 `license=MISSING` 的 descriptor，
  而 preflight 只在交付模式检查 license，预览模式对"文件被移动/删除"完全静默。
- 修复：`license == AssetLicenseStatus.MISSING` 时在两种模式下都追加
  `code="missing_file"` 的 issue（非阻断诊断，预览可继续）；交付模式叠加保留原有
  `license_blocks`。`AssetPreflightIssue.code` 注释同步补 `missing_file`。
- 连带测试更新（锁定旧行为协议）：`tests/core/test_w5_audio_composition.py::
  TestLocalAssetProvider::test_escape_and_missing_are_diagnosed` 原断言交付模式 issue
  恰为 `{"license_blocks"}` —— 该断言锁定的正是本条缺陷（缺失文件在交付模式只报
  license、预览零报告）。按修复后的预期行为更新为
  `{"license_blocks", "missing_file"}` 并补预览模式断言。缺陷本身即计划表条目要求
  的新诊断，属"旧断言=旧缺陷"情形。

### AUD-27309 — 裁剪后 fade_in+fade_out 超剩余时长触发 ValueError [FIXED]

- 位置：`core/audio_plan.py` `AudioRenderPlan.to_timeline`（原 151-158 行）。
- 根因：两 fade 各自 clamp 到 `duration`，但未联合约束；`replace` 重跑
  `__post_init__` 的 `fade_in+fade_out <= duration_frames` 校验即崩。
- 修复：独立 clamp 后若 `fade_in + fade_out > duration`，按
  `fade_in = min(fade_in, duration // 2)`、`fade_out = min(fade_out, duration - fade_in)`
  联合压缩（证据报告建议方案），合法计划在任意窗口裁剪下不再崩溃。
- 测试：60 帧窗口（50+50 fades）、61 帧奇数窗口、未裁剪原值保留三组。

### AUD-27311 — steps 模板 `columns` 参数静默失效 [FIXED]

- 位置：`core/builtin_templates.py` `_build_steps`（原 175 行 `columns = min(len(parsed), 4)`）。
- 根因：ParamSpec 声明了 `columns`（0=auto），构建函数从未读取。
- 修复：读取 `int(params.get("columns") or 0)`，`>0` 时采用并 clamp 到
  `[1, len(parsed)]`；`<=0`/转换失败回退原 auto 逻辑（`min(len(parsed), 4)`）。
  转换防御覆盖从持久化 TemplateInstance 恢复（无 schema 校验）的非常型值。
- 测试：columns=2 时第 3 张卡换行；columns=0/-3 保持 auto；columns=9 clamp 为单行两列。

### AUD-27401 — detach 将持久化 override 键未校验直传 replace [FIXED]

- 位置：`core/commands.py` `DetachComponentInstanceCommand.apply`（原 813 行）。
- 根因：override 键来自磁盘场景文件（外部数据），`element_id` 键会改写元素身份，
  未知键让 `dataclasses.replace` 抛难定位 TypeError，detach 中途失败。
- 修复：新增共享校验 `_validate_element_update_keys(updates)`（与
  UpdateElementCommand 相同的 `set(updates) - _ELEMENT_FIELDS` 白名单 +
  ValueError），detach 在构建 patch 前调用；`element_id` 不在白名单内即被显式拒绝。
- 测试：脏 override（含 `element_id` 键）detach 抛 `ValueError`；干净 override 仍正常烘焙。

### AUD-27402 — master/override 更新键缺白名单 [FIXED]

- 位置：`core/commands.py` `UpdateComponentMasterCommand.apply`（原 1061/1078-1081 行）
  与 `SetComponentOverrideCommand.apply`（原 1136 行）。
- 根因：两处 updates 直接进 `replace()` 或写入持久化 overrides，键无校验；脏键经
  AUD-27401 路径放大。
- 修复：同一 `_validate_element_update_keys` 在三个写路径统一执行——master 更新
  （传播分支复用同批键，一次校验覆盖）、override 写入（持久化边界）。非 Mapping 的
  update 项维持原有的静默跳过语义（与 detach 的 isinstance 分支一致）。
- 测试：master 未知键/身份键、override 身份键均拒绝；合法 master 更新仍向实例传播。

### AUD-27412 — keep_aspect 混合模式仍拉伸 [FIXED]

- 位置：`core/constraints.py` `resolve_constraint_transform`（原 116-139 行）。
- 根因：keep_aspect 只统一了 sx/sy 系数，但非 "scale" 轴的几何不乘系数——
  horizontal="scale" + vertical="top" 时宽缩高不缩，纵横比被破坏，与模块 docstring
  "never stretch" 矛盾。
- 修复：`uniform` 在 keep_aspect 且任一轴为 scale 时作用于两轴尺寸；非 scale 轴的
  pin 规则改为针对"缩放后的盒子"保持其文档化锚点——left/top 保持距原点距离
  （x/y 不变）、center 保持中心偏移（`x + delta/2 + (w - w')/2`）、right/bottom 保持
  距远边距离（`x + delta + (w - w')`）。双轴 scale 行为与之前完全一致。
- 测试：1920x1080→1080x1920 下 scale+top（225x225、y 保持）、scale+bottom（远边边距
  精确保留）、left+scale（左缘保持）、双 scale 回归不变。

### AUD-27415 — resolve_value 无环检测 + getattr 任意属性 [FIXED]

- 位置：`core/design_tokens.py` `DesignTokenSet.category/resolve_value`（原 37-48 行）。
- 根因：token 数据来自场景 metadata 与品牌主题包（外部数据）。(1) 引用环
  （a→b→a）无限递归 RecursionError，渲染/主题切换整体崩溃；(2) `category()` 用
  getattr 暴露任意实例属性，`$to_dict.x` 使 `key in cat` 抛 TypeError。
- 修复：`category()` 改为显式类别白名单
  `{palette, type_scale, spacing, radius, shadow, motion}`（`_TOKEN_CATEGORIES`），
  白名单外返回空 mapping；`resolve_value` 改为迭代解析 + visited 集合——环或超长链
  退化为"未解析引用原样返回"（与既有 unresolved 语义一致），不再递归。
- 测试：互环/自环/畸形类别（`$to_dict.x`、`$__class__.x`）/正常链/普通值透传。

### AUD-27505 — 交付许可只查链中第一个可解析字体 [FIXED]

- 位置：`core/font_registry.py` `FontRegistry.resolve_chain`（原 157-173 行）。
- 根因：`blocks` 仅由 `chosen`（链中首个可解析字体）的 license 决定；实际供字的
  后继回退字体（如 PREVIEW_ONLY 的 CJK/emoji 字体）许可未被检查，受限字形流入交付物。
- 修复：对链中每个实际贡献了字形的字体（`covers & unresolved` 非空）检查许可，任一

- 测试：OPEN 拉丁 + PREVIEW_ONLY CJK 回退 → 阻断；OPEN + EMBEDDED → 不阻断；
  未贡献字形的受限回退 → 不阻断。

### AUD-27513 — from_dict 信任外部 sanitizer_hash [FIXED]

- 位置：`core/html_layer.py` `FreeformHtmlMotionLayer.from_dict`（原 188 行）。
- 根因：`__post_init__` 仅在哈希为空时推导；`from_dict` 原样接受工程文件任意值，

- 测试：伪造哈希被重算覆盖；正确哈希保留；round-trip 一致。

### AUD-27601 — page_timing_for float 转换无防御 [FIXED]

- 位置：`core/html_page_deck.py` `page_timing_for`（原 511-517 行）。
- 根因：`default_seconds`/`durations_seconds` 直接 `float()`，`"abc"` 即抛
  ValueError 击穿场景加载/导出/undo 链路；同函数 transition_seconds 却有完整防御。
- 修复：新增 `_safe_page_float(value, fallback)`（`float()` 失败回退 +
  `math.isfinite` 拒绝非有限值），default 与逐项 durations 均走该函数；坏 duration
  项退化为 0.0 后被 custom-mode 门槛拒绝、回退 default 模式。`page_count` 的 int
  转换一并加 try/except（同类缺陷，同函数首行）。
- 测试：`default_seconds: "abc"` 回退默认值；`durations_seconds: [3.0, "bad"]` /
  非列表容器回退 default 模式；合法 custom 时序不受影响。

### AUD-27602 — 数值校验拦不住 NaN [FIXED]

- 位置：`core/html_page_deck.py` `PageDeckTiming.__post_init__`（原 331-339 行）与
  `page_timing_for` 回退逻辑（原 512-514 行）。
- 根因：`<= 0` 对 NaN 恒 False（NaN 为真值绕过 `or fallback`），NaN 时长经
  `page_start_frame` 的 `round(NaN)` 抛 ValueError，整份项目无法加载。
- 修复：`__post_init__` 对 default_seconds/transition_seconds/durations_seconds 用
  `math.isfinite` + 符号联合校验（显式 ValueError）；读取侧由 AUD-27601 的
  `_safe_page_float` 在进构造前拦截（NaN/inf 回退）。
- 测试：NaN default / NaN custom 项 / NaN transition 构造均拒；
  `{"default_seconds": nan}` 元数据回退后 `page_start_frame` 正常工作。

### AUD-27705 — overwrite 导入非原子 [FIXED]

- 位置：`core/motion_graphic_template_store.py` `import_template_folder`（原 168-174 行）
  与 `_atomic_copytree`。
- 根因：overwrite 路径先 `shutil.rmtree(destination)` 再复制，复制失败（磁盘满/IO
  错）只回滚 tmp，旧模板已不可恢复——违背模块 docstring 的原子写承诺。
- 修复：`_atomic_copytree` 增加 `replace_existing` 参数，经新的
  `_replace_destination_atomically` 完成交换：旧包先 rename 为同目录隐藏备份
 （`.name.old-<uuid>`）→ 新包 rename 入位 → 成功后才 rmtree 备份；中途失败且
  destination 缺失时把备份 rename 回原位。`import_template_folder` 不再预 rmtree，
  `overwrite=False` 时既有拒绝语义不变。
- 测试：monkeypatch `copytree` 抛 OSError 模拟复制失败 → 异常抛出且旧包完整可加载；
  正常 overwrite 内容更新成功；无 overwrite 旗标仍拒绝。

### AUD-27706 — zip 导入无总量/条目上限 [FIXED]

- 位置：`core/motion_graphic_template_store.py` `import_template_zip`（原 193-211 行）。
- 根因：`extractall` 对解压后总字节数与条目数无限制，高压缩比 zip 炸弹可先写满磁盘，
  库内的逐文件尺寸上限只在解压完成后生效。
- 修复：解压前预检 `zf.infolist()` 条目数（`_MAX_ZIP_ENTRIES = 512`）与
  `sum(info.file_size)` 总量（`_MAX_ZIP_TOTAL_BYTES = 64 MiB`），超限抛
  TemplateStoreError（消息含实际值与上限）；条目遍历复用同一 infolist。
- 测试：600 条目 zip 拒绝；monkeypatch 总量上限 128B 后 512B 条目拒绝；
  小型合法包 zip 正常导入。

### AUD-27717 — SetBrandThemeCommand 整档重编译丢弃模板后编辑 [FIXED]

- 位置：`core/template_commands.py` `SetBrandThemeCommand.apply`（原 87-96 行）。
- 根因：模板场景重编译返回全新 TeachingSceneDocument，只回填 template_instance/

  模板元素、cues/markers/pages/asset_refs/html_layer 及 metadata 键全部保留；
  metadata 取 `{**recompiled.metadata, **scene.metadata, instance, brand_theme}`
  （场景侧键优先，模板键兜底）。undo 语义不变（整场景前态）。
- 测试：追加元素 + cue + 自定义 metadata 键在重主题后全部存活，模板元素确实换上新
  token 色（#ff0000），instance 仍可再编译；用户删除的模板元素保持删除；undo 复原。
