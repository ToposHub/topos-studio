## AUD-17700 [Major/risk] run() 初始化异常不发 failed 信号，clip 缓存渲染永久锁死

**状态：FIXED**

**根因**：fps 解析、缓存目录创建（os.makedirs）、编码器构造全部在主 `try:` 之前执行；
`_parse_fps` 只捕获 `(ValueError, IndexError)`，`timeline_fps=None`（from_dict 对
`"timeline_fps": null` 透传）时 `'/' in fps_str` 抛 TypeError，非法/锁定路径时
makedirs 抛 OSError——异常直接逃出 `run()`，541-544 的
`except → encoder.abort() → failed.emit` 永不执行；控制器 inflight 登记只在
failed/finished_ok 回调清除 → 本会话内该 clip 每次请求都返回 "already rendering"。

**修复**（render_cache_worker.py）：
1. 初始化段（388-414）整体纳入独立 try/except，任何失败
   `failed.emit(cache_id, "Render cache init failed: ...")` 后 return——run() 的
   每条退出路径现在都发出终止信号。
2. `_parse_fps` 增加 None/非字符串强制转换（`str(fps_str) if fps_str is not None
   else ""`）并把 TypeError 加入捕获列表——畸形 fps 回退 (24,1) 而非击穿。
3. `encoder` 改为 `RenderCacheEncoder | None` + 前置 assert，主 except 的
   `encoder.abort()` 语义不变。

测试：`TestAud17700`（_parse_fps 容错 ×4 断言 + makedirs NotADirectoryError 时
failed 恰好发出一次且带 init 语义消息）。

## AUD-17801 [Major/bug] apply_splits 不去重相同 timeline_frame，宏执行回滚失败

**状态：FIXED**

**根因**：`_filter_split_candidates` 只过滤不去重；源帧→时间线帧映射（跨 fps/变速
圆整）非单射，两个 accepted 候选落到同一 timeline_frame 时第二条
SplitClipCommand 在开区间校验处抛 ValueError，MacroCommand 回滚全部已应用子命令
后裸抛——用户"全部应用"整体失败。detect_conflicts 已把 duplicate_splits 列为
冲突，apply 侧却无对应处理，两条路径行为不一致。

**修复**（apply_ops.py `apply_splits`）：在过滤与排序之间按 `timeline_frame` 去重
（保留 confidence 最高者，平局取先到），去重时向 `warnings` 追加
"Merged N duplicate split position(s)"——与 detect_conflicts 的 duplicate_splits
语义对齐，且不再有同帧第二条命令。

测试：`TestAud17801`（3 候选含 1 组同帧 → split_count==2、命令数==位置数、
warning 含 duplicate；无重复时无 warning）。

## AUD-17810 [Major/bug] load_analysis 未捕获 ValueError，击穿 "invalid → None" 契约

**状态：FIXED**

**根因**：缓存文件属外部数据；`SceneCutAnalysis.from_dict` 对未知枚举值
（`SceneCutKind(data.get("kind", ...))`）与 `__post_init__` 越界校验抛 ValueError，
不在 load_analysis 的 `(JSONDecodeError, KeyError, TypeError, OSError)` 捕获列表内。
当前唯一调用方用宽泛 `except Exception` 兜底掩盖（本身违反铁律），新调用方按
docstring 使用即崩溃。

**修复**（cache.py `AnalysisCache.load_analysis`）：在 JSONDecodeError 之后追加
`except ValueError` 分支（JSONDecodeError 是其子类，顺序保证精确分支优先），
记录 error 日志后返回 None——契约恢复，调用方可收敛为窄异常。

测试：`TestAud17810`（未知 kind / 越界 sensitivity 两类损坏 JSON → None）。

## AUD-17902 [Major/bug] 检测失败被转换为"成功完成的空结果"

**状态：FIXED**

**根因**：docstring 契约声明 `Raises: RuntimeError: If detection fails`，实际
except 分支返回空候选 analysis；worker 对返回值只判 is_cancelled 便
completed.emit——解码失败显示为"完成、0 个切点"，违反"不得宽泛 except 掩盖领域
错误"铁律。

**修复**（detector.py）：except 分支记录 diagnostics["error"]、上报 ERROR 相位后
`raise RuntimeError(f"Scene cut detection failed: {e}") from e`；worker 的
`except Exception → error.emit(classify_error(e))` 完整通道随即生效（该通道
本来就在，只是从未被触发）。

测试：`TestAud17902`（stub 采样器抛 RuntimeError("decoder exploded") →
detect() 抛 "Scene cut detection failed"）。

## AUD-17910 [Major/bug] 自适应阈值只反映"片尾最后 30 帧"统计

**状态：FIXED**

**根因**：第一遍循环把全部帧分数灌入 RollingStats（滑窗只留最后
window_size 个），随后用该终态窗口求出的单一 threshold 应用到第二遍全片所有帧
——阈值实际由片尾 30 帧决定，与类文档 "Rolling median/MAD dynamic threshold"
不符：片尾密集则前段漏检、片尾安静则前段误检。

**修复**（filters.py `process`）：删除第一遍全量统计；第二遍主循环内逐帧
`threshold = rolling_stats.get_threshold(sensitivity)` 后再
`update(当前帧分数)`——当前帧不参与自身阈值（窗口 <5 样本时 get_threshold
自动回退固定公式，即滚动预热）；`diagnostics["threshold_value"]` 记录最后一帧
的滚动阈值。`_apply_guards` 与 moderate-margin 判定随 per-frame threshold
联动。

测试：`TestAud17910`（构造"前 30 帧低分+第 5 帧 0.65 尖峰+后 30 帧 0.9 高分"
序列：文档化旧行为阈值=clamp 后 0.7 会漏检 0.65 尖峰；新实现检出
source_frame==5；且末帧阈值 >0.5 证明阈值逐帧滚动而非单一值）。
既有 xfail 容差锁测试（test_scene_cut_false_positive_guards.py 21 项）全部
通过、未改动。

## AUD-17920 [Major/bug] start>0 时 seek 丢弃起始帧且 source_frame 整体错位一格

3. `open()`/`close()`/seek 失败回退/`sample_single_frame` 重置迭代器时同步清空

测试：`TestAud17920`（start=10/end=15：sample_frames 产出 source_frame

## AUD-18110 [Major/bug] _cfr_source_to_timeline 反向分支忽略 fps 换算

**状态：FIXED**

**根因**：非反向路径为 `relative × timeline_fps / (source_fps × speed)`，反向
路径 timeline_fps 约掉后只剩 `relative_reversed / speed`，丢失
`timeline_fps/source_fps` 因子；而逆方向 `_cfr_timeline_to_source` 反向分支按
source_fps 换算——两个方向互为不一致的函数，反向+fps 转换（23.976→24）时误差
≈relative×0.001 帧，约 1000 帧处即达 1 帧容差边界，违反模块
"Mapping error should never exceed 1 frame" 承诺。

**修复**（timeline_mapping.py `_cfr_source_to_timeline`）：反向分支复用正向换算
链——`relative_source_reversed` 先除以 source_fps（缺失时回退 timeline_fps）
得秒，除以 speed，再乘 timeline_fps；与逆向映射重新对称。

测试：`TestAud18110`（源帧 0 → 2399 而非旧值 2397 且 error<0.5；5 个采样点
source→timeline→source 往返误差 ≤1 帧；源尾帧 2397 → timeline 0）。
