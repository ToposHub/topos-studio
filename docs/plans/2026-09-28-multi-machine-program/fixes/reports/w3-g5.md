## 1. AUD-18900 — FIXED（Critical/risk/M）

**位置**：`src/features/edit/core/timeline_preview_renderer.py:430-502`（原 447-470）。

**根因**：`acquire()` 的 `closed` 检查与 `inflight += 1` 之间、以及 `retire()` 的
`closed = True` 与 `inflight` 判定之间均无锁。UI 线程 `_clear_direct_preview_sources()`
（经 `set_viewport_size` / `set_preview_quality` / 时间线重建 / `render_cache_worker.py:331`
触发）恰在 worker 通过 closed 检查后、递增 inflight 前 retire，会看到 `inflight==0` 并立即
`source.close()`，随后 worker 对已释放的 PyAV 容器 `read_frame()` → avcodec 段错误
（即该类 docstring 自述的 ~1/3 复现场景）。

**修复**：
- `__slots__` 增加 `_lock: threading.Lock`（模块已 `import threading`）与
  `_source_closed: bool` 幂等标记；
- `acquire()`：closed 判定 + inflight 递增持锁原子（check-then-act 消除）；
- `retire()`：置 closed + inflight 判定持锁；`release()`：递减 + 是否释放判定持锁；
- `source.close()` 统一走 `_close_source()` 在**锁外**执行（避免 C 层 close 阻塞
  acquire），`_source_closed` 保证全生命周期只 close 一次（重复 retire / 多余
  release 均不二次关闭）。

## 2. AUD-19000 — FIXED（Critical/bug/M）

**位置**：`src/features/edit/core/timeline_render_plan.py:1435-1443`
（`build_direct_topos_delivery_plan`，fades 检查之后、资产判定之前）；docstring
条件清单同步补「无关键帧动画（animated_params）」。

**根因**：渲染路径按 `clip.get_param_at_frame` 逐帧求值，关键帧优先于静态值
（`timeline_v2.py:770-778`；`with_keyframe_added` 只更新 `animated_params` 不改静态
`opacity`/`transform` 字段）。eligibility 只比对静态字段——带 opacity/transform 动画
但静态值恒等的 clip 通过判定，直通成品静默丢失全部动画。违反 `.clinerules`
「直通判定必须穷尽动画参数」。

**修复**：
```python
if getattr(clip, "animated_params", None):
    return None, "animated_params_present"
```
穷尽语义（任意动画键，不限于 opacity/transform.*）+ `getattr` 兜底缺属性的外部构造
clip；无动画（属性缺失/空 dict）不误伤快路径（有对照正例测试）。

## 3. AUD-12600 — FIXED（Critical/bug/M）

**位置**：`src/features/edit/adapters/fcpxml_adapter.py:70-88`（解析）、`:362`
（导出 frameDuration 写点）。

**根因**：FCPXML `frameDuration` 是**每帧的秒数**（24fps → `100/2400s`、
NTSC 29.97 → `1001/30000s`），旧代码把帧率 Rational 原样当 frameDuration 写
（`30000/1001s` ≈ 30 秒/帧），解析时也把 `100/2400s` 读成 `Rational(100,2400)`
（to_fps≈0.0417）——真实 FCP 文件导入的所有帧号偏差约 576 倍，导出文件帧率错误。
自产自读往返恰好自洽，掩盖缺陷。

**修复**：
- `_fcpxml_frame_duration_to_fps(fd)`：帧时长→帧率倒数换算
  `Rational(per_frame_den, per_frame_num)`（`Rational.__post_init__` 自动约分，
  `100/2400s` → 24/1）；非正时长显式 `raise ValueError`（调用方既有 try/except
  保持默认 24fps 降级，错误码问题属 AUD-12605，不在本批范围）；
- `_rational_to_fcpxml_frame_duration(fps)`：写 `f"{fps.den}/{fps.num}s"`
  （30000/1001 → `1001/30000s`）；
- `_time_to_frames` 重写为精确整数有理数运算
  `(t_num * fps.num) // (t_den * fps.den)`（floor 语义，负数也正确），消除旧
  `float(seconds) * fps.to_fps()` 在 NTSC 帧率下的浮点帧偏移（如
  `1001/30000s`@29.97 可能算出 0 帧）。

## 4. AUD-12601 — FIXED（Critical/bug/M）

**位置**：`src/features/edit/adapters/fcpxml_adapter.py:119-138`。

**根因**：旧实现 `f"{frames * fps.den}/{fps.num * fps.den}s"` 分母多乘
`fps.den`，结果 = `frames/fps.num` 秒：整数帧率（den=1）侥幸正确，NTSC
（den=1001）所有 offset/duration/tcStart 缩小约 1001 倍，导出文件不可用。

**修复**：`seconds = frames * fps.den / fps.num`，输出前 `math.gcd` 约分到最简
（3000 帧@30000/1001 → `1001/10s`）；`frames == 0` 输出 `0s`。
