## 关键实现说明

### AUD-25206 增量缓存的安全性（canvas.py）

作废判据是「前缀逐项同一对象 + 长度不减」，实时绘制路径
（`on_brush_stroke_added` → `brush_shape.brush_strokes.append(stroke)`）
原地 append 天然满足；引擎重建列表（撤销/重做反序列化产生新 dict）时
身份校验失败 → 安全回退全量重建（即修复前行为），正确性优先。
追加笔触超出旧包围盒时先做 bbox 并集再作废缓存图像，避免「bbox 已变
而 `_rendered_strokes_count` 未复位」导致的丢笔触。

### AUD-25207 直接绘制回退（canvas.py）

直接路径不使用 `CompositionMode_DestinationOut`（会在视图 backing
store 上打洞擦掉图像本身），橡皮擦笔触以蓝色区分显示；这是超预算/内存
不足时才走的预览回退，语义正确性以缓存路径（DIRECTION_OUT 局限于
独立 QImage）为准。

### AUD-25208 状态源拆分（canvas.py）

mask 按钮的信号链（`mask_btn.toggled → mask_toggled →
Canvas._on_mask_preview_toggled → engine.set_mask_preview_mode`）写的是
matte 预览，故回填读 `engine.show_mask_mode`；`_show_mask_overlays`
（覆盖层可见性）与按钮彻底解耦。split 按钮同样补 blockSignals。

### AUD-25501 选中保持（mask_panel.py）

三层优先级：显式选中请求（`select_shape` 记录，含控制器在延迟重建前
对新形状的选中）> 原选中项恢复（blockSignals，无副作用重发）>
自动选末项（保持「新增窗口」场景 UX，会发 shape_selected）。
