## 逐条结论

### AUD-4603 — FIXED（bake/unbake 冻结 i18n 标题）
`src/features/composite/bake_service.py`

根因：`plan` 只记录标题字符串，unbake 用 `plan.original_title == target.node_title`
决定是否清 `user_label`——对带 i18n 翻译或 `instance_label` 的节点该比较永假，
unbake 后 `user_label` 被固化为当时的翻译标题（user_label 优先级最高，切换语言
失效，且随 to_dict 持久化）。

修复：
- `BakePlan` 新增 `original_user_label: Optional[str]`，`plan_bake` 记录
  `target.user_label` 原值（含 None）。
- `apply_bake_rewrite` 在烘焙节点上持久化 `_bake_original_user_label` 参数
  （"" == 无标签），使跨会话（保存/重载后 unbake）也能精确还原。
- `plan_unbake`：优先读烘焙节点上的记录；无记录的旧烘焙走启发式——剥离
  `(baked)` 后缀后与 `_auto_display_title`（新辅助：临时清 label 计算
  display_title）比较，相等即还原 None，绝不冻结翻译/实例号。
- `apply_unbake_rewrite` 原样恢复 `user_label`（含 None）。

### AUD-48008 — FIXED（Y-only EXR 解码全黑）
`src/features/composite/core/image_loader.py`

根因：两代 OpenEXR 路径的读通道循环只请求 R/G/B(/A)，缺失通道零填充，
Y 数据只用于位深推断，从不读出。

修复：`_decode_exr`（2.x）与 `_decode_exr3_part`（3.x）均加入亮度回退——
R/G/B 缺失且存在 "Y" 通道时，懒读取 Y 平面并广播填充缺失通道（Y 读取失败
降级为零填充并记 warning）。Y-only matte 现在解码为灰度图而非全黑。
测试用注入的伪 OpenEXR/Imath 模块驱动（venv 无 OpenEXR 绑定）。

### AUD-4900 — FIXED（编译器干跑实际变异图）
`src/features/composite/core/layer_stack_compiler.py`

根因：`_project_param` 对已存在的 Merge 节点立即 `set_parameter`（eager 写），
`sync_from_node_graph(repair=False)` 的"干跑"实际改写了活动图参数，且不在任何
undo 事务内。

修复：
- `_project_param` 改为**纯记录**：一律产出 `set_parameter` CompileChange，
  由控制器在 `_apply_changes`（事务内，经 `graph.set_node_parameter` 走锁内
  路径并 bump generation）统一应用；删除已死代码 `_try_set_param`。
- 值未漂移时跳过记录（稳态重编译零 set_parameter 变更），使 sync 干跑不会
  误报 "topology differs"。
- 控制器 `_apply_changes` 既有 set_parameter 分支按序应用（create →
  connect/disconnect → set_parameter），无需改动。

### AUD-4901 — FIXED（opacity 投影落点错位 / Transform 回退未实现）
`src/features/composite/core/layer_stack_compiler.py`

根因：链拓扑 `m0(fg=root0, bg=root1) → m1(fg=m0, bg=root2)` 中 Merge 的
opacity 只调制 fg（shaders.py:380）；旧代码把 `layer[i].opacity` 写到
`merge[i]`——中间层(i≥1)的 opacity 因此调制"上方整组"，底层与单层栈无投影
目标，docstring 承诺的 root 回退不存在。

修复（受锁定测试 `test_three_layers_two_merges_correct_order` 约束，不能改
拓扑）：
- 顶层（live 链 i==0 且有 merge）：opacity/blend/matte → merge[0]（fg ==
  root(l0)，语义正确，保持既有行为）。
- 其余层（中间层、底层、单层栈）：**不再**写 group 调制性的 opacity 到
  merge[i]（消除"调暗 B 连带调暗 A"）；blend/matte 仍按 layer_model 契约投影
  到 merge[i]（"与下一层结合的 Merge"）。
- 新增 `_project_root_opacity`：root 声明 opacity 支持
  （`supports_layer_opacity` ClassVar / PARAM_DEFS 含 opacity / 参数表已含
  opacity）时投影到 root 节点；否则 opacity≠1.0 的层记 warning（可定位），
  不再静默假装生效。
- 重写方法 docstring 如实描述映射（doc-gap 面）。

已知残余（记录，非本批可解）：TransformNode 未声明 opacity 参数（transform
求值器也无对应 uniform），故 Transform-rooted 中/底层 opacity 目前为
"报告 warning + 无渲染效果"，优于旧的错误渲染（连带调暗上方组）；完整解需
TransformNode/求值器扩展（不在本批白名单内）。

### AUD-4906 — FIXED（duplicate Precomp 共享 child_stack_id）
`src/features/composite/core/layer_stack_controller.py`

根因：`_clone_node` 经 to_dict/from_dict 原样复制 PrecompNode 的
`child_stack_id`，复制的 Precomp 与原层别名同一子栈；删除任一层会拔掉对方的
子栈。

修复：`duplicate_layer` 对 `layer_type == precomp` 走专门分支——新增
`_duplicate_layer_stack_tree`：深拷贝子栈树（逐层克隆 source/root 节点、重接
source→root 内部连线、Layer 换新 id 并重映射同栈 parent/matte 引用、嵌套
Precomp 递归），新栈 output 指向克隆的边界节点，克隆节点参数写回新
child_stack_id；子栈缺失时降级告警；失败路径整体回滚（栈 + 克隆节点）。
新栈 merge 链由 `_recompile` 的递归编译重建。

### AUD-4907 — FIXED（嵌套层操作锚定 main 栈）
`src/features/composite/core/layer_stack_controller.py`

根因：`set_layer_property` / `set_layer_parent` / `move_layer` /
`duplicate_layer` 全部 `stack = self.main_stack()`，嵌套栈层的 parent/track
matte 校验对着 main 的成员表必然失败，move/duplicate 对嵌套层直接拒绝。

修复：四处统一改为 `stack = self._stack_for_layer(layer_id) or
self.main_stack()`（与既正确的 `set_layer_track_matte` 同型）；校验、递归
编译、undo 与 emit_changed 全部作用于真实所属栈。

### AUD-5000 — FIXED（node_graph_cycle 死代码）
`src/features/composite/core/layer_stack_validator.py`

根因：`topological_sort()` 有环时 raise ValueError（Kahn 算法，从不返回部分
列表）；旧代码 `except Exception: order=None` + `order is not None and ...`
使环检测分支永假（假阴性），且宽泛 except 掩盖一切非环异常。

修复：`except ValueError` → 报 `node_graph_cycle`（ERROR）并返回；其余异常
单独捕获报 `topology_check_failed`（WARNING，可定位）；保留部分列表分支作
防御性兜底并注释其当前不可达性。

### AUD-5004 — FIXED（音频误分类为 image）
`src/features/composite/core/media_drop_payload.py`

根因：`MEDIA_TYPE_AUDIO` 定义后从未返回；别名表与扩展名兜底均无音频分支，
音频资产 → media_type="image" → 创建指向 .wav/.mp3 的 image_input 坏图层。

修复：
- `_classify_media_type`：新增 audio 别名（audio/sound/music/snd）与
  `AUDIO_EXTENSIONS`（.wav/.mp3/.m4a/.aac/.flac/.ogg/.opus/.aiff/.aif/.wma）
  扩展名分支，返回 `MEDIA_TYPE_AUDIO`。
- `resolve_drop_payloads`：出口统一过 `_reject_audio_payloads`（资产解析与
  路径兜底两条路径都覆盖），音频拖放被拒绝并记 warning（可定位）。
- `MediaDropPayload.node_type` 对 audio 显式 raise ValueError（防御直接构造
  者绕过 resolve 层）。

### AUD-5008 — FIXED（插件节点能力查询返回 None → placeholder）
`src/features/composite/core/node_capabilities.py`

根因：`get_node_capability` 表未命中立即 `return None`，与 docstring 声称的
"先查 NODE_REGISTRY 再合并类属性"不符；`register_plugin_nodes` 注册且未手写
进静态表的类型被调度器归为 placeholder 而不渲染。

修复：表未命中时回退 `NODE_REGISTRY`——新增
`_synthesize_registry_capability`：尊重 `IS_PLACEHOLDER` 类约定，否则合成
保守 effect 能力（action="effect"、effect_type=自身、owns_color_texture=True、
category="Plugins"）；docstring 重写为与实现一致的四级解析顺序。真正未注册
类型仍返回 None（is_placeholder 语义不变）。

### AUD-5100 — FIXED（remove_node_and_reconnect 缺表达式/绑定/父子清理）
`src/features/composite/core/node_engine.py`

根因：该删除主路径只 `del nodes` + 剥连接 + GroupNode 解引用，缺
`remove_node` 具备的 `_expression_manager.remove_node`、其它节点指向被删
节点的 `parameter_bindings` 清理、子节点 `parent_id` 置空。

修复：抽出共享清理 `_detach_node_references_unlocked(node_id, node)`，
`remove_node` 与 `remove_node_and_reconnect` 统一走它（语义与
ExpressionManager 的"保留指向被删 id 的依赖边"设计一致——表达式自身归属
被删节点的被清除）。

### AUD-5101 — FIXED（剥离连接后才标脏，空操作）
`src/features/composite/core/node_engine.py`

根因：`_mark_dirty_downstream(node_id)` 沿 `src==node_id` 的边传播，但调用
点在连接过滤之后——被重连的下游节点 `_dirty` 保持 False。

修复：`_mark_dirty_downstream(node_id)` 移到连接剥离**之前**（边尚完整时），
被重连消费者现在被正确标脏（`_force_full_eval` 之外的增量求值方不再看到
陈旧清洁态）。

### AUD-5102 — FIXED（evaluate() 无锁遍历）
`src/features/composite/core/node_engine.py`

根因：主循环 `self.nodes[node_id]`、`get_input_connections` 逐次取锁外的
节点/边访问与 UI 线程增删节点竞争（KeyError / 撕裂读）。

修复：循环前在 `self._lock` 内一次性快照 `eval_order`、`nodes_snapshot`、
`incoming_index`（入边索引），循环内全部走快照（`.get` 代替下标）；单节点
求值仍在锁外（避免跨 GPU 工作持锁饿死访问器）。docstring 明确"调用方仍须
单线程；_dirty 与求值缓存归求值线程所有"。

### AUD-5103 — FIXED（to_dict/validate/migrate_* 无锁）
`src/features/composite/core/node_engine.py`

修复：`to_dict`（全序列化，含 deepcopy）、`validate`、
`migrate_color_input_to_topos_color`、`migrate_output_format_mode` 全程持
`self._lock`（RLock，与内部 topological_sort/get_input_connections 重入兼容）；
migrate_* 维持 generation/`_force_full_eval` 记账。

### AUD-5104 — FIXED（from_dict 直接索引连接字段）
`src/features/composite/core/node_engine.py`

修复：加载循环对 nodes/connections 容器做 list/tuple 类型检查（否则告警忽略）；
逐条目：非 dict 条目跳过 + warning；连接四字段逐一 `isinstance(str)` 且非空
校验，非法跳过 + warning；`connect()` 返回 False 记 warning（坏引用可定位，
如指向缺失节点/端口）。损坏数据不再以 KeyError/AttributeError 中断整个工程
加载，合法部分照常载入。

### AUD-5105 — FIXED（groups/viewport/viewer 引用别名 + 无验证）
`src/features/composite/core/node_engine.py`

修复：新增 `_load_groups`（仿 `_load_backdrops`）：deepcopy + dict 检查 +
`node_ids` 规范化为字符串列表（`get_group_for_node` 等成员访问器不再
KeyError）；`viewport_state`/`viewer_state` 改为 isinstance(dict) 校验 +
deepcopy，非法类型告警忽略——图状态与调用方字典不再共享引用。

### AUD-5200 — FIXED（应用级插件目录解析错误）
`src/features/composite/core/node_plugin.py`

根因：`Path(__file__).parent³` 只到 `src/features`，应用级目录被解析为不存在
的 `src/features/plugins/node_plugins`；仓库真正的 `plugins/node_plugins/`
（含 posterize/vintage 示例插件）永不扫描。

修复：改用仓库约定风格 `Path(__file__).resolve().parents[4]`（本文件位于
`<root>/src/features/composite/core/`，parents[4] == 仓库/应用根），目录经
测试断言存在且含自带插件。

注（超出本批白名单的既有事实，未改动）：仓库自带两个示例插件自身 import
的是重构前路径 `from src.composite.node_plugin import ...`（`src/composite`
已不存在），目录修复后它们会以可定位的 ImportError 记录在插件错误表中，
仍不会被注册——需另行修（`plugins/node_plugins/*.py` 不在本批白名单）。
