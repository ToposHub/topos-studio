## 逐条明细

### AUD-9504 — FIXED
`__init__` 显式初始化 `self._properties_panel: Optional[Any] = None`（置于 `_node_toolbar = None` 之前）。`on_enter`(1477)、`_on_project_settings_requested` 等绑定前直接读取不再 AttributeError；与既有 `getattr`/`hasattr` 防御点（getter 6207、_on_node_selected 3336）语义一致化。

### AUD-9505 — FIXED
`cleanup()` 开头统一 stop 8 个单发/防抖定时器：`_renderer_retry_timer`、`_eval_debounce_timer`、`_prefetch_timer`、`_param_debounce_timer`、`_batch_param_debounce_timer`、`_minimap_timer`、`_interaction_debounce_timer`、`_nav3d_restore_timer`；清空 `_pending_param_change` / `_pending_batch_param_change` / `_pending_interaction_update`；置 `_is_active = False`。双保险：`_retry_renderer_init`(1537) 的 `not self._is_active` 守卫在 renderer 已置 None 且 inactive 时直接返回，杜绝 cleanup 后 300ms 重建孤儿渲染线程。

### AUD-9506 — FIXED
`load_composite_data` 的 duration/fps 转换改为逐字段 try/except (TypeError, ValueError) + warning 日志 + 回退默认（duration→0，fps→24.0），风格对齐同文件 `set_source_image_size`(1795–1799) 范例。损坏工程文件不再从加载路径抛 ValueError 逃逸 Qt 槽。

### AUD-9600 — FIXED（四层防御）
1. 构造器归一：传入 frame_range 倒置时交换 start/end；
2. 联动钳制：`start_frame_spin.valueChanged`/`end_frame_spin.valueChanged` 互推（升 start 推高 end、降 end 拉低 start，用户最新编辑获胜），`_range_sync_lock` 状态锁防递归（.clinerules 信号防递归约束）；
3. Render 点击兜底：`_on_render_clicked` 对 VIDEO 模式倒置区间弹 `QMessageBox.warning` 并拒绝 accept（绕过 UI 钳制的程序化路径也有提示）；
4. `get_settings()` 输出契约：`end_frame = max(start_frame, end_frame)`，杜绝下游 `composite_render_output.py:1018` 负数总帧数。

### AUD-9700 — FIXED
根因：`_handle_paint_press` 只记录首点、不调 `start_drag`，而 `mouseMoveEvent`(7585) 仅在 `is_dragging` 时分发 `_handle_tool_move`，且 live release 路径从不调 `_handle_tool_release`（7286 行注释确认 per-tool release 有意不走 live 路径）。修复：
- 笔画路径 press 调 `_interaction_state.start_drag(tool=PAINT, ...)` 使 move 可达（不 emit `interaction_started`——笔画走 page 侧 `_on_paint_stroke_committed` 专用 undo 路径，参数管线不介入）；
- `mouseReleaseEvent` drag 结束分支在 emit `interaction_ended` 前对 PAINT/ROI 显式调 `_handle_tool_release(view_pos)`（其余工具维持通用参数路径不变）；
- Alt+click 克隆源设置不进入拖拽态（点击语义）；
- Esc 取消路径同步清 `_paint_drag_points`/`_paint_drag_node_id`。
`paint_stroke_committed` 现可真实发射，page `_on_paint_stroke_committed`(9501) 恢复可达。

### AUD-9701 — FIXED
`_handle_roi_press` 调 `start_drag(tool=ROI, ...)`（同样不 emit interaction_started，ROI 经 `user_roi_changed` 自有提交路径）。move 更新橡皮筋、release 提交 `_apply_user_roi` 或点击快速清除，整链可达。

### AUD-9702 — FIXED
`_compute_uv_at_mouse` 删除重复的全视口居中 letterbox 推导，改为直接复用 `_compute_vertices(vp_w, vp_h, tw, th)`（含 `_content_rect_pixels` 对工具栏/播放条/检查条的扣减 + zoom/pan），与绘制及命中测试路径同源。像素检查器读数不再系统性纵向偏移。

### AUD-9703 — FIXED
`initializeGL` 的句柄重置提取为 `_reset_owned_gl_handles_for_rebuild()`：除 ODT LUT 三元组外，同时清零 `_current_tex_id`、`_owned_display_tex_id/_size`、`_owned_aov_tex_ids/_sizes`、`_owned_secondary_tex_id/_size`、`_owned_secondary_b_tex_id/_size`、`_owned_quad_tex_ids`（保留键清零值）+`_owned_quad_tex_size`、`_copy_read_fbo/_copy_draw_fbo`。上下文重建后所有 owned 资源走按需全新分配路径（旧对象随旧上下文消亡，无需显式删除，符合 GPU 资源约束）。提取方法同时使该逻辑可无 GL 单测。

### AUD-9704 — FIXED
`set_state` 新增 `_restore_float` / `_restore_int` 校验辅助（try/except (TypeError, ValueError) → warning + 回退默认，可选 lo/hi 钳制），覆盖 zoom_level/pan_x/pan_y/channel_mode/exposure/viewer_gamma/display_transfer/display_primaries/tonemap/target_peak/split_difference_scale/magnifier_zoom；`show_bbox_overlay`/`show_format_overlay` 补 bool() 强转。畸形工程数据不再中断 `restore_viewer_state`。

### AUD-9800 — FIXED
`_would_create_cycle` 不再依赖 PortItem 不存在的 `_connections` 属性。改为一次遍历 `scene().items()` 中的 ConnectionItem 构建 {src_node: [dst_node]} 邻接表（DFS 保持线性），再沿其展开。环防护从恒 False 变为真实生效。顺带修正方向推导：与 `_can_reconnect`/`_perform_reconnection` 同源使用 `dragging_src = self._reconnect_src if self._is_reconnecting else self._disconnect_src`（否则修复后 Alt+disconnect 模式方向反置——即证据报告 AUD-9801 指出的被掩盖缺陷，属使 9800 修复正确所必需）。

### AUD-9905 — FIXED
`sample_value_curve` 与 `sample_speed_curve` 改为边采样边裁剪：
- 循环前用与旧实现完全相同的逐次加法跳过窗外前缀（`while f < lo: f += step`），保持输出序列与旧"全跨度生成后过滤"逐位一致（含浮点相位与强制端点样本）；
- 循环上界加 `f <= hi`，整段在窗外的 segment 直接 continue；
- 删除事后全量过滤。

### AUD-9918 — FIXED
