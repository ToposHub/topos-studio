| ID | 状态 | 修复摘要 |
|---|---|---|
| AUD-38302 | FIXED | `set_lut(emit_changed=True)` 的 `changed` 信号被自身 `blockSignals(True)` 吞掉：旧代码在 blocked 区内调用 `_emit_changed_signal()`——Qt 级发射被吞，且 `_pending_lut` 已被置 None，16ms 节流定时器重放时也无事可做，信号永不送达。修复：把即时发射移到 `finally` 恢复 `blockSignals` 之后，先停定时器再同步 flush。 |
| AUD-38303 | FIXED | 点击 hue 曲线端点的 wrap-around 同步只改 `pts[0]/pts[-1]`，未置脏、未重建 LUT，UI 与渲染状态发散。修复：同步真正改动数据时（两端 Y 不一致）置 `_lut_dirty` 并走 `update_lut()`（节流发射 changed，与加点路径一致）；端点已一致时点击不触发无意义重渲染。 |
| AUD-38304 | FIXED | `calculate_curve` 裸 `except:` 违反 .clinerules 且掩盖编程错误。修复：改为 `except (ValueError, IndexError)`（PCHIP 拒绝非单调/退化控制点的 ValueError + 越界 IndexError），其余异常（如 AttributeError/RuntimeError）正常穿透。 |
| AUD-38308 | FIXED | LUT 导入 `shutil.copy2` 失败后仍把指向不存在路径的条目加入图库。修复：`except Exception`（宽泛，违规）改为 `except OSError`，记录含源/目标路径的 error 后直接 `return`，不再添加幽灵条目；成功路径与"源已在 lut_dir"路径行为不变。 |
| AUD-38405 | FIXED | Vectorscope 对 HDR 输入 `np.clip(0,1)` + `max>1.5 一律 /255` 启发式，双重扭曲超白像素色度（HDR 红 (2.4,1.2,1.2) 被压成 (1,1,1) 塌缩为白色；真 HDR 被 /255 压到近黑）。修复：(1) /255 仅在超出 [0,1.5] 的值全部为整数码值且峰值 ≤255（uint8 直接转 float 特征）时走遗留路径；(2) 负值仍截 0（负 RGB 无示波语义，与旧下界一致），超白像素（max 通道 >1）沿常色度射线除以 max(R,G,B) 投影到单位立方体表面——色相与相对色度方向保留（scope 只显示色度不显示亮度）。HDR 数值域不再被无依据钳制。全程产生新数组，不改上游渲染缓冲。 |
| AUD-38406 | FIXED | `np.random.choice(N, k, replace=False)` 对全像素索引全量置换（4K 实测 ~349ms/次，卡 UI 线程）且逐帧重随机致迹线闪烁。修复：新增 `_stable_sample_indices()`——固定种子（`default_rng(0x5EED)`）按 (像素总数, 采样数) 缓存索引集，尺寸变化才重生成（O(k)）；帧间采样点稳定（密度直方图语义下少量重复采样无影响）。 |
| AUD-38600 | FIXED | `sid = segment_id or f"vault_clip_{clip_id}" if clip_id else f"vault_shot_{start_frame}"` 因三元表达式优先级低于 `or`，实际解析为 `(segment_id or ...) if clip_id else ...`——clip_id 为空时调用方显式传入的 segment_id 被静默丢弃。修复：改为显式 if/elif/else 分支（segment_id > clip_id > start_frame 回退）。 |
| AUD-38601 | FIXED | `float(clip.get("relevance", 1.0) or 1.0)`：合法 0.0 被 `or` 误判缺失置为 1.0；非数值令 float() 抛 ValueError 穿透；越界值触发 `SemanticSegment.__post_init__` 域校验 ValueError。修复：新增 `_relevance_to_confidence()`（完整类型注解）：None/缺失/非数值/NaN → 默认 1.0；合法数值（含 0.0）按原值保留；越界钳制到 [0.0,1.0]（confidence 文档域）。三处调用点（clip:74、search_hit image:213、audio:227）全部切换。 |
