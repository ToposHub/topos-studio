## 逐条明细

### AUD-30301 [Major/doc-gap] `_append_validation_background` 用 `document.lower()` 索引切片原文档 — FIXED

- 根因：`str.lower()` 对部分字符改变长度（`'İ'` U+0130 → 2 字符），`lower.rfind("</head>")` 的索引相对原文档偏移，`<style>` 可被插进标签内部，验证探针页面损坏 → 合法场景被误判"捕获为空"。
- 修复：新增模块级 `_CLOSING_HEAD_RE = re.compile(r"</head\s*>", re.IGNORECASE)`，用 `finditer` 取**最后一个**匹配（保持原 `rfind` 的"最后一个"语义）在**原文档**上定位插入点；无匹配时仍前置。`re.IGNORECASE` 保留大小写不敏感匹配，且每个匹配索引都是原文档的合法索引。
- 回归：`test_validation_background_inserts_before_head_with_case_expanding_char`、`test_validation_background_matches_case_insensitive_last_head`（含 `</HEAD >` 变体）、`test_validation_background_without_head_prepends_and_none_is_identity`（None/"" 恒等返回原对象）。

### AUD-30304 [Major/bug] 以异常消息子串（"uniform frame"/"near-uniform"）分类空白捕获 — FIXED

- 根因：空白帧重试判定完全依赖后端异常的英文措辞；消息改写/本地化后合法 uniform 诊断会直接 raise（可重试空白被误判为硬错误），反向地无关异常恰含子串会被静默重试。
- 修复（结构化契约）：
  - `html_scene_renderer_v2.py` 新增 `HtmlBlankCaptureError(HtmlRenderError)`（类属性 `blank_capture = True`）；`HtmlSceneRendererV2.render` 在 `CaptureFailureCode.BLANK` 时抛出该类型（`from None`），其余失败仍抛 `HtmlRenderError`——均为既有 `except HtmlRenderError` 调用点的兼容子类。
  - `html_validation.py` 新增 `_is_blank_capture_error(exc)`：结构化优先（`HtmlBlankCaptureError` → True；`HtmlRenderError`（非空白）→ **False，绝不回退到消息匹配**）；无结构化标记的异常（注入的测试替身/旧渲染路径）保留旧的子串回退。`_capture_one` 改用该分类器。
- 回归：`test_blank_capture_classifier_is_structural`（消息提到 "uniform frame" 的非空白 `HtmlRenderError` 不再被误分类）、`test_gate_retries_structured_blank_capture_without_matching_words`（德文消息的空白捕获仍被重试后聚合为"HTML 验证捕获为空"）、`test_gate_propagates_structured_non_blank_mentioning_uniform`（首个候选即上抛，调用次数 == 1）。

### AUD-30311 [Major/doc-gap] `_html_with_native_overlay` 同样的 lower() 索引偏移（主渲染路径） — FIXED

- 与 AUD-30301 同根因，且该函数在 `HtmlVectorSceneRendererV1Adapter.render_frame` 中**每帧**执行，`</body>` 前存在大小写展开字符时 overlay `<div>` 落进错误偏移，产出错误帧或 fail-closed 报错。

### AUD-30401 [Major/bug] 预合成实例只展开一层，嵌套场景二级实例被静默丢弃 — FIXED

- 根因：`_render_precomp_instances` 只遍历顶层文档的 `scene_instances`，被引用场景自身的 instances 无递归展开路径；仅有的防护是直接自引用跳过。
- 修复：拆分为 `_expand_instances(scene, ...)`（声明级展开）+ `_render_referenced_scene(source, ...)`（单场景内容渲染），后者递归调用前者展开被引用场景自身的实例：
  - **防环**：`visited: frozenset[str]` 按**路径**传递（`visited | {source.scene_id}`），A→B→A 的间接环在回边处跳过；非环菱形引用（A→B→D、A→C→D）D 仍按路径各渲染一次。
  - **深度上限**：`_PRECOMP_MAX_DEPTH = 8`，超限抛 `RuntimeError("precomp instance nesting exceeds 8 levels at instance '…'")`——fail-closed，不再静默丢弃或耗尽栈。
- 回归：`test_precomp_instances_recurse_beyond_one_level`（二级实例 `inst_c`/`c_elem` 出现）、`test_precomp_reference_cycles_terminate_without_dropping_siblings`（环终止且兄弟内容完整、回边实例组不出现）、`test_precomp_depth_cap_fails_closed`（20 级链抛错）。

### AUD-30402 [Major/bug] 遮罩绑定支持实例目标，但渲染实例时从不引用遮罩 — FIXED

- 根因：`_composition_defs` 把 `instance_id` 列为合法遮罩目标并生成 `<mask>` defs 与绑定，但实例 `<g>` 从不查询 `mask_bindings`，遮罩指向实例时输出完全不蒙版的画面。
- 修复：`render_frame` 把 `mask_bindings` 传入 `_render_precomp_instances`；`_expand_instances` 在 **depth==0**（被渲染文档自身的直接实例，即绑定表的作用域）给实例组写 `mask="url(#…)"`。被传递引用的场景自身的遮罩本就不内联 defs（基线行为），维持不变、不产生悬空引用。
- 回归：`test_mask_bound_to_instance_masks_the_instance_group`（`data-instance-id="inst_masked"` 的组带 `mask="url(#mask_m1)"`，defs 含 `<mask id="mask_m1"`）。

### AUD-30404 [Major/perf] 每帧重复磁盘 IO 与 base64；嵌套实例逐帧重建 AssetResolver 并 preflight — FIXED

- 修复（均在渲染器任务实例上，`prepare`/`cleanup` 重置，跨任务不串数据）：
  - `self._data_uri_cache: dict[(scene_id, asset_id), str | None]`：`_render_element` 图片分支查表，未命中才 `resolver.asset_by_id` + `resolver.data_uri`（读盘+base64 一次），父场景与嵌套场景共用；未命中结果（含 None→占位符）同样缓存。
  - `self._nested_resolvers: dict[scene_id, AssetResolver]` + `_resolver_for()`：每个被引用场景构建一次 resolver 并 preflight 一次，不再每实例每帧重建。
- 输出字节不变（同一 resolver 的 data_uri 是确定性的），release fixtures / 缓存哈希不受影响。
- 回归：`test_image_data_uri_resolved_once_across_frames`（4 帧，`AssetResolver.data_uri` 恰被调用 1 次）、`test_nested_resolver_built_once_across_frames`（4 帧，resolver 构造数 = 父 1 + 嵌套 1 = 2）。

### AUD-30501 [Major/risk] 共享协调器惰性初始化无锁 — FIXED

### AUD-30504 [Major/bug] `replace_all()`/`clear()` 后 revision 从 1 重新计数，跨项目可重号 — FIXED

- 根因：`self._revisions[scene_id] = self._revisions.get(scene_id, 0) + 1` 是**每 id 计数器**，清空即归零；项目关闭（`replace_all(())`）后重开同 scene_id 的项目，`scene:<id>:r1` 等缓存键可命中上一项目的陈旧渲染，`module.py` 的 revision 相等性判断也会碰撞误判。
- 修复：改为**进程级单调序列**（模块级 `itertools.count(1)` + `_REVISION_SEQUENCE_LOCK`，`_next_revision()` 原子取号，全部 store 实例共享）：任何 scene_id 在进程生命周期内拿到的 revision 严格递增、绝不重号。`replace_all`/`clear` 后未注册 id 仍查得 0（语义不变）；`register` 的同文档幂等（不取号、不通知）不变。
- 回归：`test_revisions_never_repeat_across_project_switch`（重开项目/清空后 r2>r1、r3>r2，清空后查 0）、`test_revisions_bump_on_change_and_not_on_identity`（同文档不 bump、变更 bump）。

### AUD-30600 [Major/risk] "重新生成预览"在 UI 线程同步渲染整段 GIF — FIXED

- 根因：工具按钮槽内同步执行 `load_preset_scene` + `render_preset_gif`（纯 CPU：场景分辨率 SVG 光栅化 + LANCZOS + GIF 编码，最多 24 帧），主线程阻塞数秒、事件循环停摆、不可取消。
- 修复：`asset_library_panel.py` 新增 `_PreviewRenderJob(QThread)`：load+render 全在工作线程执行，经**队列信号**（`succeeded`/`failed`）回报；槽内即禁用按钮并显示"Rebuilding preview…"状态，完成/失败在 UI 线程刷新缩略图/弹警告，`_finish_preview_job` 统一清引用（`wait()`+`deleteLater`）并按当前选择恢复按钮态。job 不设 parent（面板销毁不触发"running thread destroyed"，Qt 自动断开已销毁接收者的队列投递）；运行中重复点击直接忽略。
- 回归：`test_regenerate_preview_renders_off_ui_thread`（渲染恰 1 次且在工作线程；期间按钮禁用；完成后缩略图刷新、`_preview_job` 清空、按钮恢复）、`test_regenerate_preview_failure_surfaces_off_thread`（异常经队列信号在 UI 线程弹出、状态恢复）。

### AUD-30610 [Major/bug] 自动打点关键帧被已存在窄区间轨道静默钳制 — FIXED

- 根因：`add_keyframe` 的 `min_val`/`max_val` 只在**新建轨道**时生效；AI 路径默认建的 `[0,1]` 轨道上再打 x=850，原始值入库但求值时被 `_clamp_range` 钳到 1.0，静默错动画。
- 修复：存在轨道时**只拓宽不收窄**——`widened_min = min(track.min_val, value[, min_val])`、`widened_max = max(track.max_val, value[, max_val])`：越界值入轨即扩轨（"所见即所渲"），调用方显式界（auto-key 的 ±1e6 宽界）同样并入，后续区间内的打点不缩回已拓宽的边界。
- 回归：`test_keyframe_outside_existing_track_range_widens_the_range`（[0,1] 轨道 + x=850 → max_val=850，`get_value(12)==850.0`）、`test_keyframe_range_widening_respects_caller_bounds_and_never_narrows`（宽界并入 → ±1e6；后续 3.0 不收窄）。

### AUD-30611 [Major/bug] 一次拖拽+自动打点最多拆 6 条撤销记录 — FIXED
