### AUD-16605 — _cleanup 未释放复合纹理缓存/bg·snapshot FBO/program·VAO；成功路径不销毁 shared context/surface 【FIXED】

`edit_gpu_preview_renderer.py:_cleanup`（现 5408 行起）补齐：

1. **复合纹理缓存**（预算 268MB，条目为全分辨率 tex+fbo）：开头调用
   `invalidate_composite_cache()` + `_drain_composite_cache_invalidate()`，
   与运行期失效（1984 行）同一套机制，在 GL 线程释放全部条目。
2. **bg composite / snapshot FBO**：`_bg_composite_tex/_bg_composite_fbo/
   _snapshot_tex/_snapshot_fbo` 逐个 release 并置 None，`_bg_composite_size`
   一并清空。
3. **program/VAO/VBO**：`_yuv_program/_yuv_rect_program/_yuv3_program/
   _grade_program+_grade_vao/_transform_program+_transform_vao/_crop_program+
   _crop_vao/_generator_program+_generator_vao/_blend_program/_blend_vao/
   _quad_vao(别名)/_flip_blend_vao/_yuv2_vao/_yuv_rect_vao/_yuv3_vao/
   _transition_program+_transition_vao/_dip_program+_dip_vao+_flip_dip_vao/
   _snapshot_program+_snapshot_vao/_quad_vbo/_blend_quad_vbo` 全部 release
   （`_full_frame_transition_*` 原已释放）。
4. **辅助 GL 对象**：`_gl_pass_timer.release()`（in-flight timer query）与
   `_yuv_uploader.release()`（PBO/R8/R16UI 纹理池 + program）。
5. **shared context/surface 成功路径销毁**：moderngl `ctx.release()`（需
   ctx current，保持在最前）→ `QOpenGLContext.doneCurrent()` → 亲和性
   `moveToThread(app.thread())` 移回 GUI 线程（渲染线程无事件循环，
   deleteLater 无法就地处理）→ 经新增信号 `_gl_teardown_requested`
   （队列连接，GUI 线程槽 `_teardown_gl_handles_on_gui`）执行
   `ctx.deleteLater()` 与 `surface.destroy()`。QCoreApplication 不存在
   （进程退出中）时跳过，由 OS 回收。

验证：`tests/edit/test_fix_wd11g57_aud.py::TestRendererCleanupReleasesAllResources`
（fake GL 对象注入，断言 31 个属性全部 released、缓存条目释放、timer/uploader
释放、未初始化态 no-op、teardown 信号送达槽）。
