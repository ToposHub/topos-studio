## AUD-16605 [Major/bug] _cleanup 未释放复合纹理缓存、bg/snapshot FBO 与多个 program/VAO；成功路径从不销毁 shared context/surface

**状态：FIXED**

`_quad_vbo`/`_blend_quad_vbo`）；④ `_yuv_uploader`（PBO/纹理池）、
`_gl_pass_timer`（timer query）。且 run() 正常退出路径从不销毁
`shared_pyqt_context`/`surface`。

修复（`_cleanup` 内，全部在 `ctx.release()` 之前）：

## AUD-16900 [Major/bug] iris 半径上限 1.55 在宽幅画幅下盖不住边缘/四角，终点处全帧跳变

**状态：FIXED（GPU 侧；CPU 孪生路径遗留）**

根因：`procedural_mask` 中 `point.x *= aspect` 后坐标域为 x∈[-aspect,aspect]、
y∈[-1,1]，右边缘中点距离=aspect、角点距离=√(aspect²+1)。16:9 时分别为
1.778 / 2.04，均 > 常数上限 1.55——iris 整个过渡过程从未覆盖左右边缘带与
四角（一直显示 outgoing 画面），progress=1.0 被端点早退一次性翻转为全 1，
产生全帧硬跳变。

修复（GPU_TRANSITION_FRAGMENT_SHADER_SOURCE）：
- 圆（kind 1）：`radius = progress * sqrt(aspect*aspect + 1.0)`——半径终值
  恰为角点距离，progress→1 时几何上全覆盖，跳变幅度归零；
- 椭圆（kind 2）：保持 0.62 纵横比，x 半轴终值取
  `sqrt(aspect*aspect + (1.0/0.62)^2)`——代数上恰好把角点 (aspect,1) 收进
  椭圆（(aspect²+1/0.62²)/rx² ≤ 1 取等号）。
- GLSL 严格类型：所有数字带 `.0`。

遗留（白名单外，需后续批次跟进）：CPU 路径 transition_mask.py:136 用同一
常数 1.55（该文件不在本批白名单，未修改）。GPU 预览/headless GL 导出已
修复；CPU 回退/非 GL 导出在宽幅画幅下 iris 仍呈现旧缺陷，且与 GPU 路径
存在 divergence，应同步套用相同画幅自适应公式。

回归：TestAud16900IrisRadiusCoversFrame（shader 源不再含 `1.55 * progress`
且含自适应公式；Python 镜像几何验证：16:9/4:3/2.4 下终点半径 ≥ 角距，
椭圆把角点收进椭圆内，并保留"旧常数 1.55 < 边缘中点距离"的缺陷存在性
证据）。tests/edit/test_transition_mask_gpu.py（6 项）与
test_gpu_transition_preview.py（23 项）邻接运行通过。

## AUD-16905 [Major/risk] _update_integrated 每 hop 全量重扫 _gated_blocks，实时音频路径成本无界线性增长

**状态：FIXED**

根因：每 100ms hop 执行一次 `[z for z in self._gated_blocks if z > relative_gate_z]`
的 Python 列表推导全量重扫；调用方是 audio_playback.py 实时混音路径（每轨
一个 meter），块数随播放时长线性累积——1 小时会话末尾每 hop 每轨约 3.6 万
次解释器级比较，8 轨即每 100ms 十余毫秒音频线程开销，且无上界。

修复（两段式）：
- 音频热路径 `_update_integrated`：只做第一阶段绝对门限检查 + 摊还 O(1)
  追加（`_gated_z` 几何扩容 numpy 缓冲替代 deque）+ 运行和 + dirty 标记；
- 第二阶段相对门限筛选移到 `integrated_lufs` property 读取时惰性计算
  （`_recompute_integrated`：运行和 O(1) 得第一阶段均值，numpy 向量化
  筛选求均值，dirty 清除后重复读取不重算）。音频线程 per-hop 成本从
  O(N) 降为 O(1)，UI ~10Hz 读取时一次向量化扫描（36k float 的 numpy
  比较 ~µs 级）。BS.1770-4 两阶段 gating 数值语义不变。

回归：TestAud16905LazyIntegratedGating（hop 后 dirty=True 且读数不变、读取
触发重算并清除 dirty、无新块重复读取不重算；-23 LUFS 校准保持 ±1.5；
惰性结果与全量重扫参考实现 bit 级一致）。邻接 tests/edit/test_loudness_meter.py、
