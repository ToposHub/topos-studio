## 设计说明（关键决策）

1. **AUD-39201 的接线范围**：GPU 帧释放的渲染线程注册/排水机制实现在 frame_queue.py（模块级），由 video_async_renderer.py 的渲染线程（`run()`）注册并排水。video_playback.py 不在本批白名单——v3 pipeline（AsyncRenderer，src/features/color/core/async_renderer.py）作为渲染线程的注册接线属于下一批（video_playback.py 及其渲染链路），本批机制对"未注册"场景保持既有立即释放行为，不会造成回归。
2. **AUD-39210 的语义变化**：ffmpeg 后端 `start()` 从"同步探测后返回成败"改为"廉价检查 + 后台探测"（缓存命中"不支持"时仍立即失败，保持 `ProgramMonitorOutputController` 的 native 后端回退在已探测场景下有效）。探测结论未缓存时 `start()` 返回 True、失败经日志 + 线程退出呈现——监视器输出是非关键路径，优先保证 UI 线程不被阻塞。
3. **AUD-39211 的默认值**：帧不带任何色彩元数据时保持旧系数（BT.709 全量程、无范围扩展），无依据不改变既有输出；带元数据（哪怕只有 matrix 或 range 之一）才按 normalize 后的矩阵/范围转换。
