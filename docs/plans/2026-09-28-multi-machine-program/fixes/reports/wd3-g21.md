## 1. AUD-24501 [Major/bug/M] — FIXED

证据复现（batch-245）：`_on_parameter_reset`（:808-810 raise ValueError）、

- `_on_parameter_reset`：两分支（ball/ring）先校验，坏值 warning + return，
  不再 raise（正常路径行为不变，回归用例锁定）；
- `_on_parameter_change` component 2：先校验再取分量，坏包丢弃；
- `_flush_trackerball_motion`：逐轮 try/except (TypeError, ValueError,
  IndexError) 包住 `_wheel_from_trackerball_point`，坏轮 `continue`
  （面板原值保留，其余轮照常发布）；

`_updated_wheel` 的 raise 保留为内部不变量断言（调用方已全部传入校验过

## 5. AUD-24702 [Major/bug/M] — FIXED

证据复现（batch-247）：u_raw_color_space==13 的九个系数与 ==2（Rec.2020）
逐字节相同——两个不同色域不可能产生 7 位小数全同的变换矩阵；image_engine
cs_map 含 13→Fujifilm F-Gamut 映射项，该选项实际执行 ProPhoto→BT.2020。

修复矩阵生成方式：基色作列向量构造 RGB→XYZ、白点定标、
`M = M_target⁻¹ @ Bradford(D50→D65) @ M_ProPhoto`，与文件内既有矩阵

即行主序矩阵的转置）：

```glsl
mat3 prophoto_to_fgamut = mat3(
     1.0696275, -0.0061746,  0.0035957,
    -0.0069129,  0.9562600, -0.0118759,
    -0.0627145,  0.0499146,  1.0082802

```

与审计独立计算值（[0][0]≈1.070 等）一致。`u_lut_tex` 绑定核实：RAW_VIEW
的 LUT 始终是 texture3d（`_load_lut_sync`/`_upload_3dlut` 或 2×2×2 identity
fallback），`textureSize(...).x` 取每轴网格数，映射公式正确。
