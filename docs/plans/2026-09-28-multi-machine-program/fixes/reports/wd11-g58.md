## AUD-17000 [Major/bug] 占位素材元数据宽高未经验证直接 int()

**状态：FIXED**

**根因**：`render_placeholder_frame_for_asset` 用 `int(metadata.get(...))`
直接转换外部持久化数据；JSON round-trip / 手工编辑后的非数字字符串、
dict/list、NaN/inf 会让 ValueError/TypeError 逃逸进逐帧渲染/导出路径
（两个调用点的 `except (ImportError, AttributeError)` 不捕获）。

**修复**（placeholder_frame.py:116 `_metadata_dimension`）：安全数值提取——
bool 一律视为畸形；int/float 走 `int()` 并捕 `(ValueError, OverflowError)`
（覆盖 NaN/inf）；str 走 `float()` 解析并捕 ValueError；其余类型回退 0，
由既有 `meta_w or width` 回退传入尺寸。畸形值不再抛异常。

**测试**：`TestPlaceholderFrameMetadataSafety`（12 组参数化 + 2 个行为断言）。

## AUD-17001 [Major/bug] 确定性静态帧无缓存 + int64 meshgrid 百 MB 级临时分配

**状态：FIXED**

**根因**：输出纯确定性但两个调用点（timeline_preview_renderer.py:3657、
timeline_export.py:9292）逐帧调用、无缓存；每次调用两个 int64 meshgrid
（4K 约 66MB）+ 多个 float32 中间数组 + 冗余 `.copy()`，约 170MB 瞬时 churn。

**修复**（placeholder_frame.py:57 `@lru_cache(maxsize=4)` 的
`_render_placeholder_frame_cached` + `render_placeholder_frame` 分发副本）：
- 按 `(width, height)` 缓存，命中只付一次 uint8 拷贝（分发独立副本，
  调用方可安全修改，下游 `_apply_preview_color_grade`/`_resize_frame_to_viewport`
  等消费者契约不变）；
- 斜纹掩码按行周期 `2*period` 平铺（行 i 与 i+2*period 的
  `((x+y)//period)%2` 恒等，商恰 +2）：一块 `(2*period, width)` bool +
  `np.tile`，替代整帧 int64 meshgrid；
- 暗化/正常两套调色行分别预转 uint8 后按掩码选取，单次 `(H,W,3)` 分配。
  数学取值与旧实现逐位一致（新测试内置 legacy 参考实现比对 5 组尺寸
  全部 `array_equal`，脚本预验证含 1920×1080 亦逐位相等）。

**测试**：`TestPlaceholderFrameCache`（缓存同一性、副本独立性、逐位一致）。
