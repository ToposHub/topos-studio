## 修复摘要

### AUD-35405 performance_monitor clear()/reset() 清理不完整
新增 `_clear_data_locked()`（调用方持锁）：覆盖 start_session 清理的全部
字段族——基础统计、P0.A 播放统计、S5.B 渲染队列/YUV 分段计时、零拷贝
计数、降级状态（_degradation_level/_consecutive_*_ticks/
_prefetch_lookahead_reduction/_last_tick_p95_high_time）、P2.2 代理阶梯。
start_session/clear/reset 三者统一走该助手（clear 保持会话状态、reset
额外清会话状态）。`check_tick_performance_and_degrade` 样本不足的早退
由硬编码 `return 0` 改为 `return self._degradation_level`，与
`get_degradation_level()` 口径一致。在 wd17-g91 已提交的 `_append_bounded`
有界统计窗之上继续工作，未回退。

### AUD-35500 Subsampling.NONE 与 YUV_444 枚举别名
`NONE = (0, 0, 0)`（不冲突值域，表示"无色度平面/J:a:b 语义"），
`chroma_width_divisor`/`chroma_height_divisor` 对 NONE 显式返回 1
（避免 0//0 与 b==0 → 2 的错误分支）。`from_tuple((4,4,4))` 仍返回
YUV_444（不再有歧义）。`get_by_properties(subsampling=YUV_444)` 不再
混入 rgb24/gray 等非 YUV 格式。注意：该值参与 `generate_proxy_key` 间接
路径不涉及（键只用 policy 名称），无缓存兼容问题。

### AUD-35504 generate_proxy_key 缺 topos 三参数
key_parts 追加 `topos_bit_depth`/`topos_keep_444`/`topos_qp`——Topos
代理编码参数变更后旧缓存键自动失效（键值整体变化=全量代理重建，符合
"缓存键含全部影响结果的输入"约束）。

### AUD-35505 最小分辨率按轴独立钳制
新增 `_scale_with_min_clamp(original_size, scale, min_size)`：最小分辨率
以"钳制统一缩放系数"整体生效（eff = min(1.0, max(scale, min_w/w,
min_h/h))），保持宽高比且永不放大源。替换 calculate_proxy_size 的
HALF/QUARTER/CUSTOM/AUTO 四处按轴 `max(min, dim)`，以及
`ProxyResolution.calculate_size`（503-505 同模式；保留取偶）。
小尺寸源（如 320x240）现在返回原始尺寸而非被上采样到 (640,360)。
CUSTOM 分支虽未被审计点名但属同型缺陷，一并修复。

### AUD-35506 calculate_target_size 奇数高度未取偶
`target_height = min(max(2, int(height)), self.target_height) // 2 * 2`
（与宽度同样向下取偶），消除 H264/JPEG（yuv420p 系）"height not
divisible by 2" 编码失败风险。

### AUD-35600 成功路径重复探测源文件
`_run_ffmpeg` 新增 `source_fps` 参数（generate() 入口探测到的 fps 随
调用传入）；成功路径 duration 直接 `total_frames / source_fps`，删除
对源文件的两次 `_probe_source`（条件+取值各一次）。fps 缺失/<=0 时
降级 0.0，不再抛 ZeroDivisionError/TypeError 被外层 except 把成功
误报为失败。

### AUD-35601 CLI 进度按 \n 分行（\r stats 解析停摆）
### AUD-35602 Windows stderr 永不排水（死锁）
两条一并修复：废弃 select+readline 模型，改为后台排水线程
（`ProxyFFmpegStderr`）持续 `stderr.read(4096)` 入缓冲，监控循环从
缓冲取字节并按 `\r`/`\n` 双分隔切行解析 `frame=`——编码期间（\r 结尾
stats）帧数解析、0.5s 进度回调、取消轮询与循环内 kill 全部恢复工作；
Windows 上管道由排水线程持续排水，不再写满阻塞 ffmpeg。进程退出后
join 排水线程并合并残余块，失败分支错误信息取自收齐的 stderr。循环
保留 0.1s 轮询间隔（替代原 select 超时）避免空转。

### AUD-35603 _run_pyav_to_topos 硬编码 limited range
从流级 `codec_context.color_range`（AVColorRange：0=unspecified/
1=MPEG-limited/2=JPEG-full）解析源量程并如实写入 movie_cfg 与
fc（`range_code = 1 if full else 0`，与 _run_topos 口径一致；播放侧
ToposMediaSource 读 movie 级 summary.color_range，故以 movie_cfg 为
权威）。swscale reformat 不传量程参数、像素数据保持源量程——标签如实
即正确。unspecified 时按 limited 回退并告警一次（G7 口径）。
回归测试用 color_range=2 的真实 h264 源走完整链路，断言代理
`md.color_range == 'full'`。

### AUD-35607 max_concurrent 从未实施
`__init__` 增加 `threading.Semaphore(max(1, max_concurrent))`
（`self.max_concurrent` 同步钳正）。`_run_task` 在置 "generating" 前
以 0.2s 粒度轮询获取槽位（与 `_generation_deferred` 等待循环合并，
保持排队任务可取消），finally 中释放——成功/失败/取消均不泄漏槽位。

### AUD-35608 on_complete/on_error 持管理器锁调用
`_run_task` 在锁内只更新任务状态与缓存，出锁后逐个调用回调
（对齐 progress_wrapper 的既有写法），消除与 DiskProxyService 的
manager._lock→service._lock 反序 AB-BA 死锁条件。
`queue_proxy_generation` 发现已有有效代理时的同步 on_complete 同样
移到锁外（出锁后执行再返回 None）。

### AUD-35609 pause() 对进程内编码路径无效
ProxyGenerator 新增 `_pause_event`（threading.Event）与
`_inprocess_encode` 标志：generate() 分发到 _run_pyav/
_run_pyav_to_topos/_run_topos 前置位、finally 复位（入口同时清掉
残留暂停标志）。pause()/resume() 优先走 CLI SIGSTOP（原逻辑），无
进程且进程内编码中时置位/清除事件。三个帧循环（demux/read_frame
检查点）调用 `_wait_if_paused()`：0.2s 粒度等待，cancel() 置位
`_cancelled` 后立即退出等待。pause_all_generation 经 generator.pause()
现在对主编码路径生效（含 Windows 等非 POSIX 平台）。

### AUD-35610 同源重复入队静默丢弃后来调用方回调
`ProxyTask.on_complete/on_error/on_progress` 改为列表；重复入队时把
后来调用方的回调 append 到既有任务并返回既有 task_id；任务结束时
（锁外，见 AUD-35608）逐个调用。disk_proxy_service 只经
queue_proxy_generation 传单回调（接口不变），不受字段类型变化影响。

### AUD-35616 _source_index 每源仅一条索引
`_source_index: Dict[str, Set[str]]`。upsert_entry/load 用
`setdefault(...).add(key_hash)`；invalidate_by_source 遍历该源全部
key_hash 逐一置 STALE（docstring "失效所有相关 entry" 兑现）；
remove_entry 删除全部条目；get_entry 在多策略条目中返回 updated_at
最新的那条。save 无需改动（本就持久化全部 _entries），重载后陈旧
旧策略条目不再"挤出后重新可见"。

### AUD-35701 estimate_seek_cost 反向小距离跳转低估
重构分支：反向跳转（target < current 且当前帧已越过目标帧前的
keyframe）一律 `return max(1, decode_forward)`（GOP 编解码器无法反向
顺序解码，必须回到 keyframe 重新 forward 解码）；仅正向小距离且
未越过 keyframe 时返回 frame_distance。同步修正与条件相反的注释
（原"当前帧在 keyframe 之后"对应 `current_frame <= keyframe`）。

### AUD-35711 RAW BITMAP 缩略图缺 RGB→BGR
`_load_fast_thumbnail` RAW 分支 else（BITMAP）补
`cv2.cvtColor(thumb.data, cv2.COLOR_RGB2BGR)`，与 JPEG 分支
（imdecode→BGR）、postprocess 回落分支（显式转 BGR）统一 BGR 出口，
消除缩略图红蓝互换。测试用 monkeypatch rawpy.imread 注入 RGB 位图
验证通道互换已修复（.nef 扩展名——.dng 在 VIDEO_EXTENSIONS 中会先
进视频海报帧分支，该路由属 G93 邻域未动）。
