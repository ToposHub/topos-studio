### AUD-14413 — FIXED

**位置（修复前）**：`skill_runtime.py:607-611`（`DefaultGraphBuilder.build`）。

**根因**：`declared = [TaskRole(r) for r in manifest.roles if r in {...}]` 对全部非法 roles 产出空列表 → 返回无节点空图；`TaskGraph.validate` 无节点时通过，executor 返回 `()`，`SkillResult` 无 failed/cancelled/degradation——注册成功、运行"成功"却什么都没做。部分非法时同样静默少跑角色。

**修复**：(1) build 内 `manifest.roles` 非空且 `declared` 为空 → `raise ValueError(...none map to a known TaskRole...)`；(2) `_run_taskgraph` 以 `except ValueError` 捕获构造失败 → `degradation="TaskGraph 构造失败：..."` + SCHEMA_INVALID error 诊断（模板变量 `detail=` 正确传入，无 AUD-14414 类占位符问题），异常不击穿 `run()`；(3) 构造成功后比对 `manifest.roles` 与图中角色，被丢弃的角色发 WARNING 诊断 + degradation 兜底说明（"产物不完整"）。写候选仍在 finally 释放。

**测试**：`test_all_invalid_roles_raise_instead_of_empty_graph`、`test_empty_roles_still_returns_empty_graph`（官方路径不回归）、`test_runtime_surfaces_build_failure_not_silent_success`、`test_partially_invalid_roles_warned_and_degraded`（含 creative_director 仍产出 artifact）。

### AUD-14700 — FIXED

**位置（修复前）**：`timebase.py:91-101`（对照 :58-61 秒路径）。

**测试**：`test_ntsc_one_hour_matches_seconds_path`（107892，与秒路径差 ≤1）；24/25 原值锁定；既有 `test_timebase_conversion.py` 全过。
