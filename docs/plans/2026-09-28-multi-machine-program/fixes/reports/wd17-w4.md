## 逐条详情

### AUD-16808 [Major/bug] — FX-C02 render-operation 计划无生产消费者

**现状核查（重要）**：计划行描述"GPU 预览渲染器仍走 legacy 全屏后置合成路径"在
HEAD 上已过时——`EditGpuPreviewRenderer._do_composite`（edit_gpu_preview_renderer.py:2415-2437）
在存在调整剪辑时已走 `_composite_with_adjustment_scope` 的 z-order 作用域合成，
legacy 全屏后置路径已被移除（w11 批 fc3436c64 更新过本模块 docstring，
`tests/edit/test_gpu_adjustment_scope_composite.py`、`tests/edit/test_fix_wd11g57_aud.py`
已有锁定）。**仍然成立的缺陷残件**：`build_render_operations`（纯数据计划）
在生产代码中零消费者——分类逻辑（哪些层是 adjustment/solid）在
`timeline_preview_renderer` 与 GPU 侧 `_build_scoped_composite_work` 各持一份。

**修复**（单一分类权威接线）：

1. `src/features/edit/core/effect_render_operations.py`
   - `build_render_operations` 新增 `grade_snapshot` 回调参数；
   - `ApplyAdjustment` 新增 `grade: Optional[dict] = None` 字段（T-P1-22 三元组第三项）；
   - no-op 跳过规则修正：**仅有 ColorStack grade、无 effects 的调整剪辑不再被跳过**
     （生产端会对其原位 grade；GPU 侧 `_apply_adjustment_clips` 对空 effects +
     无 grade + 恒等 Transform 才是像素级 no-op，跳过仍与之等价）。
2. `src/features/edit/core/timeline_preview_renderer.py`（`PreviewRenderWorker._try_gpu_render`）
   - 装车循环前用遮挡裁剪后的 `layers` 组装 shim `FrameRenderPlan`，调用
     `build_render_operations(frame_plan, asset_resolver, effects_snapshot,
     grade_snapshot)`；
   - 循环改为 `for op in render_ops`，调整剪辑分支改 `isinstance(op,
     ApplyAdjustment)`（effects/grade 直接取自计划，快照在构建时一次性采集），
     solid 分支改 `op.is_solid`；删除两处独立的 `asset_type ==` 判定。
   - 仅动渲染 worker（渲染线程侧），未触碰 UI 线程/GL 约束；行为等价性依据见上。

### AUD-28101 [Major/bug] — elastic_in_out 中点跳变

**核查**：审计证据中的旧实现（双衰减包络、中点跳 0.5、终点前 ≈0.75）已被
cb95e2f0b（2026-10-01，w14 批"g73: Penner-accurate elastic curves"）重写为
标准 Penner easeInOutElastic（period 0.45/s=0.1125）。数值复核：t=0.4999/0.5/0.5001
→ 0.4993/0.5000/0.5007（连续）；t=0.9999 → 0.99991（收敛）。

**本次动作**：不改码；`tests/app/test_fix_wd17w4_aud.py::TestElasticInOutContinuity`
锁定端点精确（0→0、1→1）、中点值 0.5 与两侧连续（|Δ|<0.05，旧缺陷为 0.5）、
终点收敛（<5e-3）、中心对称、有界过冲、以及与 Penner 参考公式逐点一致。

### AUD-6311 [Major/bug] — set_generation_transport 零调用，节点恒 NEEDS_CONFIG

**核查**：全库 grep 确认 `set_generation_transport` 调用方仅测试——生产零接线，

**修复**：

   - 新增 `install_default_generation_transport(*, config=None,
     credential_store=None, provider_factory=None) -> bool`：从用户级
     `~/.topos/ai_profiles.json`（`load_user_ai_config`）解析第一个支持 image
     模态的 profile（单条损坏跳过），key 按写惰性经共享 `make_credential_store()`

     候选（URL/文件）解码为 RGBA [0,1]，必要时重采样回请求尺寸（provider 有
     最小像素数上采样；遮罩合成要求同形）；

   - 新增 `_decode_image_to_rgba` 辅助（PIL 解码；transport 运行于既有
     AUD-6307 的短生命周期 worker 线程，无 UI 线程/Qt 依赖）。
2. `src/features/composite/module.py`（配置流消费文件，白名单外，已披露）
