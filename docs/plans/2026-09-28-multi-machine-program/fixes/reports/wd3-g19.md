## 锁定旧行为协议处理（AUD-0701 × AUD-24200 冲突）

`tests/color/test_fix_wd3g20_aud.py::TestAUD24200LayerSnapshotValidation` 锁定了
"`Layer.from_dict` 对层级结构损坏（`blend_mode: None`）抛错 → color_stack_hydrator
逐条捕获丢弃"的契约（且从_dict 的全部外部数据入口都经该逐项隔离）。按"不翻转
既有用例"原则：

- 层级结构损坏（blend_mode 非 str）**保持抛错**，但由裸 `AttributeError` 升级
  为带明确信息的 `ValueError`（wd3-g20 用例仍绿：其断言的是丢弃行为与日志，
  不绑定异常类型）；
- 嵌套结构（单个 mask shape / 曲线 / 控制点 / 容器）按 AUD-0701 的最低要求
  （"至少把单 shape/单 curve 的失败隔离为局部降级"）局部降级 + warning 日志。

  文件后同一合并命令仍同样段错误（exit 139）**，且各目录单独运行全部绿、

  引入。

  非错误，未改语义。
