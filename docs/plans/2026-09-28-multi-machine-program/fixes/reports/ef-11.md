## 关键决策说明

1. **AUD-8607/88020/8911/9100 选文档侧修复**：均为 doc-gap 类。8607 改哈希分配会改变 id 语义且与 cryptomatte 体系冲突；88020 函数签名无相机朝向，负值语义不可实现；8911 的 Python 实现与 shader 实现**数值一致**（都是线性），错的是双方注释；9100 的"让参数参与几何"需发明缩放映射且调用方在白名单外（nodes/）。四处均已把契约写清。
2. **AUD-8710 导出收敛的安全性**：`grep` 全仓库确认 `DEFORMER_SHEAR/SPHERIFY` 只被 `tests/composite/test_fix_wd7g39_aud.py` 从 `.base` 直接导入，包级 `__init__` 导出无人消费；AUD-8703（他批）已让 evaluate_deformer 对未实现类型抛 ValueError，导出常量只会误导。
3. **AUD-9204 依赖 content_revision 契约**：核实 geo3d_node.py:300-312 的 content_sig 包含 (primitive, grid_x, grid_z, spacing, transform, 材质)——instance_offsets 内容的任何决定因素变化都会递增 revision，签名丢 tobytes 不丢可感知性。
4. **AUD-88040 的 GL 释放全部发生在渲染线程**（draw→_build 调用链），符合"UI 线程不碰 GL"红线；AUD-88055 同理（HDRI bake 本就要求渲染线程调用）。
5. **无 HDR 数值钳制、无裸 except、无吞错**：新增 except 均带 logger 留痕且重抛或返回明确 fallback；未引入任何 >1.0 值域钳制。
