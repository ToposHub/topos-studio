   N 样本列表）+ `open_ms` 列表 + p50/p95/min/max/mean + `probe_argv`
   （复现命令）；
3. **schema 注释**：模块 docstring 内完整记录 result.json schema（含
   cold_start 段每个字段的口径），并在 result 内 config.cold_start 记录
   请求的 N；
4. 探针失败（子进程非零退出/无 JSON）显式 RuntimeError，不留静默缺样本。

**实测说明**：本机不产出正式数据（manifest 拒绝），但探针机制已用真实
素材+陈旧 dylib 冒烟验证（见 §验证记录）：3 次真实子进程采样
cold_first_frame_ms = [10.718, 10.810, 10.721]，聚合 p50=10.721 正确。
