## 设计决策与残留说明

- **AUD-9005 的方案取舍**：审计给出三条路线（有界 wait / 杀子进程 / UI 提示）。选"杀子进程"为根因修复：在途 assimp CLI 转换是被点名的 120s+ 阻塞源，取消令牌经线程局部钩子直达等待循环后即刻 SIGTERM（2s 宽限再 SIGKILL），shutdown 侧另有进程登记表兜底（覆盖无令牌的直调路径）。未做 daemon worker：Python≥3.9 的 ThreadPoolExecutor 退出 join 经 `threading._register_atexit(_python_exit)` 的 `_threads_queues` 进行、不看 daemon 标志，改标志无收益。纯 Python 侧第三方解析无法安全强杀（模块 docstring 明示），退出等待上界收敛为该次解析的自然时长。
- **AUD-9006 的版本兼容**：`_trimesh_geometry_world_matrix` 同时覆盖 4.x（`graph.get` + `geometry_nodes`）与 3.x（`transforms.node_to_matrix` dict）；几何名本身也在候选列（部分加载路径用几何名做 frame 名）。graph.get 的窄异常元组 `(ValueError, KeyError, TypeError, AttributeError)` 只用于候选轮询，最终失败返回 None 由调用方回退 identity（保持旧代码"可加载"底线）。
- **AUD-9007 的取舍**：审计建议"保留原树"或"mesh 名映射"，两者都做了（两级匹配 + 保留树）。部分匹配场景（如 3 个匹配 1 个失配）也走保留树——几何可见性优先于动画层级保真，且蒙皮数据经 `_attach_gltf_skin` 在两种路径下都生效（直接改写 source.mesh 实例）。
- **AUD-9106 的 colors 对齐**：过滤只在与 positions 行数严格相等时同步裁剪 colors（含 list 入参先 asarray）；错配长度维持原"回退 flat 色"语义。
- **AUD-9117 的后缀方案**：首个同名不加后缀保证无重名场景 id 逐位稳定（持久化的 hidden 集不受扰动）；`#n` 位置后缀在兄弟删减时会漂移（位置式消歧的固有属性），远优于现状的"重名即同一 id"。
- **AUD-9301 的边界**：spline_panel.py 不在白名单，未给它加 `dispose()`；`findChildren(QTimer)` 全停是等价且更普适的落点（任何面板持有的 QTimer 都停），dispose() 钩子对已具备它的 KeyframesPanel 优先调用。page.cleanup() 内部的定时器问题属 AUD-9505（另行批次）。
- **AUD-9401 的回滚语义**：rejected 回滚用 `_applying_state=True` 包裹（复用状态锁抑制 itemChange 副作用），并显式丢弃 `_change_old_data` 快照——取消后不留半开事务，下次编辑的 `_begin_change` 重新捕获。
- **锁定旧行为**：无需任何既有测试改动——全部邻接测试按原断言通过（含 backdrop 往返、VBO 池引用计数、trimesh 转换、undo 事务等）。
