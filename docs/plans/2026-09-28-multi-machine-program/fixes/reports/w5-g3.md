## 1. AUD-36200 [Critical/perf-opportunity/M] — FIXED

**问题**：`WindowsHwPlanarSource._convert_frame_planar` 每帧硬编码
`color_range='limited' / color_matrix='bt709' / color_primaries='bt709' /
color_transfer='bt709'` 并写入 DecodedFrame 动态属性；渲染器
`edit_gpu_preview_renderer._decoded_frame_color_tag` 动态属性优先于
metadata，导致真实流色彩元数据（HDR10 的 bt2020nc/smpte2084、full-range）
被永久屏蔽，按 BT.709/limited 错误解码。

**关键调研发现（决定实现形态）**：实测本仓 .venv 的 PyAV 17.0.1，
`VideoStream` / `CodecContext` / `Codec` 均不暴露任何 color_* 属性
（`dir()` 为空）——父类 `_probe_metadata` 的流级色彩探测在该版本实际
取不到值（返回 None）。**`av.VideoFrame` 是码流色彩标记（SPS/VUI）
唯一的 Python 侧表面**（返回 FFmpeg 整型枚举：primaries/trc/colorspace、
range 0=unspecified/1=limited/2=full）。

**根因修复**（hw_planar_source.py）：
1. 新增模块级常量与判定函数（带类型注解）：
   `_UNSPECIFIED_COLOR_TAGS`（''/unknown/unspecified/reserved）、
   `_FRAME_COLOR_READERS`（色彩字段 → 帧属性名 + 归一化函数，
   复用父类探测同款 `normalize_color_primaries/transfer/space`、
   `map_color_range`）、`_DEFAULT_COLOR_TAGS`（渲染器同款缺省
   bt709/limited）、`_is_unspecified_color_tag()`。
2. 新增 `_resolve_probe_color_tags()`：从父类 `open()` 填充的
   `self._metadata` 读容器探测色彩值，未标记（None/unknown 族）字段
   回退渲染器缺省；在 `open()` 末尾（`_verify_hw_output` 之后）调用，
   存入 `self._probe_color_tags`（`__init__` 先以纯缺省初始化）。
3. 新增 `_frame_color_tag(frame, field)`：回退链
   **解码帧 color_*（码流标记，HDR10/full-range 权威来源）→ 容器探测值
   → bt709/limited 渲染缺省**；对 `getattr(self, '_probe_color_tags', {})`
   防御式读取（兼容 `__new__` 构造路径）。
4. `_convert_frame_planar` 中四行硬编码替换为
   `self._frame_color_tag(frame, ...)`，注释说明不得硬编码的原因
   （P010/HDR10、full-range 语义）。

每帧成本为 4 次属性读 + 归一化查表（相对 NVDEC 解码可忽略），无分配。
macOS VT 路径（macos_vt/source.py 从 demuxer info 读流值）与 CPU planar
路径（不设动态属性、靠 metadata 兜底）的行为均不受影响；本修复使 HW
路径同时优于两者：帧级码流标记 + 容器探测双层来源。

- 文件：src/shared/media/windows_hw/hw_planar_source.py
- 行号：32-37（import）、70-102（常量/判定）、120-123（__init__）、
  148（open 刷新）、238-282（两个新方法）、356-362（替换硬编码块）

**测试证据**（tests/color/test_fix_conventions_aud5.py::TestHwPlanarColorTags，
7 用例，与 tests/media 既有契约层手法一致：__new__ 构造 + fake av frame +
patch `_extract_visible_plane_data`）：
- `test_frame_hdr10_tags_are_used`：帧标记 bt2020/smpte2084/bt2020nc/full
  （FFmpeg int 9/16/9/2）→ 四字段原样透出（修复前恒为 bt709/limited）。
- `test_frame_bt601_full_tags_are_used`：SD full-range（smpte170m/full）透出。
- `test_unspecified_frame_falls_back_to_probe_metadata`：帧 unspecified →
  容器探测值（bt2020/smpte2084/bt2020nc，range None → limited）。
- `test_all_unspecified_falls_back_to_renderer_defaults`：全未标记 →
  bt709/limited（渲染器缺省，既有契约保持）。
- `test_unknown_normalized_values_treated_as_unspecified` / 
  `test_resolve_probe_tags_normalizes_case` / `test_no_probe_tags_attr_still_safe`。

**既有测试兼容性**：`tests/media/test_windows_hw_planar_source.py`
