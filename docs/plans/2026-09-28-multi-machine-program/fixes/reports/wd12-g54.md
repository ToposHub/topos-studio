### AUD-15513 [Major/risk] scrub 预览 worker 与播放启动竞态 — FIXED

- 根因：`preview_scrub_audio` 只在入队时检查 `is_playing`；暂停期入队的任务在 Play 后仍通过
  generation 校验（generation 只被新预览请求递增），worker 随后执行 `reset_dsp_states()`
  （清掉播放中的混响尾/包络）并把解码器 seek 到 scrub 帧。证据报告所引行号（3625-3634 等）
  在 D11 修复后已漂移，缺陷本体仍在（现位于 worker `run()` 与 `preview_scrub_audio`）。
- 修复（三层，审计建议的两个方向都做）：
  1. `AudioScrubPreviewWorker.__init__` 新增 `is_playback_active: Callable[[], bool]` 回调；
     `run()` 在破坏性混音（reset + seek）**之前**检查，播放已启动则丢弃任务
     （`AudioClock.is_playing` 由 QMutex 保护，worker 线程可安全轮询）；
  2. 新增 `cancel_pending()`：锁内递增 `_latest_generation` 使队内旧任务过期并清空队列；
  3. manager 新增 `_invalidate_scrub_previews()`（递增自身 generation + worker cancel），
     在 `play()`（启动时钟前）与 `resume()` 中调用。
- 残余窗口：worker 检查通过后、mix 开始前按下 Play 的微秒级 TOCTOU 需共享 mixer 锁才能完全
  消除（会引入 play 阻塞在 mix 上的新权衡），本批按审计建议的检测/失效方案落地。

### AUD-15515 [Major/bug] resume() 无状态守卫 — FIXED

- 修复：`AudioClock.resume()` 返回 `bool`（确为 PAUSED 并恢复 → True；否则 no-op → False）；
  `AudioPlaybackManager.resume()` 据此提前 return——停止态/从未播放时不再误发
  `state_changed("playing")`，与 `pause()` 的守卫对称。返回值语义对既有调用方向后兼容。

### AUD-15517 [Major/bug] get_progress() duration==1 除零 — FIXED

- 修复：`denominator = max(1, self._timeline_duration - 1)`（审计首选方案）。单帧时间线
  current_frame=0 → 进度 0.0，不再抛 ZeroDivisionError。

### AUD-15608 [Major/bug] simplify_samples 递归爆栈 — FIXED

- 修复：Douglas-Peucker 改为显式栈迭代（kept 标记数组 + `(start, end)` 段栈），保留点集合与
  递归版等价（端点必留、最大偏离点分裂递归）；属性访问提升到循环外的局部列表。
- 回归：3000 帧两值交替（旧实现深度 O(n) 必爆默认 1000 递归上限的噪声形态）正常返回且端点保留；
  既有 4 个简化语义用例全部保持通过。

### AUD-15609 [Major/bug] Write 模式"覆盖整段已录曲线"未实现 — FIXED

- 根因：默认命令是"每关键帧一个 AddAutomationKeyframeCommand"的宏，`KeyframeTrack.add_keyframe`
  仅同帧替换，录制区间内不同帧号的旧关键帧残留，新旧曲线混杂插值。
- 修复：新命令 `OverwriteAutomationCommand`（定义于 automation_recorder.py，commands.py 不在本批
  白名单）：
  - apply 时快照整个 automation dict → 删除每个录制段帧区间 `[lo, hi]` 内旧关键帧 → 写入新关键帧；
  - undo 按快照完整恢复（含段外关键帧与旧值）；单命令 = 单次 undo；
  - recorder 增加录制段追踪：Write/Latch 单段覆盖全程，Touch 按住区间成段、松手段间旧曲线保留
    （对齐模块 docstring"松手后回到原曲线"）；
  - `stop(make_command=...)` 工厂路径语义不变（自定义工厂自行负责覆盖语义）。
- 序列化注意：该命令实现了 `to_dict/from_dict`（command_type=`OverwriteAutomationCommand`），
  仅作为 undo 栈顶命令使用，不注册进 `_MACRO_SUBCOMMAND_TYPES`、不应嵌套进可序列化宏
  （undo 栈未持久化，已核实无历史落盘路径）。
- 既有测试锁定旧契约者按协议更新（见下节）。

### AUD-15701 [Major/bug] drift 检测把 PARTIAL 折叠为不可用 — FIXED

### AUD-15807 [Major/bug] 左缘裁剪上限混入整体平移约束 — FIXED

- 修复：`compute_trim_range` 的 `max_start` 改为 `end - 1`（仅受 duration>=1 与左邻约束），
  删除 `right_neighbour_start - current_duration` 耦合。右邻对右缘方向的约束仍由 `max_duration`
  表达。调用方（timeline_view.py，不在白名单）left/right trim 共用该范围，对左缘向内拉、
  左缘上限、右缘时长帽三种场景行为均正确。
- 残余（白名单限制）：调用方对 left-trim 的向外拉伸仍会独立 clamp duration
  （`max_duration = right_nb - current_start` 是右缘语义），极左拉伸时 end 可能被拉回——该
  交互需调用方按 mode 拆分边界（审计建议的另一半），timeline_view.py 归属批次处理。

### AUD-15809 [Major/bug] 29.97 drop-frame 双重补偿 — FIXED

- 修复：标准 SMPTE ST 12-1 换算——十分钟块 = `1800 + 9×1798 = 17982` 实际帧；非整十分钟内
  显示帧号 = 分钟内实际偏移 + 2；整十分钟不跳帧。删除恒真条件
  `frame_in_minute >= 0` 与额外 +2。
- 验证：对 SMPTE 正向映射（`F = nominal − 2×(total_min − total_min//10)`）做 0..54000 帧
  全量 round-trip，0 失配；关键点 F=1800→00:01:00:02、F=17980→00:09:59:28（旧实现误输出
  00:01:00:04 / 00:10:00:02）、F=17982→00:10:00:00。非 drop 帧率路径不变。
