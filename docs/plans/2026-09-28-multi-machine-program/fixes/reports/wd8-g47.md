## 设计决策与残留说明

- **AUD-13210 的 null 语义**：按审计建议的修复式（`or ()` + isinstance 校验）落地——显式 null 与键缺失同义（返回明确结论、不崩溃），只有**非集合真值**（dict/str/int 等）才判"格式无效"fail closed。本批以审计建议为准，未采用更激进的"null 即缺失证据即阻断"（会改变无 entries 报告的既有放行语义）。
- **AUD-13201 的补发 header**：AgentEventKind 无通用降级事件，选择补发与实际请求一致的 `RUN_REQUEST_HEADER`（带 `degraded_from`）——既记录降级事实，又修正 trace 中 request_mode 与实际请求不符的问题（该不符正是审计影响栏点名的一项）。既有测试断言首个 header 的 `request_mode=="tool_loop"` 不受影响（补发仅在降级路径出现）。
- **AUD-13202 的用量口径**：真实 usage 存在时 `session_total_tokens` 为逐轮 `total_tokens` 之和；缺失时按各轮发送前的窗口估算累计（仍带 estimated 标记，"不伪造真实用量"红线不破）。单轮 + 无 usage 的旧输出（`session_total_tokens=0`）保持不变（`session_total` 为 0 时直接沿用 `estimated`）。
- **AUD-13305 的 8 下限**：图内无任何 clip 信息时的保守计费下限取 8（高于典型局部重算的 1-3 clips，保证全量 > 局部的排序成立）；有图信息时用图内 clip 并集，有调用方总数时以总数为准（且不少于并集），`estimate_is_floor` 如实标注。调用方无 src 内变化（该函数此前无 src 调用方，仅测试），新参数纯可选。
- **AUD-13308 的迁移表**：`USER_OVERRIDE → {ACCEPTED, REJECTED, LOCKED}` 允许（人工再决策）；`SUPERSEDED`/`REJECTED`/`LOCKED` 为终态（同态幂等除外）。`record_user_override` 原有的 LOCKED 保护不变。
- **锁定旧行为**：零个既有测试被修改。全部邻接测试按原断言通过——含 `test_decision_service.py`（ACCEPTED→REJECTED、lock 幂等）、`test_cg_cp_ix.py`（单 artifact stale/一致性与 hash）、`test_w6_w9_contracts.py`（clip 级成本与超限）、`test_chat_run_driver.py`（header 断言取首个）、`test_chat_inbox_integration.py`（两轮追问）等。
