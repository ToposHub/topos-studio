## 备注 / 残留

- AUD-81003：若某 worker 永远卡死在渲染中，其 renderer 会滞留 abandoned 注册表直至
  进程退出（daemon 线程）——这是线程亲和安全下的有意取舍（审计建议原文："对 join 超时
  的 worker 记录泄漏并跳过跨线程 cleanup"）。

  CacheManager 无"降级类别"公共 API，故采用求值窗口内包装公共 `put()` 注入
  `category=PREFETCH`，未触碰 cache_manager.py（白名单外）。
- AUD-8212：`should_use_compute_blur` 签名未加 edge_policy（调用方 blur_evaluator.py
  在白名单外）；`apply_blur_compute` 顶部的拒绝保证语义正确，仅多一次程序选择。
- gl_utils 保持 DORMANT 标注：四项修复按"接线后即正确"标准完成，未新增生产调用方。
