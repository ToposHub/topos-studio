## 逐条明细

### AUD-34300 — FIXED
`src/shared/media/adapter.py`
- 新增 `_convert_planar_to_rgb(frame)`：planar RGB（GBR 平面序，`gbrp*`/`topos_gbrap*`/plane_infos 分量 G,B,R）整数面按位深满刻度归一化、浮点面（`gbrph16le` 线性 HDR）不缩放；planar YUV（Y,U,V[,A]，Alpha 忽略）经 `color_decode.get_color_converter().yuv_to_rgb`（色度子采样由其 `_match_chroma_to_luma` 处理）。
- 色彩语义来自帧元数据（`metadata.color_matrix/color_range` 标准名映射），缺省/未收录回退 **BT601+LIMITED**（旧 VideoDecoder 兼容路径的"数字 601 limited-range"实现；矩阵系数与 `RANGE_CONSTANTS` 未动，符合 range 契约审计注记）。
- `_convert_to_bgr8` planar 分支：转换→clip [0,1]→uint8→RGB 翻 BGR（删除误导性 warning 与 `to_rgb()` 依赖）；`_convert_preserving_depth` planar 分支：uint16 按位深满刻度重建、uint8 走 8-bit、float 出 float32 **不 clamp**（线性 HDR 值域可 >1）。
- `topos_cfa*` 抛含 "CFA" 的领域 ValueError（需 GPU debayer）；平面数不足抛含"平面数不足"的 ValueError——错误可区分，不再统一折叠 None。
