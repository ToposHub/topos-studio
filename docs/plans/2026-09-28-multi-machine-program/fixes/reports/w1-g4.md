## 1. AUD-03900（= BUG-B3-01）[Critical] — FIXED

- 结论：问题在当前代码存在（非 INVALID）。`_apply_settings` 原样存在审计引用的
  代码块（修复前 `preferences_dialog.py:2032-2050`）：无条件遍历
  `self._plugin_list` 收集停用项并写回 FE config，而 `_plugin_list` 仅由用户
  手点 "Refresh Plugins"（`_create_advanced_page` :1395）填充，对话框构造/
  `_load_current_settings` 均不刷新 → 打开偏好直接 Apply/Save 即把
  `disabled_plugins` 覆写为 `[]`。
- 根因修复（最小）：`_apply_settings` 中收集停用项时同时检测列表是否含有
  真实插件条目（`item.data(UserRole)` 非空的行；占位行 "No plugins found"
  无 UserRole 数据，天然排除）。仅当 `has_plugin_entries` 为真时才执行
  `fe_main.load_config()/save_config()` 写回，并同步更新内部镜像
  `self._disabled_plugins`；否则整体跳过，保留 FE 侧现有停用状态。
  - 该条件同时覆盖审计列出的加重因素：刷新过但 FE 运行时未起
    （`ensure_runtime()` 前 `plugin_manager.plugins` 为空）时列表只有占位行，
    同样不写回，不会经第二条路径清空。
- 位置：`src/app/ui/preferences_dialog.py` `_apply_settings`
  "Advanced (Logs & Plugins)" 段（修复后约 :2022-2059）。
- 测试证据：
  - 新增 `tests/app/test_fix_prefs_docks_aud.py::TestAud03900FeDisabledPluginsPreserved`
    5 个用例：未刷新 Apply / 未刷新 Save / 占位刷新 Apply（均断言
    `fe.saved is None` 且 `fe.conf["disabled_plugins"]` 保留原值）、真实刷新后
    Apply 仍正确写回（`["fe.alpha", "fe.gamma"]`）、真实刷新后全勾选写回
    `[]`（明确用户意图允许）。9/9 通过。
  - 锁定旧错误行为的既有用例翻转：`tests/app/test_preferences_dialog_coverage.py`
    原 `test_apply_without_refresh_clears_fe_disabled_plugins`（断言 Apply 后
    FE `disabled_plugins == []`，注释明言"锁定现状…修复后需同步更新"）更名为
    `test_apply_without_refresh_preserves_fe_disabled_plugins`，断言翻转为
    `fe.saved is None` + 保留 `["fe.alpha", "fe.beta"]`；模块 docstring 的
    锁定清单同步标注。属于"锁定旧错误行为"的合法翻转。
  - 直接调用真实 `_apply_settings`/`_on_save` 的
    `tests/ui/test_developer_mode_prefs.py` 3/3 通过（修复后该路径不再触写
    开发者本机 FE config，反而更安全）。

## 2. BUG-B4-01 [Critical] — FIXED

- 结论：问题在当前代码存在。`DockLayoutMixin.setup_docks` 的
  `self.all_docks = [...]` 基础列表 + 其后条件 append 序列（修复前
  `dock_layout_controller.py:967-1020`）确实漏掉
  `dock_properties/dock_edit_effects/dock_caption_workspace/dock_adr_take_sheet/dock_multicam`
  5 个 `create_custom_dock` 创建的 Edit 页 dock（创建于 :557-627，均为条件创建，
  adr/multicam 创建即隐藏）。
- 根因修复（最小）：在 Edit dock 注册段（`dock_ai_edit_assistant` 之后、
  `dock_composite` 之前）按既有模式补 5 个带 `if self.dock_xxx:` 判空的
  `self.all_docks.append(...)`，并附注释说明机制（对齐 :1001-1003 处
  Keyframes/Spline 的教训注释）。位置：修复后约 :988-1000。
- 注册后的行为影响核查（确认无回归）：
  - `_perform_update_all_titlebars` / `_sync_floating_docks`：浮动时安装
    FloatingDockTitleBar——正是修复目标；停靠时 1px 占位标题栏与其它 dock 一致。
  - `_save_all_docked_sizes` / `_restore_docked_sizes`：新增 5 个
    `dock_<name>_docked_size` 键——正是修复目标。
  - `apply_default_layout`（:2247-2254）会把 all_docks 成员 `setVisible(True)`，
    含默认隐藏的 ADR/Multicam：该调用发生在 `initialize_page_layouts` 与
    `restore_layout_state`（main_window.py :541→:561→:574）之前；三条
    initialize 分支的前置隐藏清单（:1111-1116 / :1155-1160）显式隐藏全部 5 个，
    硬编码回退分支的 hide-all 循环（:1230/:1329/:1347）修复后也覆盖它们，
    且启动收尾 `restore_layout_state` → `_enforce_page_dock_visibility`
    （:2842）在非 Edit 页强制隐藏 adr/multicam/properties → 最终可见性不变。
  - 硬编码回退分支 Color 快照（:1216）理论上会短暂含可见的 adr/multicam，
    但每次页面切换经 `switch_to_page` → enforce 收敛；caption 的 enforce 缺口
    是 BUG-B4-02（本批未含，行为与修复前一致：该快照此前就含可见 caption）。
- 测试证据：
