## 1. AUD-0907 [Major/risk/M] — FIXED

证据复现（batch-009）：缓存键 `("spatial_out", width, height)` 等内嵌尺寸，
而 `RenderSurfaceCache.get`（video_denoise_gl.py:108-119）已实现"同 key 且
尺寸匹配复用 / 不匹配释放重建"——键含尺寸意味着每种历史分辨率各占一个
dict 条目且永不淘汰。4K 单张 RGBA16F ≈ 66MB，spatial 5 键 + temporal 4
全分辨率键 + window 前缀独立一套，1080p/4K 混合分辨率时间线上显存占用随
出现过的分辨率种类线性增长。

修复：两个降噪器共 15 处 `self._surfaces.get((name, w, h), w, h)` /
`peek((key, w, h))` 全部改为纯字符串键（spatial：spatial_out / spatial_mid /
enh_low / enh_low_mid / enh_low_out / spatial_detail_out；temporal：
temporal_luma_cur / temporal_luma_prev / temporal_hist_a / temporal_hist_b /
temporal_out / temporal_motion / temporal_motion_sm / temporal_debug 及
window_ 前缀全套）。键与尺寸解耦后每个语义表面恒占一个槽位，尺寸切换由
缓存自身的重建逻辑处理——显存占用与分辨率切换次数无关。键均为两文件
私有（全仓 grep 确认无其他构造方），`_last_motion_key` 初始化值与
`_estimate_motion` 的 `key_prefix + "temporal_motion"` 保持一致。

## 2. AUD-0910 [Major/bug/M] — BLOCKED

证据复现（batch-009）：MSL :709 `if (mode == 14) return msl_hsv2rgb(float3(a_hsv.x, a_hsv.y, a_hsv.z));`
是 HSV 恒等往返 ≈ Normal 混合；标准 Color 混合应为
`float3(a_hsv.x, a_hsv.y, b_hsv.z)`（上层色相/饱和度 + 下层明度）。审计
明确：缺陷源于 GLSL 权威文本（shader_nodes.py:670 同病），MSL 翻译忠实；
建议修复为"两侧同步修改（GLSL shader_nodes.py:670 + MSL :709）并跑 G2
复验"（ADR 0004 契约）。

阻塞原因：
1. 本批文件白名单（wave_d_plan.json g:20 与任务行内一致）只含
   `shader_nodes_msl.py`，**不含 `shader_nodes.py`**；
2. 单侧只改 MSL 会直接击穿 G2 对拍门禁：
   `tests/color/test_metal_composition_blend_modes.py` 的 `SDR_CASES` 覆盖
   全部 19 种混合模式（含 "Color"=mode 14）的 GL↔MSL 输出对拍
   （≤1/255 LSB），本机为 macOS（Metal 可用），该用例必然由绿转红——
   引入比原缺陷更严重的回归（双后端行为分叉）。

已核对：本机当前 `tests/color/test_metal_composition_blend_modes.py` 全绿
（22 用例，双侧一致地保留该缺陷），维持现状不劣化。建议后续在含
`shader_nodes.py` 的批次中执行：两处 `vec3/float3(a_hsv.x, a_hsv.y, a_hsv.z)`
同步改为 `(a_hsv.x, a_hsv.y, b_hsv.z)`，随后跑 G2 blend 对拍与
`tests/color/test_layer.py` 混合模式相关用例。

## 3. AUD-0911 [Major/bug/M] — FIXED

证据复现（batch-009）：GPU toe 为 `if (c < low && black_point < low) {软压缩}
else if (c < black_point) {return black_point;}`，CPU 旧实现外层仅
`if black_point < low:`（bp >= low 时**什么都不做**，丢失 elif 钳制）；
shoulder 为 `if (max_c > high && white_point > high) {压缩} else if
(max_c > white_point) {scale}`，CPU 旧实现 `if white_point > high:`（wp <=
high 时丢失 elif 钳制）。优化边界 wp∈[0.5,5.0]、high∈[0.1,1.5]、bp≤0.2、
low≥-0.5 下两个缺失区域均可达，反编译拟合参数应用到 GPU 后不复现 LUT。

修复（the_decompiler.py `GradingMath.apply_soft_clip` 重写）：
- toe 逐通道：`toe_mask = (c < low) & bool(black_point < low)`、
  `clamp_mask = (~toe_mask) & (c < black_point)`，两分支分别软压缩 / 钳到
  bp——与 GPU if/elif 逐元素等价（bp<low 时钳制掩码数学上为空，行为与
  旧实现一致）；
- shoulder：`if white_point > high:` 走肩压缩（仅 max_c > high），
  `else:` 走 `max_c > white_point` 整体比例钳制；
- 删除 wp>high 分支内的肩后二次钳制：肩压缩按 mapped_max/max_c 等比缩放
  后最大通道 = mapped_max < W 恒成立，该步在精确算术下是 no-op 而 GPU
  并无此步。

## 4. AUD-0912 [Major/bug/M] — FIXED

证据复现（batch-009）：GPU 权威在 gamma 之后有独立暗部保护级
（shader_nodes.py GRADING_SNIPPET / MSL :124-136：`luma_post_grading < 0`
时 `x < -0.5 → -0.5 - |x+0.5|*0.1` 逐通道软压缩 + 通道平衡
`max-min>0.15 && min<0 → mix(color, vec3(luma), clamp(|min|*0.25,0,0.15))`）；
soft_clip 的 toe 段后有 RGB 平衡块（shader_nodes.py:867-881 / MSL
:761-773：`toe_max-toe_min>0.2 && toe_min<low → mix(res, vec3(toe_luma),
clamp((toe_max-toe_min)*0.25,0,0.15)*|toe_min|)`）。CPU 前向模型两级全缺，
拟合目标函数与含这两级的 GPU 渲染系统性偏差。

修复（the_decompiler.py）：
1. `apply_grading` 在 gamma 三分支之后、# 5. Shadows 之前插入暗部保护级
   （numpy 向量化）：luma 权重取输入 dtype；`dark_mask` 用**压缩前**
   luma 判定；软压缩 `np.where(deep_mask, -0.5 - |res+0.5|*0.1, res)`；
   平衡块的 min/max 取**压缩后**通道、mix 基准取**压缩前** luma——与
   GLSL 语句顺序逐条一致（这一前/后取值次序是权威文本的关键细节）。
2. `apply_soft_clip` toe 循环后插入 RGB 平衡块：per-pixel
   balance_factor、toe_luma、mix 系数 `factor*|toe_min|`（不钳制乘积，
   与 GPU mix 外推语义一致）。

## 5. AUD-0913 [Major/bug/M] — FIXED

证据复现（batch-009）：CPU `rgb2hsv(np.clip(res, 0, 1))`，GPU 两侧直接
`rgb2hsv(color)`；exposure/gain 推到 >1 或负值后 hue_shift≠0 时 CPU 把 v
压到 ≤1、GPU 保留，HDR 区间可见分叉。

修复：删除 `np.clip(res, 0, 1)`，`GradingMath.rgb2hsv(res)` 直用未 clip
的 res。回归用例以 `hsv2rgb(rgb2hsv(x) 平移)` 为 oracle 精确对拍（含
v=2.0 的 HDR 保留断言：旧实现输出 ≤1.0，新实现保留 2.0）。

## 6. AUD-1000 [Major/bug/M] — FIXED

证据复现（batch-010）：`reset()` 只清 `last_frame_index=-1 /
accumulated_frames=0`，不清 identity 字段；`prepare()` 中
`delta=0; if last_frame_index >= 0: delta = ...` → reset 后 delta 恒 0，

同帧重绘判定整体收进 `if self.last_frame_index >= 0:` 门内（无历史时不再
计算/检查 delta，直接走完整推进：last_delta=0、last_frame_index=frame、
accumulated_frames=1 → 下一帧恢复复用）。顺带删除
`self.last_delta = self.last_delta` 自赋值。既有 10 个状态机用例
（test_temporal_denoise_state.py）全部保持绿色（真同帧重绘语义不变），
新增 reset-后-恢复用例。
