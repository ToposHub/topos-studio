### AUD-19305 [Major/bug] 偏好页外部 config 值无验证 — FIXED

- 根因：`load/restore_defaults/get_scene_cut_settings_from_config` 直接消费持久化 dict；类型损坏时
  `int(sensitivity * 100)` 抛 TypeError → 宿主 `except Exception: pass` 半加载 → Apply 把默认值写回。
- 修复：新增 `_safe_float/_safe_int/_safe_bool`（类型归一 + 范围 clamp + warning 日志），范围常量
  与控件构造一致（sensitivity 0.35–0.75、min_scene_frames 2–120、max_queue 2–32）；
  `load()`、`restore_defaults()`、`get_scene_cut_settings_from_config()` 全部数值/布尔键过归一。
- 回归：新测试 4 例（坏类型回退默认、越界 clamp、load/restore 不抛）。
