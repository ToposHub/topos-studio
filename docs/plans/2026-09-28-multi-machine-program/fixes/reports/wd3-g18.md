### AUD-0412 [Major/bug] AI 降噪路径对 HDR 输入强制 clip [0,1] — FIXED

- 根因确认：`_run_ai` 对 `self.image` 整帧 `np.clip(0,1)`（模型输入、blend 分量、
  输出三处），>1.0 高光不可逆压平；Basic 路径注释明确支持 HDR（:153），行为不一致。
- 修复（max-scaling 方案）：

    `model_input = clip(original / scale, 0, 1)`；

    `[0,1]` clip（与 Basic 路径"支持负值与 >1.0 HDR"契约对齐）；
  - docstring 输入/输出契约更新。
