## 1. AUD-15301 [Major/perf-opportunity/M] — FIXED

**问题**：`DelayEffect.set_params` 在 time/采样率变化分支经
`_rebuild_delay_line → _recompute_hp_coeff` 用**旧** `self._low_cut_hz` 计算
highpass 系数；随后属性才被覆盖为新值，但唯一按新值重算的 `elif` 分支已被
跳过，之后同值 set_params 差值判据恒为 0 不再重算——工程加载/预设恢复时
time 与 lowcut 同时偏离默认值，反馈回路低切永远停在旧截止频率。

**修复**（`audio_dsp.py` DelayEffect.set_params）：先计算 `time_changed`/
`lowcut_changed` 并提交 `self._low_cut_hz = new_lowcut`，再进入重建分支；
`elif lowcut_changed:` 只调 `_recompute_hp_coeff()`。

**测试**：`TestAud15301DelaySetParamsStaleLowcut` 3 例——time+lowcut 同时变、
同值重放、采样率变化，均断言 `_hp_coeff == exp(-2π·new_fc/sr)`。

## 3. AUD-15303 [Major/risk/M] — FIXED

**问题**：`DelayEffect.process` ping-pong 模式 `swap = np.arange(channels) ^ 1`
在奇数声道（≥3）时末声道索引越界（3 声道 swap=[1,0,3]），渲染线程 IndexError。

**修复**（`audio_dsp.py` DelayEffect.process）：`swap = np.minimum(np.arange(channels) ^ 1, channels - 1)`
——偶数声道按对交换不变；奇数声道末声道映射到自身（与 ImagerEffect 防御风格一致）。

**测试**：3/5/7 声道 process 不抛错且输出有限（参数化 3 例）+
4 声道乒乓交叉反馈回归（ch0 信号经延迟后出现在 ch1，ch2↔ch3 对不受影响）。

## 16. AUD-15512 [Major/bug/M] — FIXED

**问题**：旧实现先 `ring.read(chunk_samples)` 消费再写设备：
`write_samples` 返回 0（设备瞬断、缓冲意外满）时样本已从 ring 拿走且只回滚

peek/write/commit）：

- 输出取数改为 `ring.peek(chunk_samples)`（拷贝、不消费）；
- `write_samples` 成功后按实际 `written` 提交 `ring.read(written)`——
  部分写入的余量留在 ring 头部由下一轮 peek 补写；写失败（written==0）时
  数据原样留在 ring，仅回滚 chunk 分数。

**测试**：`TestAud15512WriteFailureRetention` 4 例——ring 路径写失败样本
