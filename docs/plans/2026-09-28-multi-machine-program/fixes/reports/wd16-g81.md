## 逐条结论

### AUD-31621 — FIXED
单条损坏 profile 的 data_policy/limits 非对象时抛 AttributeError，逃出"单条损坏跳过"策略使全部 profile 加载失败。
**根因**：`from_dict` 直接 `dp.get(...)`，非映射值（`"local"`/`42`）抛 AttributeError，不在加载降级的 `(KeyError, TypeError, ValueError)` 捕获元组内。
**修复**：`from_dict` 对 `data_policy`/`limits` 先做 `isinstance(dict)` 判定，非映射降级为空 dict（走 DataPolicy/ProviderLimits 默认值），单条损坏恢复为可跳过/可降级。
**测试**：`TestAud31621CorruptProfileIsolated`（from_dict 降级、config/用户文件两条加载路径）。

### AUD-31623 — FIXED
load_user_ai_config 把暂时性读取失败（OSError）与文件不存在同等返回 {}，配合调用方 read-modify-write 整体覆盖 → profiles 与 API key 全部丢失。
**根因**：`except (FileNotFoundError, OSError, ...)` 一律返回空 dict，而 FileCredentialStore/set_credential_storage_preference/ProfileRegistry.save_to_user_file 均为 load→改→整文件覆盖。
**修复**（三层）：
1. 新增 `UserAiConfigError`；`load_user_ai_config(path, *, strict=False)`：FileNotFoundError（合法首启）仍返回 {}；其余 OSError/解析失败在 strict 下抛 `UserAiConfigError`，非 strict 保持容错但补 warning 日志（不再静默）。
2. `save_user_ai_config` 落盘守卫：目标文件存在但 strict 预读失败 → 抛 `UserAiConfigError` 拒绝覆盖（覆盖型调用方即便自身未改造——如 FileCredentialStore——也被兜底保护）。
3. 覆盖前以 `shutil.copy2` 保留一代 `.bak`（copy 而非 move：替换失败时原文件仍完好）。
**测试**：`TestAud31623ConfigLoadDistinguishesFailures`（7 例：双模式缺失、损坏 JSON、权限拒绝、save_to_user_file 拒绝覆盖、凭据覆盖拒绝、.bak 世代、损坏文件拒覆盖）。

### AUD-31700 — FIXED
`_open` 的 certifi try 块吞掉 opener 抛出的 OSError 家族异常并无条件重发同一 POST（重复请求/重复计费风险）。
**根因**：`self._opener(request, ...)` 在 `try: ... except (ImportError, OSError, TypeError)` 内，HTTPError/URLError/TimeoutError 均 OSError 子类，被吞后重发。
**修复**：try 块只护 `import certifi` + `create_default_context`；opener 调用移出 try，context 可用则附加参数，异常正常透传给 `_request_json/_request_bytes` 的既有契约映射。
**测试**：`TestAud31700NoDuplicateSend`（HTTPError 透传且仅发送一次；429 映射 GEN_PROVIDER_RATE_LIMITED）。

### AUD-31701 — FIXED
endpoint 未做任何验证：空/相对端点使 `urllib.request.Request` 在 try 外抛原始 ValueError 逃逸 provider 错误契约。
**根因**：Request 构造在 `_request_json/_request_bytes` 的 try 之外，`endpoint=""` 产生相对 URL 直接抛 `ValueError: unknown url type`；`generate()` 只捕获 `_VolcengineProviderError`。
**修复**：新增 `_validated_url()`（urlparse 校验 scheme∈{http,https} 且 netloc 非空，非法抛 `GEN_PROVIDER_CONFIG_INVALID`）；图像/TTS 两个 generate 均改用之；另加 `except Exception` 兜底将非契约异常（如 `_body` 内 int() ValueError）映射为 `GEN_PROVIDER_FAILED`，错误消息保持消毒（不含响应体/密钥）。
**测试**：`TestAud31701EndpointValidation`（3 个非法端点 + TTS 空端点 + 非契约异常兜底）。

### AUD-31702 — FIXED
`is_cancelled` 仅在网络请求前检查一次，阻塞 HTTP 期间完全不可取消。
**根因**：取消检查后紧接同步 `urlopen`（默认 120s 超时），期间取消无效果，结果仍落缓存并作成功返回；且取消检查排在 `_secret` 的 keychain/文件 IO 之后。
**修复**：两个 generate 均为三段检查：①入口（先于凭据 IO）；②阻塞响应返回后、写缓存/构造候选前——请求已发出无法撤回，但取消后的结果不再落盘/不再上报为成功。
**测试**：`TestAud31702Cancellation`（取消跳过凭据 IO get_calls==0；图像/TTS 阻塞期间取消丢弃响应 candidates==()）。

### AUD-31703 — FIXED
图像尺寸静默强制 2048×2048 正方形，`aspect_ratio` 请求字段被完全忽略。
**根因**：`_body` 只看 recipe.width/height，总像素不足 `3_686_400` 时直接 `width = height = 2048`，宽高比信息全丢。
**修复**：`_resolve_size`：recipe 显式宽高 → recipe.aspect_ratio → request.aspect_ratio → 2K 方形兜底；比率解析（`a:b`，容错 `axb`）后长边锚定 2048，再经 `_upsize_to_min_pixels` 等比放大至最小像素（偶数对齐）。16:9 → 2560×1440，1280×720 → 2560×1440，4096×2304 不变，无尺寸信息仍 2048×2048（与既有 wire 契约测试一致）。
**测试**：`TestAud31703AspectAwareSize`（6 例含比例保持与最小像素断言）。

### AUD-31704 — FIXED
多个 b64 候选写同一缓存文件 `{request_id}.png`，后者覆盖前者。
**根因**：`_cache_b64` 目标文件名只含 request_id，候选循环内多次 `os.replace` 同一路径。
**修复**：`_cache_b64` 增加 `candidate` 序号参数（与 asset_id 的 `-c{index+1}` 对齐），文件名 `{request_id}-c{index+1}.png`；`_candidates` 传入 `index+1`。
**测试**：`TestAud31704DistinctCandidateCacheFiles`（两候选两文件、内容各归各位）。

### AUD-31705 — FIXED
参考素材被静默丢弃，但 provenance 仍记录 `reference_asset_ids`/`reference_bindings`，溯源失真。
**根因**：`_body` 从不上传参考输入，而 `_provenance` 无条件记录 `request.effective_reference_*`。
**修复**：①新增 `_reject_reference_media`：携带参考素材的请求显式报 `GEN_PROVIDER_MEDIA_UPLOAD_BLOCKED`（图像/TTS 共用，不再静默降级为纯文生图）；②`_provenance` 只记录实际发送的输入——reference 字段恒空并注明理由，审计链路与事实一致。
**测试**：`TestAud31705ReferenceAssetsHonesty`（携带参考被拒；provenance 不记录未发送输入）。

### AUD-31800 — FIXED
cancel/cancel_all 持有互斥锁期间同步 wait(3000)，调用线程可被阻塞数秒且所有管理操作被锁死。
**根因**：`cancel` 全程持锁执行 `worker.wait(3000)`；`cancel_all` 逐个 cancel + 逐个 wait(3000) 全程持锁（最坏 3s×N）。
**修复**：锁内仅做 worker 摘取（pop）；`wait()` 移到临界区外（`_reap_worker`）。`cancel_all` 同一纪律：锁内摘取全部，锁外 cancel/wait。
**测试**：`TestAud31800CancelDoesNotHoldLock`（cancel/cancel_all 等待期间 `is_processing` 响应 < 0.15s）。

### AUD-31801 — FIXED
wait 超时后从 `_workers` 弹出 worker，运行中的 QThread 可能失去最后引用被 GC 销毁。
**根因**：ONNX `session.run()` 不可中断，`wait(3000)` 超时后线程仍在 run() 中，pop 丢弃强引用后 Python 侧对象可被回收 → C++ QThread 运行中被析构。
**修复**：`_reap_worker`：wait 返回 True 或 `isFinished()` 才丢弃；否则挂入 `_retired_workers` 保留强引用，由 `_prune_retired_workers_locked`（`is_processing`/`request_inference`/`cancel_all` 活动时触发）在线程真正结束后清理。
**测试**：`TestAud31801RetiredWorkerReference`（超时保留引用、finished 后清理、正常结束不滞留）。

### AUD-31802 — FIXED
tile_size/overlap 无关系校验：stride ≤ 0 时静默输出全黑图像或抛 ValueError；overlap == 1 时除零。
**根因**：`stride = tile_size - overlap` 可为 0/负（range 抛错或为空 → output/weight 全零 → 归一化出整幅黑图当作 finished 结果）；`np.arange(overlap)/(overlap-1)` 在 overlap==1 产生 inf/NaN 权重。
**修复**：①`_normalize_tiling`（tile 下限 128、overlap 钳到 `[0, tile//2]`，保证 stride>0），run() 入口统一应用；②overlap==1 时 ramp 退化为恒 1 权重（无除零）；③`total_tiles == 0` 显式抛 ValueError（走 error 信号），不再输出黑图。
**测试**：`TestAud31802TilingValidation`（4 组钳制断言、overlap=1 有限值、空瓦片计划抛错）。

### AUD-31803 — FIXED
用户取消以 RuntimeError("Cancelled") 抛出，被统一 except 捕获后走 error 信号 → 主动取消被上报为推理失败。
**根因**：取消复用异常通道，`except Exception` 将其连同 traceback 一起经 error/inference_failed 上报 UI。
**修复**：新增 `_InferenceCancelledError`；两处 `raise RuntimeError("Cancelled")` 改用之；run() 的 except 分支识别后静默返回（与既有 `if self._cancelled: return` 路径一致），真实异常仍走 error。
**测试**：`TestAud31803CancelledNotReportedAsError`（取消零信号；真实失败仍 error）。

### AUD-31804 — FIXED
输入侧无 HDR 范围处理而输出侧无条件 clip(0,1)，与"HDR 内部数据不得无理由 clamp"铁律冲突且行为不对称。
**根因**：HDR（>1.0）浮点输入未经归一直接喂按 [0,1] 训练的模型；输出无条件 `clip(0,1)` 截断高光；blend 又用未 clamp 的原图混合——同一管线值域不一致。
**修复**：`_hdr_scale_for`（浮点输入峰值>1 → 峰值，SDR/整数恒 1.0）；`_run_inference` 输入除以 scale 映射到模型域、输出对称乘回；`_postprocess` 的 nan_to_num/clip 以 scale 为上界（SDR 行为不变，HDR 恢复 [0, scale]），blend 两侧同域。
**测试**：`TestAud31804HdrRangeMapping`（scale 判定；透传模型下峰值 4.0 恢复 4.0；blend 同域）。

### AUD-31809 — FIXED
下载非原子且异常中断不清理残留文件：部分文件在下次启动被 `_sync_registry` 仅凭存在即标记为可用。
**根因**：直接写最终路径；仅显式取消分支清理；URLError/写盘异常路径不清理；`_sync_registry` 只看 `os.path.exists`。
**修复**：①下载写 `<name>.part`，成功后 `os.replace` 原子落位；②`finally` 统一清理 .part（成功路径已被 replace 消费，删除静默无害）；③`_sync_registry` 要求文件非空（size>0）才标记 available——注册表无真实 sha256（值全 None，不可凭空补造），非空校验是"外部数据须验证"在本数据源下的最小可行防线，补齐校验和需上游发布侧提供，超出本条范围。
**测试**：`TestAud31809AtomicDownload`（成功原子落位无 .part、网络中断清理、取消清理、零字节残留不标记可用；附 MODEL_REGISTRY 快照恢复 fixture）。

### AUD-31816 — FIXED
`PatchMerging.forward` 引用未定义名 `dim` → NameError，调用即崩（当前 DORMANT 未接线）。

**测试**：`TestAud31816PatchMergingForward`（前向 shape (1,64,4)→(1,16,8) 且有限值；源码无裸 `dim` 引用）。

### AUD-32001 — FIXED
icon_favorite_outline 实为实心星形，与 icon_favorite 完全相同，收藏两态视觉不可分辨。
**根因**：两函数/两映射都用 `fa5s.star`（solid 集）。
**修复**：outline 改用 FA5 regular 集 `fa5.star`（已对照本机 qtawesome 1.4.1 charmap：regular 含 `star`）；函数与 `ICON_MAP['favorite_outline']` 同步。

### AUD-32002 — FIXED
'fa5s.object-intersect' 字形在 qtawesome FA5 solid charmap 中不存在，布尔交集按钮图标恒为空白。
**根因**：FA5 free 仅有 object-group/object-ungroup；qtawesome 对未知字形抛 `Invalid icon name`，被 get_icon 宽泛 except 吞掉后返回空 QIcon（已在本机 QApplication 下复现该异常）。
**修复**：改用实际存在的 `fa5s.object-group`；函数与 `ICON_MAP['op_intersect']` 同步。另按审计建议在测试中加入 ICON_MAP 全量字形存在性校验（防同类问题再入库）——当前映射全部可渲染。
**测试**：`TestAud32002IntersectGlyph`（字形存在 + ICON_MAP 全量 sweep）。

### AUD-32003 — FIXED
icon_mask 的 SVG 成功路径完全忽略 color 参数，蒙版激活态橙色高亮永不生效。
**根因**：SVG 渲染按文件原色直接返回，color 仅在加载失败回退分支生效。
**修复**：SVG 渲染后以 `QPainter.CompositionMode_SourceIn` 叠加纯色层（QColor(color)）——保留 SVG 的 alpha 形状、颜色统一为请求色；回退分支不变。
**测试**：`TestAud32003MaskIconTinting`（可见像素全部为请求色——不透明像素精确匹配，部分透明抗锯齿边缘允许 8bit 预乘量化舍入（容差 max(8, 256/alpha)，实测仅边缘 ±10/255 内漂移）；激活/非激活两态颜色可区分）。
