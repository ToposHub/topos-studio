## 设计决策与残留说明

- **AUD-14109 的 AGENT 基线**：审计指出 8 个无注册种类，但 src 内唯一消费者是 chat_run_driver（`_MODE_TO_TASK_KIND` 含 agent/image/video/music/motion_graphic/chat）；AGENT 是其中唯一无注册者。为其注册 `reply_non_empty()`（agent 模式同样产出用户可见回复）而非 `no_tool_failure()`（后者是 AUD-14110 Suggestion 的范围，且工具失败语义更严，不宜在本批顺手扩大）。
- **AUD-14208 的 cancel 例外**：cancel None 跳过保留——"无取消发生"是合法的未观测可选指标；首 token 不同，runs>0 时它是必然被观测的硬指标（数据源 `agent_metrics._avg_ms` 仅在无样本时为 None）。
- **AUD-14300 的 0.0 语义**：原 `or 0.9` 把 `confidence=0.0`/`""` 强改为 0.9；修复后仅缺键/None/非法/非有限回退 0.9，合法数值（含 0.0）如实保留。
- **AUD-14310 的默认值语义变化**：默认（不传）从"全部素材授权"变为 None=显式不限，构造侧语义等价（`asset_in_scope` 对默认仍返回 True），但 `fingerprint()` 的 JSON 表示从 `[]` 变为 `null`——语义作用域确已改变（未圈定 vs 圈定空集），指纹变化是如实的。RESTRICTED_AUTO + 未圈定现在会被 `validate_run_context` 报 `SCOPE_REQUIRED_FOR_AUTO`。
- **AUD-14312/14313 的快照语义**：探测缓存把 GPU/git 事实视为进程生命周期常量（运行中 git HEAD/GPU 拓扑不变）；模型包/codec 探测每次构建照常执行，`refresh()` 对这些维度仍然真实重探。
- **锁定旧行为协议**（3 个测试文件、4 个断言更新，均锁定的是审计判定为缺陷的旧行为）：`test_postcondition_checker.py::test_no_postconditions_not_verified`（PASSED→FAILED，AUD-14109）；`test_release_gate.py::TestSoftWarnings` 两例（summary 补首 token 数据，AUD-14208）；`tests/ai/test_agent_w0_kernel.py::test_run_context_asset_scope`（空集=全部允许 → None=全部允许 + 空集=拒绝全部，AUD-14310）。无其他既有断言被修改。
