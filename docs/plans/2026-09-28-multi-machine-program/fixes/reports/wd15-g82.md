## 根因修复详情

### AUD-32101 color_metadata_config.py:69-76（原行号）
- 症状：`__post_init__` 警告宣称 "using 'bt709'/'limited'" 但从不改写字段，日志说谎且无效值原样下传编码器。
- 修复（言行一致方案，与 R-13「未知标签显式失败、不许默认值掩盖」哲学对齐）：
  1. 合法名单提升为模块级常量 `_VALID_PRIMARIES/_VALID_TRANSFER/_VALID_MATRIX/_VALID_RANGE`（单一真相）；
  2. `__post_init__` 警告改为诚实文案（"kept as-is (no 'bt709' fallback applied); downstream encoders may reject it"）——不做 guessed-default masking（错误地把 HDR 拼写变体改写为 bt709 是色彩管线更大的危害；下游 topos_encoder._map_color_codes 对未知值显式 ValueError，PyAV 侧映射未命中则跳过）；
  3. `from_metadata`（外部数据边界）新增 `cls._from_source`：None/"" → "unknown"（与旧 `or "unknown"` 语义一致）；名单外字符串带告警归一为 "unknown"（本模块的"缺失/不可用"标记），不再以无效字符串进入编码链。
- 既有行为兼容：`from_metadata` 对名单内合法值仍逐字段直通（tests/video/test_ffmpeg_encoder.py 的 from_metadata 用例继续通过）；"unknown" 仍属合法标记零告警。

### AUD-32104 decode_worker_budget.py:123-127,134-137
- 症状：锁内计算 updates 后释放锁再 `_apply_updates`，两个并发 acquire/release 的旧快照可后到先应用，终态 worker 数停留在过期分配。
- 修复：世代化串行——
  - `self._generation`：注册表锁内每次变更（acquire/release/reset_for_test）递增；
  - `self._apply_lock`：独立 apply 锁串行化回调下发顺序（仍不持注册表锁调用用户回调，避免重入死锁；回调内 `assigned()` 走 RLock 无死锁）；
  - `_apply_updates(updates, generation)`：apply 前比对 `generation < self._applied_generation` 即丢弃过期快照（debug 日志可观测），保证最终下发的一定是最新世代分配。
- `_apply_updates` 由 staticmethod 改实例方法（需访问 apply 锁/世代）。

### AUD-32108 slice_threads_policy.py:48-70
- 症状：`_native_set`/`_native_get` 裸 `except Exception` 零日志吞掉 ToposCodecError 等领域错误，native 下发失败完全不可见（register 静默"成功"）。
- 修复：
  - 两处均先独立捕获 `ImportError`（topos_binding 不可用），再以 `except (OSError, ToposCodecError)` 捕获域内错误，`logger.warning(..., exc_info=True)` 保留栈；
  - `_native_set` 失败仍 `_applied = None`（登记一致性不变，describe() 暴露"未下发"），`_native_get` 失败仍返回 0，但现在有可归因告警；
  - 名单外异常（如 RuntimeError）不再被吞，显式上抛（符合"禁止宽泛 except 掩盖领域错误"）。
  - 实现注意：ToposCodecError 与 ToposCodec 在同一 try 内导入，避免 except 子句 NameError（_native_get 首版漏导入已在测试中抓出并修正）。

### AUD-32201 topos_binding.py movie_config（原 :4166 起赋值区）
- 症状：width/height（c_uint16）、qp（c_uint8）、timescale（c_uint32）无数值域校验，ctypes 越界赋值静默取模回绕（实测 70000→4464、300→44），回绕值落入 C 侧合法域绕过 native 校验，静默产出错误分辨率/画质文件。
- 修复：在赋值区后增加四项显式 fail-fast（与同函数 profile/pixel_format/bit_depth/alpha 白名单风格一致），复用本模块既有常量：
  - `1 <= width  <= TC_CODEC_MAX_DIM`（16384）
  - `1 <= height <= TC_CODEC_MAX_DIM`
  - `0 <= qp     <= TOPOS_QP_MAX`（95）
  - `1 <= timescale <= 0xFFFFFFFF`
  - 均抛 `ToposCodecError`，消息注明回绕风险。
- 调用方（topos_encoder.py:1154、proxy_generator.py:640,967）传入值均来自产品设置域（≤8K/qp 0..95/标准 timescale），不受影响（tests/media、tests/export、tests/native 全量通过佐证）。

### AUD-32202 topos_binding.py ParallelSequentialDecoder.worker（原 :4362）
- 症状：worker 在 try 块之前构造 ToposMovieFile/ToposDecoder/lease，该段异常导致 worker 静默死亡不发完成哨兵，主线程 `out_q.get()` 永久挂起 + fd 泄漏。
- 修复：`movie/dec/lease` 全部改为 None 初始化并纳入唯一 try（`except BaseException → out_q.put((None, e))`）；finally 对已构造对象逐个判空释放（dec.close / lease.release / movie.close），部分构造失败时关闭已打开句柄。循环体语义（stop 令牌、首帧探测、物化拷贝）不变。

### AUD-32203 topos_binding.py ToposMuxFile._write_cb（原 :2488）
- 症状：顺序写回调无锁执行 `os.write`（移动共享 fd 偏移），与 `_seek_write_cb` 持 `_wlock` 的 Windows lseek→write→恢复指针模拟不对称，交错时可写错偏移（moov/mdat 错位）。
- 修复：`_write_cb` 的 `os.write` 移入 `with self._wlock:`——两侧互斥名副其实（POSIX 下 uncontended lock 开销可忽略，回调本身已有 string_at 拷贝主导）。

### AUD-32204 topos_binding.py:3396（decode_reduced）/decode_request/decode_batch
- 症状：三个入口保留逐帧 `(c_uint16 * (w*h))()` 全平面零填分配，C4 已在 decode() 中用 per-thread grow-only scratch 消除该成本（自述注释：4K444 每帧 47.7MB 零填把 ~22ms 解码拖到 ~45ms）。
- 修复：抽出 `_tile_output_planes(plane_sizes)` 方法（TLS scratch grow-only、各平面连续平铺、视图共享 scratch），四个入口统一复用：
  - decode() 重构为调用 helper（顺带消除 plane_geometry 双查询与死变量 widths）；
  - decode_reduced/decode_request：按帧平面平铺；
  - decode_batch：按批总量（帧×平面）平铺到同一 scratch。
  - 「返回 bytes 自有拷贝」契约不变（bytes(buf) 物化后才复用）。

### AUD-32307 topos_meta.py:123-127
- 症状：CRC 一致但 vendor/label 含非法 UTF-8 字节的载荷抛 UnicodeDecodeError，逃出 `read_export_meta` 只捕 ToposMetaError 的降级层，可打断本应成功的媒体打开（topos_image_source.py:159 打开路径）。
- 修复：两处 `.decode("utf-8")` 包 `try/except UnicodeDecodeError → raise ToposMetaError(...) from exc`（与 C 侧 MALFORMED 同语义，降级契约闭合）。顺带补齐本文件缺失的 `Optional` 导入（topos_image_tier_label 注解引用）。
