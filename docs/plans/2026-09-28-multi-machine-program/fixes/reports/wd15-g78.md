## FIXED 明细

### AUD-30703 — 多行拖拽视觉/文档脱节（layer_tree_panel.py:488-499）
- 根因：`_rows_moved` 对 `start != end`（块移动）直接 return。Qt 已改动列表视觉顺序，既不提交命令也不重建，
  界面与文档（undo 栈/序列化/绘制）持续脱节；Qt 拆成多次单行 rowsMoved 时同样只提交 currentItem 一行。
- 修复：`start != end` 或 `len(selected_row_ids) > 1`（多选拖拽的两种 Qt 粒度）时，立即 `self._rebuild(self.selected_row_ids)`
  按文档行回滚视觉状态——不产生部分提交，拖拽可见地弹回文档顺序；`self._updating` 程序化守卫保持不变；
  单选拖拽（start==end 且单选）原有提交路径不变。
- 测试：4 项（单行拖拽仍提交 reorderRequested(rid, tuple)；块移动回滚且零提交；多选单行 rowsMoved 同样回滚；
  _updating 守卫不重建）。

### AUD-30800 — 硬编码 Space 播放键（mg_keyframes_panel.py:1166-1174、1864-1870）
- 根因：`_TreeSide.keyPressEvent` 与 `_TrackSide.keyPressEvent` 直接比较 `Qt.Key.Key_Space`，
  绕过 `mg_shortcuts` 的可配置绑定；用户改绑后 Space 仍触发且与新键形成双入口。
- 修复：两处改用 `event_matches(event, PLAY_PAUSE_ACTION_ID, PLAY_PAUSE_DEFAULT)`（导入自 `.mg_shortcuts`，
  与宿主窗口 keyPressEvent 2944 行同款入口），跟随用户配置的快捷键。
- 测试：3 项（默认 Space 两处均触发；monkeypatch configured_shortcut 为 "P" 后 Space 不再触发而 P 触发；
  event_matches 反映改绑）。

### AUD-30901 — save() 无保护（motion_graphic_editor_window.py:2989-2997）
- 根因：Ctrl+S / 关闭保存路径裸调宿主 saver 与缓存协调器，磁盘满/权限/网络盘失联时 OSError 直接穿入 Qt 槽。
- 修复：saver 包 `try/except (OSError, RuntimeError)`——失败时 statusBar 提示并提前返回；
  `editor_controller.save` 只在 saver 返回后才清脏标记，用户保留重试机会；`coordinator.schedule` 包
  `(ImportError, RuntimeError, TypeError, ValueError)`（对齐同文件 `_start_full_preview_cache` 的既有防护）。
- 测试：3 项（OSError 受控且保持 dirty；RuntimeError 受控；coordinator 失败不影响保存成功与 mark_clean）。

### AUD-30902 — DevTools 关闭保存路径静默丢弃（motion_graphic_editor_window.py:2194-2248）
- 根因：`_apply_html_source` 无返回值，内部失败被吞后成功消息照发、closeEvent 的 Save 分支仍 save+close，
  DevTools 更改静默丢失；空源早退与构造失败分支均滞留 `_close_after_devtools_apply`，之后任意一次手动 Apply
  意外触发 save+关闭。
- 修复：`_apply_html_source` 返回 bool；`_apply_live_dom_source` 所有出口统一经新 helper
  `_finish_devtools_apply_close(applied=...)`——任何路径都清除标志；applied=False 时保持窗口打开（脏状态保留），
  applied=True 才 save + `QTimer.singleShot(0, close)`；回退路径仅在 applied 时清 devtools pending 标志并显示成功消息。
- 测试：4 项（空源早退清标志不开窗；apply 失败不保存不关闭；无 html_layer 的 apply 失败保持打开；
  成功路径 save 被调、标志清除、close 经事件循环送达）。

### AUD-30903 — 拖拽每 tick 全量刷新（motion_graphic_editor_window.py:427、1706）
- 根因：两处 `subscribe(lambda scene, _diff: self._refresh_scene(scene))` 丢弃 diff；画布拖拽每个 mouse-move
  走 `preview_element` → 通知 → 图层树/关键帧/分镜/native overlay 全量重建。
- 修复：订阅改接 `_on_scene_notified(scene, diff)`：拖拽激活（`_drag_anchors` 非空）且 diff 为纯 transform
  字段、无 duration/pages/animation 变化、SVG 场景（html_layer 为 None——HTML 场景的 native overlay 需要
  全量刷新）时走新增轻量路径 `_refresh_transform_preview`（仅注册 store + 重算 page view + 重渲画布），
  其余一律全量刷新；`_on_drag_finished` 改为先清 anchors 再 commit，保证提交/undo/redo/时长/页面/标记等
  通知始终全量刷新（注意：SceneDiff 不追踪 markers/metadata，"空" diff 也必须走全量路径——见下方回归说明）。
- 修复过程中发现并消除的本批回归：初版对 `diff.is_empty` 提前 return，导致 AddMarkerCommand（diff 不含
  marker 字段）不再刷新时间轴标记，`tests/ui/test_motion_graphic_manual_controls.py::test_page_apply_is_one_undo_operation_and_markers_are_visible`
  失败；同时收紧 light 路由条件（新增元素无 changed_fields 条目时不得走轻量路径，防止图层树不显示新元素）。
  修正后该测试及全套邻接测试通过，未按锁定旧行为协议改动任何既有测试。
- 测试：5 项（拖拽期间 3 次 tick 仅 3 次画布渲染、0 次面板重建，释放后全量刷新且一次 undo 完整回位；
  空 diff 走全量；新增元素即使拖拽中也走全量；duration 变更不走轻量路径）。

### AUD-30904 — execute 在 try 之外（motion_graphic_editor_window.py:2204-2227）
- 根因：异常保护只包住 `ReplaceHtmlSourceCommand(...)` 构造（纯 dataclass，永不抛），真正的校验在
  `command.apply`（空源/sanitizer ValueError），`execute(CompositeCommand(...))` 在 try 外，异常穿入按钮槽。
- 修复：`execute(CompositeCommand(...))` 移入同一 try/except `(TypeError, ValueError)`；命中时走原有的
  native-only 回退（提交可映射的属性编辑并明确报告 authored 失败），不再逃逸。
- 测试：与 AUD-30902 共用（flaky_execute 首次调用抛 ValueError：断言组合命令尝试后 native 回退被执行、
  无异常逃逸、不保存不关闭）。

### AUD-31006 — 多选 Content 覆写 dict 内容（scene_inspector.py:573-574 + 宿主 _selection_updated）
- 根因：多选分支 `selectionUpdateRequested.emit(ids, {"content": value})` 把纯字符串原样应用到每个选中
  图元；shape/chart/path 的 dict content（kind/points 等几何数据）被整体替换为字符串，渲染持续报错且保存后
  永久丢失。
- 修复（在宿主 `_selection_updated` 单点归一化，保护所有发射方）：`update["content"]` 为 str 且目标元素
  content 为 dict 时改写为 `{**element.content, "text": value}` 合并——与 inspector 单选分支同一语义；
  仍是单条 CompositeCommand（一次 undo 整组恢复）。
- 测试：1 项（text 得到字符串、shape 得到带 text 键的 dict 且 kind/corner_radius 保留；一次 undo 两组均还原）。

### AUD-31007 — Transform 行逐 tick undo（scene_inspector.py:553-566、925-942）
- 根因：`_add_number_row` 的 slider/drag 每个 valueChanged 刻度直接调 `_transform_changed()` →
  `elementUpdateRequested` → 每刻度一条 UpdateElementCommand（全场景不可变重建 + 独立 undo 条目）。
- 修复：接入同文件既有的延迟提交模式——刻度仅置 `_pending_transform_change`；`drag.interaction_ended`
  （DragValue 对指针拖拽/内联编辑/滚轮缺口均成对发射 started/ended）与 `slider.sliderReleased` 时一次性提交
  `_transform_changed()`；`_updating` 程序化同步不触发（与 style/layout/shape 行一致）。
- 测试：3 项（两次刻度零发射、一次 interaction_ended 恰一条更新；多选走单条 transform_patch；无 pending
  的 stray release 静默）。

### AUD-31009 — 时长 DragValue 逐 tick SetDurationCommand（scene_timeline.py:133-137）
- 根因：`duration_spin.valueChanged` 直接 `durationChangeRequested.emit(...)`，宿主每刻度执行一条持有整景
  快照的 SetDurationCommand；拖 1s→10s 产生上百条 undo。
- 修复：`valueChanged` 仅暂存 `_pending_duration_seconds`；`interaction_ended` 一次性 emit 最终帧数
  （一次手势一条命令）；`set_scene` 的程序化 setValue 原有 blockSignals 语义不变（不暂存、不发射）。
- 测试：3 项（两刻度一提交且值为 round(2.5×24)=60；两次手势两次提交各 24/36；set_scene 不发射）。

### AUD-31011 — QSvgRenderer 无限累积（scene_view.py:87-103）
- 根因：`QSvgRenderer(QByteArray(...), self)` 以 self 为父，Python 侧替换引用不销毁 C++ 对象；
  `_refresh_scene` 每个控制器通知新建一个，编辑会话内存单调增长。
- 修复：新增 `_discard_renderer()`（置 None + `deleteLater()`，paint-safe），`set_frame` 的 svg/rgba8 两分支
  与 `set_scene` 的缓存失效路径统一走它；旧 renderer 退役后不再被 paint 路径触达。
- 测试：3 项（svg→svg、svg→rgba8、场景切换三条路径各退役一次旧 renderer）。

### AUD-31201 — 启动致命路径 sys.exit(1)（main.py:305-312）
- 根因：顶层 except 走 `sys.exit(1)` → SystemExit → 完整解释器终结化——正是本文件 docstring 记载的
  Qt6Core fail-fast 0xc0000409 / 随机段错误场景；且不停线程池与缩略图 ffmpeg 子进程。
- 修复：except 分支记录 traceback 后改调 `_orderly_shutdown(app, 1)`（停 QThreadPool → 停缩略图 worker →
  flush → `os._exit(1)`）；`app` 在 try 前初始化为 None，`_orderly_shutdown` 签名放宽为
  `QApplication | None`（函数体从不使用该参数，仅保持调用点对称）；正常路径 `_orderly_shutdown(app, rc)` 不变。
- 测试：2 项（monkeypatch QSurfaceFormat.setDefaultFormat 令启动早期失败：main() 不再抛 SystemExit、
  `_orderly_shutdown` 以退出码 1 被调用；签名注解接受 None）。
