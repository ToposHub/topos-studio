## 逐条处置

### 1. BUG-B3-02（Minor）Restore Defaults 漏掉 smart 阈值；DEFAULT_CONFIG 缺键 — FIXED

- 位置核实：`_on_restore_defaults()` Render Cache 段确无 `render_cache_auto_threshold`；`config_manager.py` 中 grep 无该键。问题存在。
- 修复：
  - `DEFAULT_CONFIG` 增 `"render_cache_auto_threshold": 6`（紧跟 `render_cache_auto_mode`，带注释）；
  - restore 段补 `self._widgets['render_cache_auto_threshold'].setValue(int(defaults.get('render_cache_auto_threshold', 6)))`。
- 附带：`pass_fusion_mode` 在 DEFAULT_CONFIG 同样缺键（B3-04 只提 restore 漏重置），按硬约束一并在 Performance 段补默认键 `"conservative"`。

### 2. BUG-B3-03（Minor）Timeline 分辨率预设下拉与配置不同步 — FIXED

- 位置核实：`_load_current_settings()` Timeline Defaults 段只回填 `_tw`/`_th` spinbox，`_timeline_res_combo` 恒停第 0 项。问题存在。
- 修复（根因：下拉构造时未携带预设数据，load 无法反查）：
  - `res_combo.addItem(item[0], (item[1], item[2]))` —— 预设尺寸存为 itemData；
  - 新增 `_sync_timeline_res_combo(width, height)`（带类型注解）：按 (w,h) 反查匹配项，无匹配落末项 "Custom"；Custom 的 (0,0) 使 `_on_timeline_res_preset_changed` 不覆盖宽高；
  - load 与 restore 均在回填 spinbox 后调用同步（restore 后默认 1920x1080 → "1080p"）；
  - 同步触发 `currentIndexChanged` 仅写入相同值（预设项）或不写（Custom），无数据篡改；load 时预览信号尚未连接（构造顺序 `_load_current_settings` → `_connect_preview_signals`），无副作用。

### 3. BUG-B3-04（Minor）Restore Defaults 漏掉 Pass Fusion Mode — FIXED

- 位置核实：`_on_restore_defaults()` Performance 段确无 `pass_fusion_mode`。问题存在。
- 修复：Performance 段补 `self._select_combo_by_data('pass_fusion_mode', defaults.get('pass_fusion_mode', 'conservative'))`；DEFAULT_CONFIG 补默认键（见第 1 条附带）。

### 4. BUG-B4-02（medium）_enforce_page_dock_visibility 漏掉 dock_caption_workspace — FIXED

- 位置核实：`edit_only` 列表为 8 项，确无 `dock_caption_workspace`；方法其余分支亦未引用。问题存在。
- 修复：`edit_only` 追加 `self.dock_caption_workspace`（属性在 `setup_docks` L560 无条件初始化为 None，列表成员统一走既有 `if d is not None` 判空，安全）。
- 顺序核实：`page_controller.switch_to_page` 先设 `current_page` 再调 enforce，Edit 页不受影响。

### 5. BUG-B4-03（medium）initialize_page_layouts 的页 dock 隐藏清单漏掉 dock_deliver — FIXED

- 位置核实：收尾隐藏段（~L1449）确不含 `dock_deliver`/`dock_node_properties`；两段前置清单亦不含；`_enforce_page_dock_visibility` 无 Deliver 分支（证据文档"附带发现"）。问题存在。
- 修复（按证据文档"建议修复方向"全量落实）：
  - 收尾隐藏清单补 `self.dock_deliver, self.dock_node_properties`；
  - 两段前置隐藏清单（saved-layout 分支 ~L1126、first-run/factory 分支 ~L1170）同步补齐对齐；
  - 硬编码兜底分支自身的前置清单（~L1207，文档未单列但同族缺口）一并补齐——满足"dock 可见性强制清单不得漏项"不变量，且有新源码级测试锁定；
  - `_enforce_page_dock_visibility` 补 `if self.current_page != "Deliver": hide dock_deliver`。与 Deliver 页激活无冲突：`current_page` 先于 enforce 赋值，且 `_migrate_deliver_layout`（负责在 Deliver 页显示该 dock）在 page_controller 中延迟 50ms 执行。
