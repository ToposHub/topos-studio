## 逐条结论

### AUD-23001 [Major/bug] capabilities() 解析结构与真实 /object_info 不符 — FIXED

- 根因确认：`for input_spec in (info.get("input") or {}).values(): if isinstance(input_spec, list)` ——
  真实格式中 `input` 的 values 是 `{"required": {...}, "optional": {...}}` 的 dict，
  `isinstance(list)` 恒 False，模型候选永远收集不到 → `available_models` 恒空集 →
  Real 路径 preflight 必然 MISSING_MODEL。
- 修复：按 `input.required` / `input.optional` 两段遍历；每个输入 spec 形如
  `[候选列表|类型名, 配置]`，仅当 `spec[0]` 是 list 时收集其中含 "." 的字符串候选
  （loader 输入的候选列表即 server 模型文件名）。带真实结构 fixture 的测试
  （required + optional 两路 + Real 路径 preflight 闭环）。
- 测试：`TestAud23001CapabilitiesParsing`（2 用例）。

### AUD-23002 [Major/bug] job_outputs 吞掉下载异常并永久置 outputs_fetched=True — FIXED

- 根因确认：`except _ComfyHttpError: warning` 后无条件 `record.outputs_fetched = True`，
  瞬时网络错误被固化为"无产物"或 `sha256:pending-download` 占位 hash 候选；失败时
  `open(target, "wb")` 半成品文件残留。
- 修复（两侧）：
  - client：失败时记 warning 后 **re-raise**，`outputs_fetched` 保持 False（下轮可重试）；
    `_download_outputs` 三条失败路径（HTTPError / 网络 / 超限）均 `target.unlink(missing_ok=True)`
    清理半成品；
  - executor：`fetch_outputs` 捕获 `job_outputs` 异常映射为 `SERVER_FAILED` 诊断返回
    （与 `submit_job` 的 SUBMIT_FAILED 包装同模式），不再让异常穿透 generate。
- 测试：`TestAud23002OutputsFetchRetry`（4 用例：失败可重试、半成品清理、网络恢复重试成功、
  executor 映射 SERVER_FAILED）。

### AUD-23003 [Major/bug] 下载路径直接拼接 server 返回 filename（无穿越校验）— FIXED

- 根因确认：`target = self._download_dir / f"{job[:12]}_{out.filename}"`，`out.filename`
  来自外部 server `/history` 响应，`"../../x"` 可写出缓存目录。
- 修复：`Path(out.filename).name` 只保留纯文件名（空/"."/".." 拒绝，
  `_ComfyHttpError("INVALID_FILENAME")`）；拼接后断言 `target.resolve()` 仍在
  `self._download_dir.resolve()` 之下（`UNSAFE_PATH`）。查询 server 的 `/view` URL
  仍用原始 filename（server 侧语义不变），仅落盘路径防护。
- 测试：`TestAud23003PathTraversalGuard`（穿越 filename 被净化为 basename，目录外无文件）。

### AUD-23004 [Major/bug] cancel() 对 QUEUED 任务乐观置 CANCELLED 但 /interrupt 不出队 — FIXED

- 根因确认：`POST /interrupt` 仅打断正在执行的任务，QUEUED 任务需 `DELETE /queue`
  （body `{"delete": [prompt_id]}`）才会移除；原实现让 executor 停止轮询而 server
  继续执行（本地浪费 GPU / 云 profile 浪费费用）。
- 修复：QUEUED → `DELETE /queue`，成功即 CANCELLED（`dequeued (cancel requested)`）；
  出队失败退回 `POST /interrupt` 尽力而为；RUNNING → /interrupt（原行为）；终态 no-op。
  模块 docstring 的取消语义描述同步更新。
- 测试：`test_comfyui_client.py::TestCancel` 更新为 3 用例（RUNNING→interrupt、
  QUEUED→DELETE /queue、出队失败退回 interrupt）。

### AUD-23011 [Major/bug] 默认 poll_timeout_s=30s 过短且宿主未覆盖 — FIXED

- 根因确认：真实 SDXL 生成普遍 >30s；宿主 `ai_editing_mixin.py:784-787` 装配
  `ComfyWorkflowExecutor(server=client, ...)` 未传 timeout → 用默认 30s → 长任务
