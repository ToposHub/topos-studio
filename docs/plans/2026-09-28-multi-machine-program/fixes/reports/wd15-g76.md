## FIXED 明细

### AUD-30100 — CSS 动画名内插原始 element_id（html_native_overlay.py:446，波及 452/456/484/486）
- 根因：`groups[f"topos-a-{element.element_id}-{prop}"]` 与 `@keyframes {name}`、`animation:{name}` 直接内插原始 id；
  `SceneElement.from_dict` 接受任意非空字符串 id，含空格/引号/`{}`/`;` 的 id 生成非法 CSS 或注入规则。
- 修复（按 wd14-g75 处方）：新增 `_css_safe_identifier`/`_animation_name`——id 先映射到 `[A-Za-z0-9_-]`；
  映射改变了 id 或与其他元素的安全 token 冲突时，追加 raw id 的 sha256 前 8 hex 消歧（确定性、跨机器稳定）；
  clean id 保持旧名形态（`topos-a-<id>-<prop>`），不破坏既有渲染/CSS 兼容。
- 测试：3 项（敌意 id 下所有 @keyframes 名与 animation 引用均为合法 ident 且集合一致；"a b"/"a_b" 冲突对获得不同名；
  clean id 保持旧名形态）。

### AUD-30101 — `native_overlay_css_variables` 未校验 token 名/值（html_native_overlay.py:609）
- 根因：`css_variables(tokens)` 的名/值来自场景 metadata/品牌主题（外部数据），`DesignTokenSet.from_dict._colors` 无字符集校验，
  `}`/`;` 可逃出声明破坏或注入整条规则。
- 修复：声明进入样式表前逐一校验——名必须匹配 `^--[A-Za-z0-9_-]{1,96}$`，值必须匹配
  `^#[0-9a-fA-F]{3,8}$` 或纯数字/长度（`px/%/s/ms`，含指数形式），不匹配的声明直接丢弃（默认 token 集 hex+px 全部通过，无行为回退）。
- 测试：2 项（敌意名/值被丢弃、合法 token 保留且无法追加规则；全部非法时返回空规则）。

### AUD-30120 — VP8 路径 stderr=PIPE 全程不排水（html_realtime_recorder.py:292/351/353/377-378）
- 根因：ffmpeg 默认向 stderr 持续输出；stderr 仅在 `process.wait()` 之后读，管道缓冲填满后 ffmpeg 阻塞在写 → 停止消费 stdin
  → writer 阻塞 → 队列（maxsize=48）填满 → 结尾阻塞 put 永久挂起。
- 修复：①命令提为 `_vp8_encode_command`，加 `-nostats -v error`；②新增 `_drain_pipe_lines`，stderr 由独立守护线程全程排水，
  chunk 在进程退出后拼接；③`process.wait(timeout=max(60, duration*4))` 超时 kill 并抛结构化 RuntimeError。
- 测试：3 项（命令含 -nostats/-v error；fake 管道读到 EOF；关闭的流不抛错）。

### AUD-30121 — writer 死亡后阻塞 put 永久挂起（html_realtime_recorder.py:245/349-353）
- 根因：writer 线程首次 `stdin.write` 抛 BrokenPipeError 即退出消费循环；收尾的无限阻塞 `put` 在满队列上挂死，
  `writer_errors` 的 RuntimeError 分支不可达。
- 修复：新增 `_enqueue_with_writer_check`——0.25s 切片限时 put，每片先检查 `writer_errors` 非空或 writer 线程已死即抛
  RuntimeError；总体超时兜底。收尾填充循环与哨兵 `None` 均改用它；该路径抛错时先 kill 残留 ffmpeg 再上抛；
  writer join 超时同样 kill + 结构化报错。
- 测试：4 项（死线程快速失败；writer_errors 浮出；满队列+活 writer 超时；有消费者时正常入队）。

### AUD-30122 — 守卫移除失败被静默吞掉（html_realtime_recorder.py:125/97-99/520-521）
- 根因：`_remove_recording_guard` 的 `except Exception: pass` 依赖并不存在的下游校验（模块结束只查文件存在/大小），
  evaluate 失败即导出整片 `visibility:hidden` 的空白视频并报成功。
- 修复：fail-closed——evaluate 内联"移除后重读 DOM"，返回守卫是否仍存在；evaluate 抛错或守卫仍在均抛 RuntimeError
  中止录制（调用方 export_service 以异常路径处理，不再静默交付）。
- 测试：3 项（移除成功正常返回；守卫仍在→中止；页面不健康→中止）。

### AUD-30130 — release() 的工厂异常覆盖返回值且池缩水（html_renderer_service.py:118/204-205）
- 根因：`release(healthy=False)` 内 `self._idle.put(self._factory())` 在 `render_frame` 的 finally 中执行，
  工厂抛异常会替换已构造好的 CaptureFailure 返回值，且旧 worker 已关、新 worker 未入池，池永久少一个。
- 修复：release 绝不抛——工厂失败记为"欠账"（`_deficit += 1`，`_factory_errors` 留诊断），`acquire()` 在队列空时经
  `_rebuild_owed_worker` 惰性重试补齐（失败则恢复欠账）；新增 `pending_rebuilds`/`last_factory_error` 只读属性。
- 测试：2 项（工厂失败时 render_frame 仍返回结构化 CRASH 失败、欠账=1、错误可查；下次 acquire 惰性补齐、欠账=0）。

### AUD-30131 — close() 与 release() 竞态泄漏 worker（html_renderer_service.py:105-113/210-223）
- 根因：release 无锁读 `_closed` 后 put；时序"release 过检 → close 置位+drain 空池 → release put"使该 worker
  无人关闭（Chromium 进程泄漏）且服务已 closed 无法补救。
- 修复：release 的 closed 检查与 put 全程持 `_lock`（与 close 置位同一把锁）：put 发生在置位前必被 drain 收走，
  发生在置位后则看到 closed 直接丢弃并 `_close_quietly`；替换用的新 worker 入池同样持锁复查 closed。
- 测试：2 项（close 后 release 丢弃且不入队、backend.close() 被调用；并发 close+acquire/release 压力循环中
  所有曾创建的 worker 要么在池中要么已关闭，零泄漏）。

### AUD-30203 — 安全门对脚本/API 类攻击空转（html_spike.py:167-176/270-271）
- 根因：无 URL 的 fixture 被映射为 `about:blank` 占位请求，以 "unrecognized_scheme" 拒绝即判 denied；
  `expected_denial_reason` 全仓库无断言消费。
- 修复：①`_requests_for_attack` 移除占位请求（返回空元组）；②`evaluate_security_corpus` 分类消费期望——
  期望属 URL-policy reason 集合（`_URL_POLICY_DENIAL_REASONS`，与 security.py 字面量同步）时必须精确匹配，不匹配即
  denied=False（附期望/观测 reason）；无请求或期望属能力族（script/popup/storage/…）时经 `_sandbox_denial_for_vector`
  对严格 CSP 头（script-src 'none'、frame-src/object-src 'none'、form-action 'none'）与 `DISABLED_FEATURES` 矩阵实证，
  未覆盖即 denied=False。全部 24 个 fixture 仍 denied=True（既有门禁语义不变），但每个裁决都有非空转依据。
- 测试：6 项（全 corpus 仍 denied；无 about:blank 占位；7 个脚本/API 类 fixture 的 reason 为 csp_*/disabled_feature:；
  URL reason 精确匹配抽样；构造 reason 不匹配 fixture → denied=False；构造未映射向量 → fail-closed；宽松 CSP 不算覆盖）。

### AUD-30205 — `_inject_csp_meta` 的 `<head[^>]*>` 误匹配 `<header>`（playwright_backend.py:1051-1054）
- 根因：`[^>]*` 吃掉 "er ..."；无 `<head>` 但 body 含 `<header>` 的页面 meta 落在 body 被浏览器忽略，CSP 防线静默失效。
- 修复：正则收紧为 `<head(?:\s[^>]*)?>`（`<head` 后必须是空白或紧接 `>`）；无真 head 的文档走既有 `<html>` 包裹回退。
- 测试：2 项（仅含 `<header>` 的文档 meta 落入新造 `<head>`；含真 head 的文档 meta 位于 head 内最前且不被 body 的
  `<header>` 吸引）。

### AUD-30206 — screenshot clip 以物理像素传入（playwright_backend.py:740-741/843-846/1013-1015）
- 根因：Playwright clip 语义为 CSS 像素；dpr≠1 时 clip（物理）大于 CSS 视口，且 `round(w/dpr)*dpr != w` 的组合
  （如 dpr=2 奇数宽）输出尺寸≠surface，全部捕获报 "png decode failed"。
- 修复：①clip 改用 `css_w`/`css_h`；②入口（浏览器启动前）预检 `round(css_w*dpr)==width and round(css_h*dpr)==height`，
  不可整除回退的组合直接返回 INVALID_INPUT（带可操作信息），不再让解码层背锅。
- 测试：2 项（1081×721@dpr2 返回 INVALID_INPUT 且未启动浏览器；capture 源码 clip 使用 css_w/css_h 而非 surface 物理
  尺寸）。

### AUD-30207 — 虚拟时钟超限后静默跳变（playwright_backend.py:357-372）
- 根因：步数（2400）或实时预算（2500ms）耗尽后直接 `state.now = target`，积分式动画少执行若干步，

  virtual_clock 字段同样携带 jumped。
- 测试：2 项（_CLOCK_SHIM 含 jumped 置位与返回；capture 对 jumped 返回结构化失败）。

### AUD-30208 — DOM 诊断在主路径无条件执行（playwright_backend.py:825-833/537-540/548-556）

- 测试：1 项（capture 源码不变式：uniform 分类先于 _DOM_DIAGNOSTICS，且诊断调用位于 `if uniform:` 守卫内）。

### AUD-30214 — 具名 QWebEngineProfile 是磁盘型 profile（qt_capture_backend.py:141-143）
- 根因：`QWebEngineProfile("topos-spike-ephemeral")` 带 storageName 即磁盘型；`NoPersistentCookies` 仅降级 cookies，
  HTTP 磁盘缓存/localStorage/IndexedDB 落盘残留，与"无残留"注释/门禁矛盾。
- 修复：无名构造 `QWebEngineProfile()`（off-the-record）+ `setHttpCacheType(MemoryHttpCache)`（AttributeError 防御

### AUD-30218 — 主机白名单解析与 URL 规范不一致（security.py:150-153）
- 根因：host 提取按 `/`/`@`/`:` 手写 split 链；`https://evil.example\@allowed.com/x` 的候选串按 `@` 切出
  `allowed.com` 命中白名单判 ALLOW，而 WHATWG 规范下 `\` 等价 `/`，浏览器实际连 `evil.example`；
  `\n`/`\r` 等控制字符也不在 whitespace 检查内。
- 修复：①含 `\` 或 ASCII 控制字符（C0/DEL）的 URL 直接 DENY（`url_contains_backslash_or_control`）；
  ②host 改用 `urllib.parse.urlsplit().hostname`（标准 authority 文法：userinfo/端口/IPv6 括号/小写化），
  新增 `_network_host`，解析 ValueError（畸形 IPv6）或空 host → `network_host_missing` DENY。
- 测试：6 项（反斜杠混淆拒绝；4 类控制字符拒绝；userinfo/端口/大小写/尾点按浏览器语义解析放行；
  子域伪装拒绝；空/畸形 host 拒绝；严格策略整体拒绝网络不变）。

### AUD-30300 — `resolve_bound_image_bytes` 宽泛 except 吞掉所有错误（html_scene_renderer_v2.py:150）
- 根因：`except Exception: pass` 把磁盘 IO、API 变更 TypeError、解析错误全部静默吞掉，图片降级占位符且无日志，
  违反"不得宽泛 except 掩盖领域错误"铁律。
- 修复：只捕获可降级类 `(ValueError, TypeError, OSError)`（AssetPreflightError 是 ValueError 子类、dict-shaped scene
  是 TypeError、读盘失败是 OSError），并以模块 logger 记 warning（含资产数、异常类型与消息）；其余异常向上传播。
- 测试：2 项（preflight ValueError → 空 dict + warning 日志；RuntimeError → 上抛）。
