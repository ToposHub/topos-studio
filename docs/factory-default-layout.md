# 出厂默认布局（Factory Default Layout）

## 背景

历史上 "Reset to Default" 的恢复来源是运行时可写的 DB 记录（`layouts` 表 `is_default=1`）
与 `.topos/default_layout_seed.json` 种子文件。它们都能被用户的 "Set as Default"
覆盖——一旦保存了坏布局，默认布局就被永久污染，用户再也回不到干净的默认状态。

## 机制（2026-08 起）

默认布局的唯一来源是**随仓库提交**的 `default_layout.json`（项目根目录）：

```
{
  "schema": 1,
  "modes": {
    "video": { "geometry": "<hex>", "state": "<hex>", "panel_states": { "<页面>": "<hex>" } },
    "image": { ... }
  }
}
```

要点：

1. **按工作模式分桶**：视频模式与图片模式布局不同，各存一份。模式无自己的捕获时
   回退 `all` 桶，再回退旧版扁平结构；缺少当前页面的有效出厂快照时，使用代码内的页面默认布局。
2. **只能通过提交变更**：该文件是受版本控制的源码文件。运行时没有任何用户操作能
   改写它（旧 "Set as Default" 菜单已移除），拖乱布局不影响默认布局本身。
3. **首次启动**：无任何已保存布局时，用出厂文件播种 `page_layouts`，新用户看到的
   就是调优后的默认布局。
4. **打包构建**：文件随可执行文件分发（`sys.executable` 同目录）。

## 工作区面板

顶部工具栏以居中的橙色标签切换工作区。应用菜单在左侧，当前页的面板入口按功能放在两侧，开启的面板会高亮图标。窗口宽度不足时自动收起图标旁的文字，悬停仍可查看按钮名称。工具栏右键菜单的「显示图标文字」选项会记住用户偏好。停靠标签组居中显示。停靠面板通过顶部入口或「窗口 → 面板」管理。

切页时在内存中立即保存停靠面板的显隐与尺寸，短间隔内的布局变更合并写盘。关闭一组面板时，另外记录打开的标签及前台标签，召回时恢复。

工具栏的「布局预设」只列出当前页面的预设，并显示该页选中的单页预设。「窗口 → 重置为默认」重新应用该页选中的预设。选中整套布局时，重置只重新应用其中的当前页。没有选中可用预设时，使用当前页的出厂默认布局。照片和视频调色页均内建「横屏调色」，各自使用本页的出厂比例。

「窗口 → 保存布局」默认选择「当前页面」，也可保存「所有页面」。单页预设写入 `page_layout_presets`，以工作模式、页面和名称区分。整套预设在 `layouts` 的 `panel_states` 里存放各页快照。「窗口 → 加载布局」可应用整套，也可从整套预设提取当前页。「窗口 → 删除布局」按相同范围操作。应用窗口的位置和大小由用户单独调整。升级时，从旧预设的各页快照迁入对应的页面，缺少页面标记的旧预设无法自动归类。

Studio 保存时分开写入 `studio_image` 与 `studio_video` 布局。切换工作模式的设置从下次启动生效，当前窗口始终保存到它实际运行的模式。缺失的页面从对应出厂布局或代码默认布局补齐。

视频导出页左侧是导出设置，右上是预览与渲染队列，右下是横跨两者的时间线。进入时自动缩放以显示完整时间线。「整条时间线」的范围条从第 0 帧到最后一个片段的末帧。拖动任一端后，渲染范围切换到「入点／出点」。较窄的窗口会优先收紧默认的设置栏与队列宽度，为预览留出空间。右侧上下区随窗口高度缩放。渲染队列可单独隐藏或浮动，重启后恢复内嵌状态、显隐和手动调整的宽度。

混音页左上是混音器，以及共享标签组的媒体池与音频效果，右上是视频监看。下方时间线顶部用一行摆放播放、录音、编辑工具和立体声主输出表，时间码位于标尺左侧。音频时间线与视频监看共用同一工程的命令历史和播放控制。升级时，旧默认摆位中的媒体池与音频效果会移到混音器旁，旧主输出停靠区由时间线填满。可在混音页使用“窗口 → 重置为默认”应用出厂摆位。

## 维护流程（更新出厂默认布局）

"设为默认"入口只在**开发者模式**下出现，开发者模式需在偏好设置中开启并重启生效：

1. 偏好设置（Topos Color > Preferences）→ Advanced → Developer → 勾选
   "启用开发者模式" → Save → 按提示重启应用。
2. 把界面调整成想要的默认布局，然后 Window > Set as Default
   （写入当前工作模式的分桶，其它模式的捕获保留）。
3. 视频与图片模式各设置一次（在偏好设置里切换工作模式并重启后再次设置）。
4. 审查 diff 并提交：

```bash
git diff default_layout.json
git add default_layout.json && git commit -m "chore: update factory default layout"
```

关闭开发者模式可再次隐藏该入口，普通用户始终无法改动默认布局。

测试：`tests/ui/test_factory_default_layout.py` 守护已提交文件的结构合法性。

相关代码：`src/app/controllers/dock_layout_controller.py`
（`_load_factory_layout` / `reset_layout_to_default` / `set_current_layout_as_default`）。

## 照片调色页

「横屏调色」上排为资源、视图和右栏，以 `default_layout.json` 的 `photo_color` 配置为起点。右栏上方是信息和裁切，下方是图层。高度不足时，这三项合并为一组标签。宽度低于 1200 个逻辑像素时，右栏移到底部示波器区，窗口够高时图层仍单独显示在信息组下方。去模糊和胶片颗粒同时移到左上，与资源共用标签栏。左栏为完整标签预留宽度，各组标签根据本栏宽度调整留白。底部的色轮组和曲线组在宽度不足时共用一列，所有标签仍可切换。

在细分隔线附近拖动可调整宽度和高度，默认预设记住手动调整的侧栏比例。选择适合窗口的缩放模式后，照片随视图大小自动适配。「窗口 → 重置为默认」恢复该预设的出厂比例。

## 视频调色页

视频调色的出厂布局使用 `default_layout.json` 的 `video_color` 比例。首次打开调色页或载入视频项目时，根据窗口所在屏幕的像素分辨率和可用逻辑尺寸选择窗口档位。4K（3840 × 2160 起）采用 1720 × 950，2.5K（2560 × 1440 起）采用 1520 × 880，2K（2048 × 1080 起）采用 1360 × 800，低于 2K 采用 1200 × 740。高档位放不下时自动降档。MacBook Air（M1，2020）的 1440 × 900 缩放工作区可使用 1360 × 800。首次进入和在调色页执行「重置为默认」都生成同一个六区结构。旧版视频调色快照在升级时从对应的页面资料和预设中移除，混合预设里的其他页面继续可用。开发者捕获其他工作区布局时，保留这组出厂比例。

上排是画廊、视图窗口和节点，中间是通栏片段条，下排是调色工具与示波器。上排以 21:57:22 为目标，下排工具和示波器以 78:22 为目标。视图和工具行以 56:44 分配片段条以外的空间，实际尺寸受面板最小尺寸限制。下排默认显示一级调色、二级调色和示波器三列。一级以色轮为默认页，二级以曲线为默认页。可用窗口宽度低于 1330 个逻辑像素时，两组调色标签自动合用一列，示波器仍在独立的一列。窗口加宽后，两组会重新并排。顶部固定入口为画廊、节点和示波器。示波器组包含「示波器」「胶片颗粒」「模糊/锐化」三个标签，顶部入口收起或恢复整组。「通道混合」默认隐藏，可通过「窗口 → 面板」打开。

片段条在可用窗口高度低于 760 个逻辑像素，或用户选择的缩略图尺寸会挤压上下两区时临时采用 Small。高度回升后恢复用户选择。上下沿的透明鼠标区域都能移动片段条，同时调整视图与工具行的相对高度。各列之间也可在细线附近拖拽调整宽度。

## 视频剪辑页

剪辑页的「默认布局」在上排并列媒体池、视图窗口和属性，下排给时间线留出整行。媒体池旁有「效果」和「混音器」标签，属性旁有「AI 助手」和「信息」标签。顶部的媒体池和属性按钮分别收起或恢复对应的标签组，再次开启时恢复关闭前的活动标签。

首次使用剪辑页或重新应用「默认布局」时，按视频项目的 4K、2.5K、2K、紧凑四档选取默认比例。默认窗口分别为 1720 × 950、1520 × 880、1360 × 800、1200 × 740 个逻辑像素。横向比例和上下两排高度比来自 `default_layout.json` 的 `video_edit`，实际可拖动范围受各面板最小尺寸约束。已有用户布局以及命名预设按原状态恢复。两个列分隔线和上下排分隔线都有透明的鼠标拖动区域。

照片和视频调色页各有「横屏调色」预设，混音页默认选中「视频混音」，还可切换到「剪辑布局」，其余页面提供「默认布局」。启用这套预设时从本机预设库一次性清理旧的单页和整套预设，之后保存的新预设继续按原流程保留。剪辑页的「默认布局」沿用调色页的横向停靠方式，在同一个 Qt 停靠区内建立媒体池、视图窗口和属性三列。窗口缩放时三列随窗口按比例调整，达到最小宽度的面板会优先保留所需空间。可用宽度不足以摆开三列时，媒体池和属性共用一组标签，视图保持独立。窗口加宽后自动恢复三列。手动拖动分隔线后会记住新的三列比例，重置可恢复 3:4:3。

## 混音工作区

混音页的「剪辑布局」上排从左到右为混音器、视图窗口和属性。视图画布默认按 16:9 自动适配，属性默认在右上开启，宽度约为其最小宽度的 1.5 倍。上排剩余宽度留给左侧标签组，默认选中混音器，媒体池和音频效果可切换。下排由音频时间线和片段编辑共用，默认显示音频时间线，贯穿窗口宽度。下排与上排优先按 3:2 分配高度，必要时给上排留出显示完整通道条的高度。高度不足时，混音器移入下排时间线的标签组，窗口加高后回到左侧。混音器可纵向滚动查看完整的通道条。

顶部提供媒体池、混音器、音频效果、视频监看和属性五个带文字的独立开关。关闭「视频混音」的五个面板后，时间线使用整个工作区。媒体池的智能文件夹默认折叠，可点击标题旁的箭头展开。已有的混音页内建布局会在首次进入时更新，命名预设可继续使用。

「视频混音」（Video Mixing）默认在左上角显示视频预览，左下角从左到右排列媒体池、混音器、音频效果、属性，四个标签默认开启，默认选中混音器。左侧从 1:2 的上下高度分配起步，默认按 16:9 设置画布尺寸并启用自动适配。窗口偏高或面板达到最小宽度时，优先调整预览高度来保持画布比例。右侧使用剩余宽度，全高显示音频时间线和片段编辑。左下工具区容不下完整混音器通道条时，混音器移入时间线标签组，空间恢复后移回左下。两套混音预设进入紧凑布局后，时间线组从左至右排列为混音器、音频时间线、片段编辑。

## 素材库与合成工作区

素材库默认把整个工作区留给文件浏览。顶部「媒体池」可打开当前工程的媒体池，通常放在浏览区下方。窗口较矮且宽度足够时，媒体池移到右侧。两种方向各自记住手动调整的分隔比例，「重置为默认」收起媒体池并恢复浏览区的默认侧栏宽度。

视频合成默认在左侧放媒体池，中间放视图，右侧放节点属性和示波器。下方关键帧时间线横跨整页，打开节点编辑器后可在底部标签组切换。宽度不足以容纳三列时，默认收起媒体池。图片合成保留默认可见的节点编辑器。
