## 一、硬编码字符串审计

### 1.1 方法与排除规则

- 基于 AST 扫描（非正则），覆盖 UI sink：`setWindowTitle / setText / setToolTip / setPlaceholderText / setStatusTip / setTabText / setItemText / setLabelText / setTitle / setMessage / addItem / addMenu / addAction / addRow / QToolTip.showText`，构造器 `QLabel / QPushButton / QToolButton / QCheckBox / QRadioButton / QGroupBox / QMenu / QAction / QTableWidgetItem / QListWidgetItem / QTreeWidgetItem`，以及 `QMessageBox.{information,warning,critical,question,about}` 与 `QInputDialog.getText/getItem/...` 的标题和正文参数。
- 另扫描所有含中文的字面量（f-string / 赋值 / 字典键 / 函数实参），用于捕获传入自定义 UI 辅助函数（`_make_row`、`_label`、`add_pair` 等）的文案。
- **排除**：日志（`logger.*` / `print`）、异常消息（`raise XxxError(...)`）、`assert`、docstring、注释、字符串比较用的字面量、CSS/QSS/HTML/JS 样式载荷、纯符号或纯占位符文本（如 `"x"`、`"ID: {}"`）、`I18N.tr` / `tr` / `tr_or_none` / `_trf` 的 default 参数（这些是合法的 i18n 模式）。
- 技术词汇表（codec 名、`dBFS`、`sRGB` 等专有名词）单独归类为"技术/品牌"，不计入需翻译问题，仅作信息项。

### 1.2 分类定义

| 类别 | 含义 | 严重度 |
|---|---|---|
| **A 中文直传** | 中文字面量直接传给 UI sink/文案辅助函数（中文界面下永远不随 locale 切换） | 高 |
| **B 英文可译** | 英文单词/短语/句子直接传给 UI sink（中文界面下显示英文） | 高 |
| B 英文技术 | 品牌、编码名、单位、格式壳（如 `"ProRes 4444"`、`"px"`） | 信息项 |
| **C 中文待确认** | 其他中文字面量（f-string 拼接、赋值、字典键），多数最终会显示，需人工确认 | 中 |

## 三、结论

1. 硬编码问题总量 711 处（A 125 + B 可译 538 + C 48），一半以上集中在 composite/ui；4 个面板完全未接入 i18n。

3. `plugins.*` 无键缺失，仅存 plan-03 已知的英文回退值问题，留待 plan-03 流程处理。
