# Baselight X Grade 对照

Baselight M 7.0.3.26500 与 Topos 使用同一张 1920 × 1080 色样图。双方的输入、工作和输出均为 Rec.709 Gamma 2.4、全范围，交付 RGB 16-bit TIFF。Baselight 的色彩空间设置为 `OCIO_g24_Rec709_tx`，关闭逆 DRT，Mastering Colour Space 设为 None。Topos 用时间线交付器生成 TIFF，记录显示 OpenGL 渲染、CPU TIFF 编码。

样本包括 33³ RGB 网格、4,096 个留出 RGB 和 1,024 级灰阶。另有四块大色样供查看器稳定取色。以下沿用[达芬奇对照流程](resolve_comparison_workflow.md)的口径，分别量同距离手势和同参数交付。

## 同距离手势

表中滑条从曝光 0、宽度 0.20 起步，拖动距离为像素。查看器色度位移折算到 900 px 的参考色度图，Baselight 位移由截图估读，Topos 按面板缩放和输入映射计算。

| 操作 | 拖动 | Baselight | Topos |
| --- | ---: | ---: | ---: |
| 曝光滑条 | +20 px | +1.16 档 | +1.194 档 |
| 曝光滑条 | −20 px | −1.16 档 | −1.136 档 |
| 曝光滑条 | +40 px | +2.31 档 | +2.359 档 |
| 宽度滑条 | +20 px | 0.383 | 0.383 |
| 宽度滑条 | −12 px | 0.090 | 0.084 |
| 宽度滑条 | +40 px | 0.566 | 0.570 |
| 从查看器拖动绿色 | 向右 60 px | 约 8.7 px | 11.5 px |
| 从查看器拖动暖色 | 向右 120 px | 约 24.3 px | 22.9 px |

表中 Topos 的滑条实测使用 Qt Fusion 样式。主窗口使用 Topos 的全局滑条主题，在该主题下向右拖 20 px 实测曝光为 +1.088 档、宽度为 0.368。

两次短距离查看器手势在 Baselight 的 TIFF 色样上均未形成可测的码值变化。该结果与光标位移独立记录。取色修饰键、逐分区手势和不同缩放级别未做跨软件量化。

Topos 的选色调节（Selective Grade）色度图随矩形面板缩放，水平和垂直位移分别按对应轴换算。点击查看器建立或选中校正点，右侧的曝光、宽度、支点和过渡数值可横向拖动。支点和过渡在 Dim／Light 分区可用。

## 第一轮 16-bit TIFF 调节增量

两边分别扣除本软件的中性 TIFF。Baselight 启用 X Grade 且无笔画时，留出 RGB 相对无算子交付已经出现 2.13 个 10-bit 码值 RMSE，网格最大偏差 64.19。双方都无调整、Baselight 无 X Grade 算子时，留出 RGB 交付的 RMSE 是 0.50 个码值，最大 1.00。

曝光用例固定取色色样、宽度和曝光档位，作用于 Master。曝光拟合使用 RGB 网格的子采样，表中 RGB 误差来自另一批色值。色度拖动用例固定宽度并按色度图的可见起点和终点对齐，位移精度受截图约束。暖色和绿色参与了拖色校准，蓝色用例留出。RMSE 按所有 RGB 通道计算，P95 和最大值按每个样本误差最大的通道统计。单位均为 10-bit 码值。

| TIFF 用例 | 宽度 | 曝光（档） | 用例 | RGB RMSE | RGB P95 | RGB 最大 | 灰阶 RMSE |
| --- | ---: | ---: | --- | ---: | ---: | ---: | ---: |
| `warm-w020-plus1` | 0.20 | +1.00 | 拟合 | 2.90 | 7.60 | 49.81 | 1.18 |
| `warm-wide-minus1` | 0.60 | −1.00 | 拟合 | 5.27 | 19.08 | 64.08 | 1.31 |
| `blue-minus075` | 0.20 | −0.75 | 拟合 | 3.17 | 9.26 | 46.64 | 0.81 |
| `green-w020-plus1` | 0.20 | +1.00 | 拟合 | 3.50 | 8.88 | 74.97 | 0.65 |
| `green-w035-plus05` | 0.35 | +0.50 | 拟合 | 2.68 | 7.20 | 53.45 | 0.41 |
| `blue-w060-minus05` | 0.60 | −0.50 | 拟合 | 3.67 | 13.88 | 50.92 | 1.25 |
| `blue-w045-minus05` | 0.45 | −0.50 | 留出 | 3.73 | 10.74 | 55.46 | 0.64 |
| `near-neutral-w030-plus065` | 0.30 | +0.65 | 留出 | 6.30 | 14.63 | 48.63 | 0.49 |
| `green-scope-hue`，右 49、上 19 px | 0.35 | 0.00 | 拟合 | 3.76 | 12.88 | 104.68 | 0.25 |
| `warm-scope-up90`，上 90 px | 0.20 | 0.00 | 拟合 | 7.43 | 26.65 | 115.62 | 0.25 |
| `blue-scope-right50-down33`，右 50、下 33 px | 0.20 | 0.00 | 留出 | 7.77 | 33.28 | 59.11 | 0.22 |

直接比较未扣除中性的交付 TIFF，三个留出用例的 RGB RMSE 分别为 2.96（蓝色曝光）、6.90（近中性色曝光）和 7.75（蓝色拖色）。两种口径均保存在对照 JSON。

这些结果覆盖 Rec.709 的 Master 单笔画。留出用例依然存在可测色差，尤其是拖色和部分高饱和样本。Dim、Light、保护点和多笔画有 Topos 内部的渲染或交互测试，跨软件的一致性尚未验证。

Topos 当前支持线性 Rec.709 和 Rec.709 Gamma 2.4，未标记的旧工程沿用原有工作域。显式选择其他工作域时，选色调节的保存数据可查看和重置，预览保留同节点的其他调色。包含有效选色调节的交付会提示工作域要求。

## 扩展色卡与实拍复测

### 界面与拖动范围

本机 Baselight 中保持 Width 0.20，记录了同一暖色点向上约 55、90、140 px 的选中轮廓。虚线框随距离增大，宽和高都扩展，中心沿拖动方向移动。Topos 使用不带描边的底图，选中调整和活动草稿使用独立的白色虚线。新轮廓在 900 px 参考色度图上的可视外接框约为 211 × 134、249 × 173、304 × 230 px。尺寸随实际画布比例换算。

### 同参数交付

同一张 1920 × 1080 Full Rec.709 Gamma 2.4 TIFF 提供给双方。保留早期的 41,057 个网格、留出和灰阶色样，增补了 360 个色相／饱和度、灰阶／亮度及肤色邻近色样。素材选用 4 条 4096 × 2160、25 fps 的 ProRes 4444 镜头各一帧。按 BT.709 标签解码有限电平 YCbCr，通过同一路径转换到 Gamma 2.4，再以 16-bit RGB 拼图。原始 MOV 保持只读。这里评估同一输入上的调色输出。

曝光更新仅收窄实测窄范围、小于一档时扩得过宽的响应。中间三组曝光数据参与范围校准，实拍像素未参与求取参数。候选方案同时比较了色卡和四帧实拍的误差。色相拖动的端点按截图对齐，相关数据以单笔画重新采集，并复核了实际像素变化。

表中误差均为 10-bit 码值 RMSE。色卡列使用 4,096 个 RGB 留出采样点。实拍列按照四个 ROI 的像素数合并。增量误差先分别减去两边的中性交付，原始误差直接比较最终 TIFF。

| 操作（Width 0.20） | RGB 增量旧 → 新 | 实拍增量旧 → 新 | 实拍原始 TIFF（新） |
| --- | ---: | ---: | ---: |
| 暖色 +1.00 档 | 2.77 → 2.77 | 1.38 → 1.38 | 1.55 |
| 暖色 −0.75 档 | 6.12 → 2.51 | 8.03 → 1.08 | 1.34 |
| 绿色 +0.65 档 | 7.89 → 2.89 | 7.96 → 0.53 | 0.79 |
| 近中性色 +0.60 档 | 10.05 → 2.22 | 7.64 → 0.58 | 0.64 |
| 暖色向上约 90 px | 7.71 → 7.71 | 3.48 → 3.48 | 3.53 |
| 暖色向上约 140 px | 11.74 → 11.74 | 4.81 → 4.81 | 4.86 |
| 蓝色向右约 50、向下约 33 px | 7.83 → 7.83 | 1.67 → 1.67 | 1.74 |

重跑第一轮 11 个用例，近中性色 Width 0.30 / +0.65 档的 RGB 增量 RMSE 从 6.30 降到 2.70，其余 10 个用例的报告数值保持一致。长距离拖色仍有偏差，例如暖色上移约 140 px 时，实拍单帧区域最高为 8.75 个码值 RMSE。尝试过的色度响应改动在蓝色和长拖动实拍上的误差上升，因此本轮保留了原有的色度渲染响应。

扩展色卡可用下列命令重建。对拍用例中的 `anchor`、`width`、`stops` 对应上表。色度用例另填 `scope_offset`，顺序为右、下，参考尺寸为 900 px。每个用例指定原生 `native` TIFF，`native_neutral` 可以在用例文件顶层统一指定。对拍报告按每个色卡和实拍区域保留 RGB RMSE、P95、最大误差及校验值。

```sh
.venv/bin/python -m tools.baselight_x_grade_round2_chart "$MOV_DIRECTORY" "$WORK"
QT_QPA_PLATFORM=offscreen TOPOS_EXPORT_GPU_RENDER=1 \
  .venv/bin/python -m tools.baselight_x_grade_comparison compare-manifest \
  "$WORK/manifest.json" "$WORK/cases-final.json" "$WORK/topos"
```

## 长拖动复测

本轮用同一台 Baselight M 采集 11 个 Master 单笔画，其中 9 个拖动长度至少为 130 px，最长 180 px。曝光为 0.00，Width 为 0.20。以 900 px 色度图为参考，记录每个笔画的起点与终点，再用相同参数从 Topos 时间线导出 16-bit RGB TIFF。靠近色域边缘的长拖动按每个颜色的通道余量逐步压缩。色域内长拖动使用七个原生色点校准位移，并以 RGB 网格的子采样调校颜色移动时的亮度响应。两边保留独立的中性交付。

新图卡包含 35,937 个 RGB 网格点、4,096 个独立 RGB 样本、1,024 级灰阶、360 个扩展色样，以及 12 条 ProRes 4444 镜头各两帧。各镜头在约三分之一和三分之二的时刻取样。实拍区域共 24 块，每块 239 × 126，解码口径与上一轮相同。实拍和独立 RGB 样本均未参与参数拟合。

下表以 10-bit 码值 RMSE 计。色卡列使用独立 RGB 样本。实拍增量按 24 块 ROI 的像素数合并，最后一列直接比较两边的最终 TIFF。

| 单笔画 | RGB 增量旧 → 新 | 实拍增量旧 → 新 | 实拍原始 TIFF（新） |
| --- | ---: | ---: | ---: |
| 暖色上 90 px | 7.71 → 7.58 | 2.96 → 2.54 | 2.61 |
| 暖色上 140 px | 11.74 → 10.00 | 4.05 → 4.14 | 4.18 |
| 暖色上 180 px | 14.66 → 11.95 | 5.63 → 4.61 | 4.65 |
| 暖色右 150 px | 30.63 → 11.96 | 8.32 → 3.27 | 3.34 |
| 绿色左 140 px | 16.19 → 16.44 | 2.44 → 2.68 | 2.67 |
| 绿色上 130 px | 92.72 → 43.67 | 3.15 → 1.01 | 1.17 |
| 蓝色下 150 px | 23.89 → 13.04 | 3.18 → 1.64 | 1.73 |
| 蓝色右 50、下 33 px | 7.83 → 5.27 | 1.03 → 0.82 | 1.00 |
| 紫色右 140 px | 27.36 → 7.67 | 3.22 → 0.77 | 0.97 |
| 青色下 130 px | 22.03 → 16.37 | 7.93 → 5.39 | 5.42 |
| 黄色左 62、上 128 px | 11.21 → 10.75 | 9.03 → 7.21 | 7.22 |
| 9 个长拖动合并 | 36.64 → 18.78 | 5.75 → 3.97 | 4.00 |

总体实拍原始 TIFF RMSE 从 5.79 降到 4.00（9 个长拖动）。绿色左拖和暖色上拖 140 px 的实拍误差略升。绿色上拖的高饱和色卡、青色和黄色的实拍仍有可见偏差。跨软件实测覆盖上述 Rec.709 单帧、固定曝光和宽度的 Master 调整。当前步骤未量化原始视频全时序和多笔画组合。

上一轮图卡与四帧实拍复跑后，4 个纯曝光用例的 TIFF 校验值一致。该批实拍中，暖色上拖 90 和 140 px 的 RMSE 分别从 3.48、4.81 降到 3.06、4.39，蓝色斜拖从 1.67 降到 1.28。

在本机单笔测试中，默认宽度的边缘长拖首次烘焙用时约 3–4 ms（Master），叠加明度范围后约 36–38 ms（13 个采样层）。该时间只包含色场计算。实际预览还涉及渲染、纹理上传和显示。

```sh
.venv/bin/python -m tools.baselight_x_grade_round2_chart --long-drag "$MOV_DIRECTORY" "$WORK"
.venv/bin/python -m tools.baselight_x_grade_round2_chart --anchor-reference "$WORK"
QT_QPA_PLATFORM=offscreen TOPOS_EXPORT_GPU_RENDER=1 \
  .venv/bin/python -m tools.baselight_x_grade_comparison compare-manifest \
  "$WORK/manifest.json" "$WORK/cases-final.json" "$WORK/topos-long" \
  --compare-to "$WORK/topos-baseline/comparison.json"
```

原生取色参考图包含暖色、绿色、蓝色、近中性、紫色、青色和黄色。按表录制原生单笔画，将每次的导出和中性 TIFF 写入用例文件。先在改动前输出 `topos-baseline/comparison.json`。报告校验本轮的图卡、原生 TIFF 和用例参数是否相同。

## 复跑

1. 创建一个工作目录 `WORK`。生成色样图并以相同的 Rec.709 Gamma 2.4 设置导入 Baselight。
   ```sh
   .venv/bin/python -m tools.baselight_x_grade_comparison chart "$WORK/rec709-g24-anchors.tif"
   ```
2. 从左到右的取色色样分别为暖色 `(.50, .28, .16)`、绿色 `(.22, .55, .18)`、蓝色 `(.17, .35, .60)`、近中性 `(.48, .44, .42)`。对每组使用单笔画和默认中性保护。依表中用例名将 Baselight 的 TIFF 存为 `$WORK/baselight-renders/CASE/CASE.0000.tif`。
   中性及查看器对照文件名为 `anchors-neutral`、`xgrade-neutral-enabled`、`green-drag-right60` 和 `warm-viewer-right120`。
3. 用 Topos 的时间线交付器重跑并写出 `comparison.json`。报告同时包含原始 TIFF 误差、调节增量误差、源文件与参考文件校验值和各阶段后端。
   ```sh
   QT_QPA_PLATFORM=offscreen TOPOS_EXPORT_GPU_RENDER=1 \
     .venv/bin/python -m tools.baselight_x_grade_comparison compare "$WORK" "$WORK/topos"
   ```
