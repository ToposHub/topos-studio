# Resolve 曲线校准

视频工程的时间线设为 **Rec.709 Gamma 2.4** 时，空白校正节点使用 v3 曲线配置。自定义 YRGB 使用 v2 算法，六条 HSL 使用 v3，柔化裁切独立使用 v2。第一次有效编辑时，算法版本和改动一起保存，可一并撤销。已有 v2 自定义曲线的节点首次编辑空白 HSL 曲线时进入 v3。已保存的曲线按节点记录的算法渲染。图片模式和其他时间线工作空间的空白节点使用各自的曲线模型。

- **自定义曲线**以 Gamma 2.4 编码的 Rec.709 RGB 为输入。Y 改变 Rec.709 亮度，RGB 调整伴随亮度补偿。YRGB 链接时，画布同步各通道的锚点。编辑强度分别缩放各通道的调整量。
- **HSL 曲线**以同一编码域的色相、亮度与色度定位。色相曲线在红色两端连续，单锚点可以整体调节，继续加点可限制影响范围。饱和度曲线的输入刻度为 0–0.5。
- **柔化裁切**低点和高点的中性值为 50，低端与高端柔化为 0。校准控件的范围各为 0–100，支持 RGB 链接及独立通道。硬裁切及软化都在编码域应用，四项处于中性时直通。

OpenGL、Metal 合成和 CPU 渲染各自使用对应的校准实现。通过现有图命令保存曲线控制点和校准版本，渲染 LUT 由这些参数重建。图节点的点态 LUT 导出也支持校准曲线和柔化裁切。

## 自定义曲线 v2 实测（2026-11-25）

在 Resolve Studio 20.2.1.6 的独立 DaVinci YRGB 工程使用 Rec.709 Gamma 2.4、Full 电平和 443×337 逻辑像素曲线绘图区。在曲线附近点击加点，再拖动锚点。横向坐标由黑到白，纵向坐标向上增加。靠近曲线向上偏 4 或 10 像素点击会在指针位置创建锚点，偏 20 或 67 像素时没有加点。偏离锚点中心抓取时，实际拖动后锚点跟随指针。Topos 把松手位置纳入本次提交，仅选中锚点时无需创建撤销记录。

直接拖动图上自带的黑、白端点，曲线上始终只有这两个控制点。黑点可沿左边向上或沿底边向右，白点可沿右边向下或沿顶边向左。松手后重新抓取并沿对应边反向拖动，两点均可回到默认角。黑点从初始角拖向 (0.17, 0.19) 时落在左边的 (0, 0.19)。白点从初始角拖向 (0.81, 0.84) 时落在顶边的 (0.81, 1)。下表端点用例保持 YRGB 链接。

由屏幕截图提取曲线描线，去掉锚点周围再按相同坐标比较纵向 RMS 距离。Y 单点抬高、单点压低、双点 S 曲线和链接双点留出的 Topos v1 差异分别为 **1.84、1.47、1.46、3.22** 像素，v2 为 **0.88、1.10、1.12、1.58** 像素。该统计含截图栅格化误差。

实际交付用同一张图卡走 Topos 时间线 OpenGL 和 Resolve 16 位 RGB TIFF。两个 Y 单点用于识别插值，Y 双点 S 曲线、独立 R、混合通道和链接双点作为整组留出。每组比较 4,096 个独立 RGB 色块和 1,024 个灰阶样本。单位为 10 位 RGB RMSE。

| 操作 | RGB v1 → v2 | 灰阶 v1 → v2 |
| --- | ---: | ---: |
| Y 单点抬高 | 3.688 → 0.502 | 5.791 → 0.487 |
| Y 单点压低 | 10.881 → 0.678 | 11.872 → 0.659 |
| Y 双点 S 曲线 | 8.422 → 0.385 | 9.139 → 0.384 |
| R 单点抬高 | 2.929 → 0.240 | 2.874 → 0.237 |
| YRGB 链接双点 | 9.448 → 0.867 | 9.353 → 0.689 |
| 黑点向上 | 2.769 → 0.077 | 2.749 → 0.053 |
| 黑点向右 | 24.590 → 0.100 | 4.571 → 0.070 |
| 黑点对角拖 | 3.161 → 0.075 | 3.134 → 0.052 |
| 白点向下 | 2.603 → 0.077 | 2.602 → 0.054 |
| 白点向左 | 27.321 → 0.100 | 3.511 → 0.068 |
| 白点对角拖 | 29.100 → 0.101 | 3.645 → 0.068 |

v2 用相邻点的弦长参数化三次样条，采样时反解曲线 X。端点向内横移时保留边界斜率，RGB 与亮度补偿之后按交付格式裁切。画布按自身坐标显示曲线，渲染包含实测的采样比例和半码值偏移。两组混合通道的独立 RGB RMSE 为 0.406 和 3.158，误差较大的组合含大幅抬升。边界极端值、HDR 和其他工作域还需独立采样。

同一组 13 个用例也对比了 Topos 剪辑时间线 CPU 预览的帧颜色与 OpenGL TIFF 交付。留出 RGB 和灰阶中，浮点预览信号与 16 位 TIFF 的逐通道最大差小于 0.008 个 10 位码值。控点测试覆盖拖动预览、停顿、松手后的最终参数、撤销及重做。

原始截图、归一化坐标和 Resolve 样本在 `/tmp/topos-resolve-curves.WeXmhy`、`/tmp/topos-resolve-curves-verified.y9sqOl` 与 `/tmp/topos-resolve-curve-ends.C8I7VI`。`curve-delivery-chordal.json` 列出生产交付 RMSE、P95 与最大差值，`plot-shape-comparison.json` 保存描线统计，`curve-preview-delivery.json` 保存 Topos 预览与交付差值。 [Blackmagic Design 调色师指南](https://documents.blackmagicdesign.com/UserManuals/DaVinci-Resolve-20-Colorist-Guide.pdf)

## 六种 HSL 曲线 v3 实测（2026-11-25）

在 Resolve Studio 20.2.1.6 的独立 DaVinci YRGB 工程使用 Rec.709 Gamma 2.4、Full 电平与 1920×1080 图卡。六个模式分别采集全局升降、局部三点及四点留出曲线，另采集跨红色接缝、单调控制点和多模式组合。曲线坐标按实际绘图区归一化，Resolve 参考与 Topos 正常时间线导出均写为 16 位 RGB TIFF。每组比较 4,096 个独立 RGB 色块和 1,024 个灰阶样本。

实测色相曲线初始无控点，首个控点改变整条水平线。另三条曲线保留两端的默认控制点。点击画布可在指针位置加点，对角拖动后以松手位置为准。色相输入读数以 256° 起始并周期回绕，红色预设的中心点可从 256° 改至 255° 跨越接缝。色相预设在中心两侧分别放置相距 60° 的锚点，亮度预设放置在 0.25 和 0.75。取色后按实测轴定位，在色相与亮度模式放置局部范围。Topos 回归覆盖只选中控点、松手提交、撤销、重做以及旧节点恢复。

从 Resolve 画布提取描线，排除控点和与中线重叠的位置。六种局部三点与四点用例中，v3 的纵向 RMS 偏差为 **0.407–0.475 个逻辑像素**，v1 为 **0.495–5.277**。v3 使用半区间长度的 Bézier 控制柄，趋势反转处使用水平切线。画布和 LUT 由同一组控点重建。

| 四点留出用例 | v1 → v3 RGB RMSE | v3 RGB 最大通道差 |
| --- | ---: | ---: |
| 色相调色相 | 17.5294 → 0.0515 | 0.7961 |
| 色相调饱和度 | 1.2234 → 0.0158 | 0.2654 |
| 色相调亮度 | 2.5405 → 0.0314 | 0.3278 |
| 亮度调饱和度 | 11.5557 → 0.0134 | 0.2341 |
| 饱和度调饱和度 | 42.0703 → 0.0232 | 0.1873 |
| 饱和度调亮度 | 110.1776 → 0.0565 | 0.4683 |

上表以 10 位码值为单位。新模型在原始 Rec.709 信号上计算三个输入轴，对色相使用椭圆色度平面和纯红采样规则。三种饱和度增益相乘。两种亮度增益相乘，色相调亮度的色度权重同时响应亮度调饱和度与饱和度调饱和度。留出组包含这两种叠加关系。测试覆盖 SDR 时间线素材与交付，HDR 和其他工作域缺少本轮对拍。

同一节点同时启用六种曲线时，RGB RMSE 从 **50.3246 降到 0.1103**，最大通道差为 **0.7961**。35 组交付清单均记录 OpenGL 渲染，v3 在独立 RGB 色块上的最大通道差为 **0.8429**。Topos 时间线 CPU 预览的浮点帧与 16 位 TIFF 的最大通道差小于 **0.008**，单位同为 10 位码值。跨版本单独粘贴 HSL 控点时使用目标节点的算法，整套调色复制会携带节点版本。

原始截图、控点坐标、两端 TIFF 与交付清单位于 `/tmp/topos-hsl-resolve.Ieuqmc`。`production-hsl-final.json` 记录交付误差和 CPU 预览信号对拍，`plot-hsl-comparison.json` 保存描线偏差。 [Blackmagic Design 调色师指南](https://documents.blackmagicdesign.com/UserManuals/DaVinci-Resolve-20-Colorist-Guide.pdf)

## 柔化裁切 v2 实测（2026-11-25）

Resolve Studio 20.2.1.6 的独立 DaVinci YRGB 工程与 Topos 时间线均使用 Rec.709 Gamma 2.4、Full 电平。Resolve 的滑杆行程为 152 逻辑像素。中性时 High 和 Low 在中点，两项柔化在最左端。每次移动高点、低点或柔化滑杆，其余滑杆的位置保持固定。两端先分别推满柔化量再收窄裁切范围，与反向操作得到相同的 16 位 TIFF。验证用例使用端点和每 19 像素的整八分之一位置，避免读数换算歧义。Topos 按实际滑槽行程跟随拖动，数值格可录入小数，松手前的最终值进入同一条撤销记录。 [Blackmagic Design 调色师指南](https://documents.blackmagicdesign.com/UserManuals/DaVinci-Resolve-20-Colorist-Guide.pdf)

采样覆盖四项单调节、硬裁切、两端柔化重叠、外扩与单独绿通道。软膝在可用范围内用二次过渡。触及中灰时，保留裁切端的平坦点，通过三次 Hermite 插值在中灰接回原斜率。两个柔化量独立保存。旧工程按所存版本渲染，旧校准节点有效编辑时可升级。单独编辑一个通道时，若升级会改变其他通道的响应，继续使用原算法。移动版四参数工程保留指数软膝，Topos 面板仅限制正在编辑的值，预览和交付使用保存的参数。

29 组实际 1920×1080 OpenGL 交付与 Resolve 16 位 RGB TIFF 比较。每组有 4,096 个独立 RGB 色块与 1,024 个灰阶。下表为独立 RGB 的 10 位 RGB RMSE。

| 设定顺序为 Low、Low Soft、High、High Soft | v1 → v2 |
| --- | ---: |
| 双端最大重叠，100 / 100 / 0 / 100 | 42.3462 → 0 |
| 非对称重叠，87.5 / 100 / 12.5 / 87.5 | 36.3516 → 0.0048 |
| 低端柔化与高端硬裁切，25 / 87.5 / 12.5 / 0 | 0.2433 → 0 |
| 仅 G，87.5 / 100 / 25 / 87.5 | 20.5618 → 0.0028 |

独立色块和灰阶两组样本的最大通道误差均为 1 个 16 位码值，约 0.016 个 10 位码值。Topos 时间线浮点预览与 TIFF 最大差小于 0.008 个 10 位码值。调色页预热后的查看器截图抽样比较四项独立设置、双端和单通道组合，与 Resolve TIFF 量化到 8 位的结果最大差为 1 个码值。实际 Resolve 对拍范围为 Rec.709 Gamma 2.4，其他工作域和 HDR 两端输出差异待采样。

截图、参数、两端成片、交付后端与像素报告位于 `/tmp/topos-soft-clip-resolve.IrV32z`。图卡 SHA-256 为 `7168a440e6d7b3e4f81ce2346ad72f7ccab7ea0ad0b59b8a0c5fcc53d14d442a`。

## v1 采样与验证

使用 Resolve Studio 20.2.1.6、DaVinci YRGB、Rec.709、Gamma 2.4、Full 电平。导出 16 位 RGB TIFF，直接比较码值。Screen、ICC 和查看器截图均在像素比较之外。图卡与[一级调色校准](/Users/heng/Documents/vscode/topos-studio/docs/validation/resolve_primary_calibration.md)相同，包含 `33³` RGB 网格、4,096 个独立 RGB 验证色块以及 1,024 个灰阶。曲线控制点从画布尺寸和锚点位置换算。Topos 接收解码后的线性 Rec.709 色块，通过原生 OpenGL 调色阶段渲染，比较前重新编码。

| 验证参数 | 独立 RGB RMSE 降幅 |
| --- | ---: |
| Y 中点、R 中点、YRGB 链接中点 | 95.8%–97.7% |
| 独立 Y S 曲线 | 88.8% |
| 六种 HSL 曲线的单锚点调整 | 96.6%–99.4% |
| 局部 Hue vs Sat 三锚点调整 | 97.1% |
| 柔化裁切四参数组合（低点 60、低端柔化 18、高点 38、高端柔化 12） | 99.1% |
| R 通道单独低端柔化 20 | 95.2% |

降幅相对于直接用未调色图卡对照 Resolve 的 RGB 均方根误差。独立 S 曲线的绝对 RMSE 为 8.31 个 10 位码值，四参数柔化裁切组合为 0.12 个。软膝的采样码值另有自动化回归测试。

平滑插值和 HSL 选择范围使用拟合模型。极端控制点、非中性强度、多种 HSL 曲线同时叠加、自定义曲线与柔化裁切的跨工具组合，以及 HDR 和其他工作色域未纳入跨软件实测。取色器沿用源图取样，直方图沿用当前查看器数据源。
