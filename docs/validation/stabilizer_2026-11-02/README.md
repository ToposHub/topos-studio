# Color Tracker 稳定器 · 2026-11-02

## 使用与达芬奇参照

在 Color 页跟踪器标题栏点击稳定器图标，不需要创建或选择窗口。选择透视、相似或平移，点击「稳定」，分析当前视频片段完整的源帧区间。拖动红色播放头可以预览，包括尚未分析的帧。

对照本机已打开的 DaVinci Resolve Studio 20 的 Tracker - Stabilizer：旁路与稳定按钮在上方，运动曲线在中间，裁切比例、平滑度、强度、相机锁定、缩放与模式在底部。相机锁定禁用三个数值控件；退出锁定保留原来的数值。复用 Topos 的全局重置图标，重置只作用于当前显示的跟踪子工具。窄面板会换行，避免文字重叠。

原有图片智能蒙版、智能背景、画笔功能保留。图片不提交视频稳定渲染参数。

## 数据与线程

- `CameraMotionAnalyzer` 在原有 TrackingService 的工作线程中分析全画面、网格分布的特征点，通过双向 LK 与 RANSAC 求相邻帧运动，累计为源像素坐标的参考帧到当前帧矩阵 H。失败帧明确标记，并继续分析后续帧，不伪造有效结果。
- `StabilizationPlanService` 的独立 CPU 队列计算平滑轨迹 S、补偿 `S @ inverse(H)` 及固定自动缩放。片头、片尾采用局部线性拟合，避免截断均值造成正常横移减速。相机锁定目标为参考帧，不平滑原有运镜。
- 调参不重新解码视频。过时代次、取消、换素材、撤销和重置会作废未完成的结果。数值拖动复用全局交互通道的单次撤销快照。
- Color 在渲染线程完成 GPU 变换，完整调色源图先于稳定采样，最终映射到当前视口 ROI；兼容代理分辨率。纹理、着色器与临时 FBO 由现有 runner/资源管理器持有和释放。
- Edit 的预览与导出在源空间完成稳定，再执行片段裁切、效果和时间线变换。不能保证这一顺序的 GPU 合成/平面直通路径明确回退 CPU，不能静默丢弃稳定。**当前未实现 Edit/Deliver 的全 GPU 稳定路径。** Composite 的 Topos Color 节点消费同一效果，并使用运行时源帧号。
- ColorStack schema v4 新增可选 `video_stabilization`，其子 schema 为 v1。旧项目缺失时为恒等；未来未知字段保留，不支持的稳定版本明确报错。片段保存、工程保存、重置、撤销与重做均经既有项目 command 提交。
- 效果 `video_stabilization` 在 Effect Catalog 注册为内部 pass，包含完整三行矩阵参数 schema；不会作为一个不能单独使用的空效果出现在 Edit 效果库。CPU 与 GPU 均保留浮点 HDR 值，黑色边界的亚像素混合也保持一致。

## 验证结果

测试素材：用户提供的 `测试素材01.mov`，1920×1080、25 fps、124 帧。三种模式均分析完整 124 帧，失败帧为 0；本机独立分析约 5.4～5.8 秒。详见 [质量数据](quality_metrics.json)。

| 模式 | 原轨迹二阶差分 RMS / px | 补偿后 RMS / px |
|---|---:|---:|
| 透视 | 0.37965 | 0.04779 |
| 相似 | 0.15768 | 0.02398 |
| 平移 | 0.05990 | 0.01777 |

此指标仅为估计相机轨迹的平滑程度，**不是与达芬奇输出的误差，也不是视觉质量相同的证明**。正常运镜保留，裁切量由实际运动决定；失败段不跨段平滑，极端裁切限制会在状态行提示。

实际 MainWindow 验证了（[检查记录](native_checks.json)）：无需蒙版发起分析、整段结果提交、播放、旁路、相机锁定（包括原强度为零）、全局重置、撤销/重做、`.topos` 保存并重新加载、关闭窗口与服务收尾。开启稳定的 2.1 秒播放样本，实际收到 49 次前缓冲发布，约 23.1 fps；短样本不代表 4K/60 fps 性能，见 [播放数据](playback_metrics.json)。

使用正式 TimelineExporter 从重新加载的工程导出 960×540、25 fps、124 帧 ProRes MOV。抽查 0、30、60、90、123 帧，相比直接源图补偿后缩小的结果，8-bit 平均绝对差约 1.09～1.16，P95 为 2～3（含编码及缩放差异）。本机测试输出在 `/tmp/topos-stabilizer-native/stabilized.mov`。

回归：2910 passed、11 skipped；新增的 GPU 代理/ROI 与控件检查另行通过 73 项定向测试；图片隔离保护及渲染收尾修改后，再通过 402 项渲染/引擎检查。涵盖真实 OpenGL/HDR、透视/平移方向、亚像素边界、序列化、取消及代次过滤、独立运动前景、场景切换和片头片尾运镜。已有 4 条测试警告未由本次功能引入。完整测试文件范围见 [test_files.txt](test_files.txt)。

尚未取得达芬奇稳定后的视频或矩阵作逐帧数值比较，不能声称稳定效果达到其专有算法的相同水平。大面积独立运动、强视差、滚动快门与严重模糊仍可能影响全局运动模型。
