# 示波器顶栏与浮动多视图

2026-11-02。

## 使用

调色页视图区右键 → 示波器，打开同一个实时示波器面板的浮动窗口。首次打开默认四视图。窗口顶部的布局图标可以切换：

- 单视图：原有单种示波器模式，通过右侧无边框类型选择器切换。
- 双视图：波形、矢量。
- 四视图：分量图、波形、矢量、直方图。
- 全部示波器：四视图加亮度波形、CIE 色度图、假色，共七种。

展开按钮可以浮动/重新停靠。布局选项同时位于三点菜单中。输入源、测量域、标尺及其他设置收在菜单内，不再占据顶栏。多视图使用固定类型组合；各格保留设置入口。

顶栏按用户运行中的 DaVinci Resolve 调色页参考重绘：24px 深灰条、左侧标题、右侧平面模式文字/chevron、滑杆图标、展开图标、三点图标及全高分隔线。Qt 自绘避免 macOS 原生 ComboBox 外观覆盖。截图使用英文，应用同时提供中文短名称。

## 实现与核对

多视图复用七个 presenter，不为每种布局创建额外 GL 分析上下文。布局切换时只移动 presenter。一次 GPU 采样服务所有可见图，波形/分量图/亮度波形各有独立缓存输出纹理，避免互相覆盖。生产 AsyncRenderer 和 standalone benchmark 两条分发路径均已更新。

实际 native Qt shared-context 截图见 waveform.png、split.png、quad.png、all.png，960×640，来自已有 2K 测试素材。所有单模式和双/四/七图模式均通过原生纹理呈现检查；四视图、全部视图的每张 GPU 输出与对应单模式逐像素一致，max_delta=0。

- 面板布局、浮动/停靠、菜单信号、CPU 备用输入、多模式分发、源选择、实时刷新等回归：160 passed；追加两个菜单测试后，多视图 UI 文件 10 passed。
- CIE 图层调整后，CIE 与多视图 UI 检查：20 passed。
- 核心输出集合、共享采样、纹理独立性、缓存复用/释放和生产 dispatch：16 项 focused checks 通过。
- Python 编译和 git diff --check 通过。

多视图暴露了旧 CPU 直方图 paintEvent 的两个异常，现已修正。CIE 标注改在透明 QWidget 层中合成，解决 native GL 贴图区域内光谱边界/色域三角形消失的问题。双视图显式指定分隔条宽度，修正一像素重叠。

## 性能

4K 输入，512×288 分析，30 次 GPU pass 均值：双视图 8.19ms，四视图 23.10ms，全部七图 26.11ms。320×180 下四/七图分别 8.28/8.98ms。完整输出见 multiview-performance.log。

这是 GPU 示波器处理耗时，不包含解码和主画面渲染，不能作为整机播放 FPS。继续使用现有低优先级 scope 队列和刷新节流；无逐帧 CPU 图像回读。其他机器、素材和并发 GPU 负载可能有不同耗时。
