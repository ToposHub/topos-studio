# Base Grade 对照验证

在 Baselight M 7.0.3.26500 的独立测试 Job 中，用 FLAPI `Shot.insert_basegrade_layer` 写入参数并渲染 16-bit TIFF。应用外观沿用 Topos 色轮、拨盘与参数控件。灰阶响应图显示当前设置及区间支点。

## 控件与计算

| 控件 | 校准域及单位 |
| --- | --- |
| Balance、Dim、Light、Dark、Bright | 线性光中的曝光档位与 A/B 染色 |
| Flare | 线性黑位补偿，中性值 0 |
| Contrast 与 Contrast Pivot | 线性曝光对比，默认斜率 1，支点默认 18% |
| 全局及分区 Saturation | 饱和度倍数，中性值 1 |
| 分区 Pivot | 以 18% 灰为基准的档位 |
| 分区 Falloff | 0 到 1 的过渡控制 |

Dim、Dark、Light、Bright 的默认支点依次为 +1、−1、−1、+2 档，默认过渡为 .75、.50、.75、.50。分区亮度采用三分量的线性颜色变换来定义影调，曝光响应以灰阶、色块和多个过渡值拟合。色偏和饱和度响应从独立调节样本测定。分区执行顺序根据组合样本确定为 Bright、Light、Dim、Dark。

## 相同参数对照

复用 [X Grade 的长距离对照测试卡](baselight_x_grade_calibration.md)作为源素材。源文件 `rec709-g24-longdrag.tif` 为 Full 范围 Rec.709 Gamma 2.4，SHA-256 为 `125e28e549d6f34b9b95404a38b8bb8b59d9a8f21d0d877d14260f2ee51105b0`。统一导入、工作、输出域和 TIFF 位深，按 [调色对照测试指南](resolve_comparison_workflow.md)直接比较两套软件的交付像素。使用现有剪辑导出入口输出 Topos TIFF。15 组有效修改覆盖全局和分区曝光、对比与支点、黑位、A/B 染色、饱和度及组合设置，另渲染中性对照。

| 样本 | 样本数 | 15 组有效修改合并 RGB RMSE（10-bit 码值） |
| --- | ---: | ---: |
| RGB 色块 | 35,937 | 2.98 |
| 独立 RGB 色块 | 4,096 | 2.61 |
| 灰阶 | 1,024 | 1.01 |
| 真实画面的等间距采样 | 24 帧，80,640 像素 | 0.98 |

真实画面单组误差为 0.58–1.58 码值。独立色块上，组合调整的最大整组 RMSE 为 6.50 码值。灰阶、独立色块和真实素材的对照使用同一套正式渲染参数。SDR 交付对照覆盖静帧和相同数值。原生鼠标拖拽距离与 HDR 原生软件输出尚未逐项校准。Topos 在 HDR 工作域用内置信号变换进行线性光往返，GPU 和 CPU 的一致性另由渲染集成测试验证。面板曲线显示灰阶响应和当前区间支点。
