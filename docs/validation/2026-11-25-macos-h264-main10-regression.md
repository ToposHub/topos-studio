# Windows 更新合入后的 macOS 真机回归

2026-11-25 · Intel i9-9900K，macOS 15.3.1。合入前提交为 `fbafb999`，实测提交为 `d065004c`。本次使用原有 Release 原生编解码库。

## H.264 时间线播放

同一份 UHD25 H.264 源素材取 [25, 225) 和 [275, 475) 两段，时间线总长 400 帧。原片与单 LUT 各播两轮。统计真实 Viewer 的去重呈现帧号。第 399 帧观察覆盖播放停止之后的 350 ms。

| 场景 | 实际呈现 | 切点相邻呈现帧 | 切点间隔 ms | 切点取帧 ms | 399 实际显示 | 跳转耗时 ms |
|---|---:|---|---:|---:|---|---|
| 原片 1 | 395/400 | 199 → 200 | 35.62 | 7.05 | 是，16.323 s | 427.0 / 12.8 / 12.3 / 13.9 |
| 单 LUT 1 | 395/400 | 199 → 200 | 53.51 | 7.25 | 是，16.015 s | 9.0 / 9.0 / 8.9 / 9.3 |
| 单 LUT 2 | 397/400 | 199 → 201 | 65.67 | 27.10 | 是，15.980 s | 10.5 / 311.3 / 8.1 / 9.1 |
| 原片 2 | 398/400 | 199 → 200 | 69.57 | 32.53 | 是，15.974 s | 9.6 / 10.3 / 10.0 / 8.9 |

跳转目标依次为 195、205、199、200。16 次均实际呈现目标帧，14 次约 8–14 ms，另两次约 311 和 427 ms。单 LUT 第二轮跨切点时从 199 直接呈现到 201。原片第一轮的末帧在检测到播放停止约 252 ms 后显示。其余三轮在停止检测前已显示。

四轮均用 VideoToolbox 零拷贝作为主要解码路径，实际呈现主要是原生 Metal。本轮持续呈现落在上轮已修复的 394–399 帧区间内。

## HEVC Main10 实际时间线交付

通过常规时间线交付入口，强制软件编码。Rec.709 使用真实 UHD H.264，PQ/HLG 使用已知信号测试色板。三个场景均为 25 fps、24 帧，带已知非静音的 48 kHz 双声道 PCM16 音轨，便于核对连续 PTS。

| 输出 | 尺寸 | 色彩标签原色/传递/矩阵 | 完整回解 | 音轨 |
|---|---|---|---|---|
| rec709 | 3840×2160 | 1/1/1 | 24 帧，`yuv420p10le` | 每声道 46080 样本 |
| pq | 128×64 | 9/16/9 | 24 帧，`yuv420p10le` | 每声道 46080 样本 |
| hlg | 128×64 | 9/18/9 | 24 帧，`yuv420p10le` | 每声道 46080 样本 |

视频每帧 PTS 从 0 到 23/25 秒，均按 1/25 秒递增。音轨 PTS 按样本连续。PQ 含母版显示与内容亮度元数据，HLG 使用相应传递标签。

取消时保留旧成片并完成重试。编码子进程启动故障及发送关闭确认后异常退出均通过，父进程能报告错误并清理暂存。覆盖了嵌套音轨准入与平面交付的相关单测。Mac 回归共 333 项通过。3 项 Windows 专用路由测试在此平台跳过。
