# Files 最终替代前复核记录

日期：2026-11-17；复核基线 `4223ede5`，对应 PR-01～05 的第二轮实现。
用户已明确项目处于开发阶段，允许破坏兼容；下一轮不以旧工程、旧配置、旧插件接口的迁移兼容为目标。

## 本轮直接修复

- 安装：事务锁拒绝链接/非普通文件，取锁失败明确拒绝；来源记录独占创建；指针切换后失败先恢复旧指针；恢复失败保留版本目录；核对实际内容摘要；相同内容遗留版本支持崩溃重试/显式降级；目录包/ZIP 保持执行位和内容身份；首次安装严格校验 SemVer；拒绝来源与安装根重叠。
- 打包：拒绝特殊文件、非法跨平台路径、源目录内部输出与输出符号链接；写临时 inode 再替换，避免硬链接输出截断源；非严格构建仍如实保留校验失败状态。
- 生命周期：取消回调失败可诊断重试且继续处理其他任务；停用后禁止新增 owner 作业；并发/重入清理不重复执行；已完成步骤不重复；半激活失败但任务在途时保留贡献；路径上下文真正冻结。
- Inventory：旧发现结果不能覆盖用户启停和实际运行状态/版本；截断诊断优先保留错误。
- Manifest：拒绝以 false/空字符串等畸形值抹去平台/依赖限制；拒绝非有限数值、非 JSON 对象与非字符串键；映射入口异常转诊断；严格 SemVer；不可用 command 往返不被启用；直接构造未来 schema 也被集合验证阻断。依赖图改为迭代 SCC，避免深链栈溢出和共享 DAG 指数展开。
- 启动：复核凭据由服务持有对象身份，不信任调用方设置的 `revalidated` 标记；复制 DTO/跨服务不能绕过复核。发出网络请求仅为 queued，HTTP ACK 为 dispatched，不能当作作业 completed；失败也保留 invocation id。无效/未来/身份错误的声明不能回退到可启动的旧接口。
- 去反向依赖：可选依赖诊断使用共享 ffmpeg locator，不再导入旧 Files utils。
- 媒体：RGB/YUV 复用独立纯几何函数，修复 Topos RGB 按目标框强制拉伸；未改 GPU 渲染管线。

## 明确保留的大工程

下列不变量未完成，已经进入[最终替代与升级总计划](../../plans/2026-11-17-files-final-replacement-and-upgrade-plan.md)：

1. 安装目标在核验后被并发换链仍可能写出受管目录。临时夹具在最终 rename 前替换 `versions`，布尔证据 `directory_race_wrote_outside_owned_versions=true`；需要可信根与目录 fd/handle 相对操作，重复 Path 检查不足以完成。
2. 安装锁在缺少 `fcntl` 的平台明确 `LOCK_UNAVAILABLE`；Windows 锁和真正掉电的 fsync/持久事务恢复尚未完成。
3. 真正的 checked 调用在 worker 复核后、GUI 提交前仍可能遇到目录/启停/库状态变化。身份票据只解决伪造；需新权威宿主的 revision/grant 失效和原子调度。
4. Inventory/Installer/Lifecycle 尚无真实生产闭环；作业历史预算、新 generation、权限 broker、进程隔离、真实贡献注册仍要接线。
5. 原 Files 安全文件事务、组织关系/回收站、完整工程事务、请求世代/分页/任务 UI、解码资源与 EOF/GPU、实际十插件和原生后端/宿主退役仍需整轮实现。旧表的通过记录不能替代这些生产验收。
