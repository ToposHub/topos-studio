## 2. B 侧收口七类产物（F §0.1 逐类对号）

### 2.1 已验证设备/格式/效果矩阵

- B2.2 素材 × 解码路径矩阵（机器 B 侧 32 素材，内容指纹 size+1MB 头 md5）：
  H264/H265 → win_hw_download 默认 + cuda_resident 候选；ProRes/DNxHR →
  cpu_planar；Topos → topos_native_cpu（解耦确认）；PyAV 探测失败 = 预期分类。
- 真机正确性：L2（NV12 双平面 md5 对拍下载参考逐字节一致 + P010 采样语义）；
  L3（真实 QThread + 共享 GL 上下文：单轨 / 反向 seek 120→40→120 源级逐帧
  确定 / 双轨 4K+2K 并发合成，×2 轮稳定）。
- 性能结论（decode-only 稳态 8w+60t）：驻留全面反超下载 1.67–3.08×
  （4K H265 387 vs 187，2K H265 1175 vs 639）；GL-ready 口径 4K H264
  245 vs 102、H265 320 vs 83，逐格交织内容一致 + 0 CPU 字节。
  **8bit H264 单轨 CPU 仍最快（5.5×），如实记录、不外推多轨。**
  证据：`docs/b22_decode_matrix_machineB_2026-10.md`、
  `scripts/bench_*_B*_20261024_run*.json`（B0 四轮 + B2.2 矩阵原始结果）。

### 2.4 资源/取消/关闭契约

- `src/shared/media/windows_hw/cuda_resident.py`：slot 池按 (w,h,fmt)
  复用、纹理注册一次、每平面 map→DtoA→unmap；拷贝后显式 cuCtxSynchronize
  （L3 实测 D2A 对主机异步，防左缘坏纹素）；slot 租约 GpuFrameRelease
  exactly-once；CudaResidentFrame.release 幂等；worker 不触 CUDA API；
  渲染线程亲和（跨线程 bind 拒绝）；关停 destroy() 注销资源+释放纹理。
- 运行中降级门闩：连续 3 次导入失败全局 tripped → 新源停驻留路由
  （resident_route_available），进程内不自动解除，诊断 reset 接口；
  既有源走 track_skip→render_error→worker 回退链，不交付半帧。
- 路由门禁：`TOPOS_WIN_HW_RESIDENT_DECODE` opt-in（默认关）+ win32 +
  codec 门 + 能力探测每次实测不缓存；失败/不支持 fail-closed 回落
  3.5 下载 planar，不冒充驻留。
