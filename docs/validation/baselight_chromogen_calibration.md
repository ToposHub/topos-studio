# Chromogen 对照验证

使用 Baselight M 7.0.3.26500 的独立对照工程，核对原生 Chromogen 阶段清单、参数命名、默认值和执行顺序。Topos 使用现有 Color 停靠标签、参数滑条、撤销事务和节点遮罩。每个 Corrector 可以保存最多 24 个有序阶段。预设可以替换或追加，用户预设以 JSON 保存，监看 LUT 可以单独导出为 `.cube`。

| 阶段类别 | 已接入阶段 |
| --- | --- |
| 基础 | 色彩饱和度、色彩串扰、高光漂白、对比度增强 |
| 进阶 | 色彩亮度抑制、中性染色 |
| 色相分区 | 扇区亮度、饱和度、偏移、压缩 |

适用阶段提供影调区间、支点、过渡和色度调制。点云支持径向、Eab 立方体、RGB 立方体及 Eab、LMS、Rec.709、Rec.2020 采样。查看器吸管采样当前节点内 Chromogen 收到的像素。阶段色相吸管把样本送过所选阶段之前的启用阶段，方便在累计的风格上继续建立色彩扇区。

## 同参数交付对照

复用 [X Grade 对照测试卡](baselight_x_grade_calibration.md)。输入为 Full 范围 Rec.709 Gamma 2.4。两套软件以同一工作域和输出域渲染 TIFF16，Topos 使用正式时间线导出。20 组调整覆盖全部十个阶段、不同分区色相以及饱和度、漂白、对比串联。以下为直接相减后的 RGB RMSE，按 10-bit 码值换算。中性对照一并报告。

| 样本 | 数量 | 中性对照 | 20 组调整合并 |
| --- | ---: | ---: | ---: |
| RGB 色块 | 35,937 | 3.48 | 6.08 |
| 独立 RGB 色块 | 4,096 | 1.86 | 5.81 |
| 灰阶 | 1,024 | 0.85 | 2.45 |
| 真实画面抽样 | 24 帧，80,640 像素 | 0.84 | 2.26 |

真实素材单组误差为 0.77 至 6.04 码值。强对比和中性染色的实拍 RMSE 分别为 6.04 和 5.56，中性染色在 RGB 色卡为 18.31。扇区亮度、偏移和压缩各组在实拍样本约为 0.77 至 1.00。递进操作共用 Eab 域计算和浮点工作流。HDR 原生外观及物理鼠标位移还需要独立校准。Topos 的线性 Rec.709、Gamma 2.4 和 ACEScct 路径用 CPU、OpenGL 和 Metal 测试验证内部一致性。

## 预设和 LUT

面板提供 Topos 自建起始风格与 JSON 预设交换。FilmLight 的 Truelight 胶片库属于 Baselight 的另一个预设来源。面板导出的 65 点 LUT 只烘焙已提交的 Chromogen 风格，按项目工作信号采样，采用普通 `.cube` 有限输入域。节点内部保留浮点变换及可编辑阶段。
