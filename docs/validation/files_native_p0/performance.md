# §9.3 规模基准（本机实测）

命令：`PYTHONPATH=. .venv/bin/python docs/validation/files_native_p0/bench_ui.py`（题目为合成条目，不含真实缩略图/磁盘 IO）。

| 条目数 | 冷首屏 ms | 热首屏 ms | 排序 ms | 搜索过滤 ms | 首帧绘制 ms | 进程峰值 RSS MB |
|---|---|---|---|---|---|---|
| 100 | 16.3 | 3.0 | 1.9 | 2.7 | 17.0 | 209.6 |
| 1000 | 12.2 | 3.7 | 4.3 | 3.0 | 13.6 | 209.6 |
| 10000 | 8.5 | 16.6 | 11.8 | 11.2 | 40.8 | 209.6 |

- 冷首屏=新面板第一次 `set_entries`；热首屏=同一面板清空后再灌入。
- 10,000 条仍在 20 ms 级填充/50 ms 内首帧；RSS 为整进程峰值，不含缩略图缓存。
- 缩略图仍按可见区请求，模型层不预解码；大数据下筛选/排序不复制后端规则。
- 结论仅限本机（macOS / Python 3.13 / PyQt6 6.11）；未把少量样例外推为通用性能承诺。
