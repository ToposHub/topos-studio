# Topos vs DNxHR 编码/解码速度 + 码率 + 画质（2026-09-11）

用户问题："DNxHR 不同规格的编解码速度，Topos 编码领先多少"。
DNxHR 梯子（Avid）：LB/SQ/HQ（8-bit 4:2:2——ffmpeg 编码器规格仅收
yuv422p，10-bit 源经 format 转换，2-bit 精度损失计入其画质）、
HQX（10-bit 4:2:2）、444（10-bit 4:4:4）。DNxHR 为**固定码率**
（档位 × 分辨率查表，无码控）。

- 60 帧真实素材（与 C043 矩阵同 fixtures）；DNxHR = ffmpeg 子进程
  墙钟（编码/解码各 2 次取优）；Topos 速度 = C043 矩阵纯净进程口径
  （编码纯调用计时 / 解码满配 16t p50 五轮）——本批 harness 进程内
  计时受 DNxHR 大块 IO 污染（proxy 170 vs 纯净 299，已弃用其计时，
  PSNR 不受影响）；
- 画质列 = 各自码率下对同源的合成 PSNR（422 权重 0.5/0.25/0.25），
  **跨行不可比、同分辨率行内可比**；Topos 档位码率 = C043（ProRes
  同档画质锚定），与 DNxHR 固定码率不是同一锚——比较时码率比列必读；
- 证据：`tools/dnxhr_{2k,4k}_{422,444*}_2026-09-11.json`（Topos 速度
  引 `tierspeed/tierdec_*_c043_2026-09-11.json`）。

## 读法

1. **编码领先 2.1~4.1×**（全规格、2K/4K 一致）——注意两编码器码率
   不同：Topos 跑 C043 档位码率（DNxHR 的 0.40~0.77×）。DNxHR 编码
   器简单（固定码率、无搜索）但逐样本工作量重（高固定码率 → 量化
   细、非零系数多）；
2. **解码 DNxHR 更快**（Topos 0.32~0.61×）：ffmpeg 的 DNxHR 解码器
   高度 SIMD 化（VLC 查表直进），且 8/10-bit 输出写回更窄。Topos
   解码短板与 ADR-C041 结论一致（符号环达平台 + 逐块 IDCT 固定
   成本；杠杆 = SIMD IDCT / metal 后端）；
3. **画质必须连同码率读**：Topos 档位码率系 ProRes 同档画质锚定，
   不是 DNxHR 锚。4K 上 Topos 各档在 0.4~0.7× 码率下同画质或大幅
   领先（proxy +0.3dB@0.40×、lt +4.6dB@0.41×、standard +6.9dB@0.43×、
   hq −0.5dB@0.73×——HQX 是 DNxHR 最强一格）；2K（噪声重的母带）
   Topos 各档在 0.40~0.72× 码率下低 2.8~4.6dB，属码率差而非编码器
   差——同码率口径下 Topos 对 ProRes 家族 +0.6~+7.3 dB 的结论不变
   （DNxHR 与 ProRes 同代同族 mezzanine，量化器结构相近）；
4. DNxHR 无码控（固定码率查表），Topos 带逐帧 sized 码控——速度
   对比已含 Topos 的码控成本。
