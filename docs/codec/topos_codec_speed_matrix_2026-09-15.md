## 口径和结论

- 真实 MOV native 解码包含包读取和解析；纯 codec 解码把包预先放在内存中，因此纯 codec 数值通常更高。
- 2K 422 从 Proxy 到 HQ 的 native MOV 解码为 730.8 → 300.1 FPS；2K 4444/4444XQ 为 183.2/148.5 FPS。
- 4K 422 从 Proxy 到 HQ 为 210.0 → 84.0 FPS；4K 4444/4444XQ 为 51.4/46.9 FPS，均高于 25 FPS 实时播放。
- 纯编码在 4K 4444XQ 为 32.1 FPS（约 1.29×实时），这组是当前最接近实时的编码压力点；后续 GPU/Metal 优化应优先围绕 4K 4444 家族和导出封装链路。
