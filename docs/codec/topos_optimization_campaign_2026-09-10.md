## 第 5 步详情：AQ/RDO 判定与 AQ v1.5 域缺陷

同码率对照（flat+V2，真实素材 3 帧，产品 tier 目标）：

| 配置 | 2K proxy | 2K hq | 4K proxy | 4K hq |
|---|---:|---:|---:|---:|
| AQ on vs off | **−33 dB（崩坏）** | −0.12 | **−33 dB（崩坏）** | −0.12 |
| RDO on vs off | −0.68 | +0.04 | **−2.43** | +0.58 |

- **AQ 在 qp≥64 域不可用（真缺陷）**：编码端 5 档量化变体表硬钳位
  `qev>63→63`（v1.5 漏改点 ×2），qp_base=79 时编码按 qp63 量化、码流
  声明 qp77~81 → 编解码量化失配（proxy@qp79 色度 10 dB）。**已修**：
  两处改为 `tc_qp_eff_ceiling(qp_base)` 条件天花板（与偏移应用点同源；
  qp≤63 行为逐位不变，debug/ASan 74/74 全绿）。**修后仍不可用**：
  码率模型在 qp≥64 深层失配（欠目标 38%、Y −16 dB）——**已由
  ADR-C039（2026-09-11）收口**：根因是 m7_probe 两处同族漏改点
  （变体钳位源误用搜索起点值），非模型抽象问题；修复后 qp≥64 域
  AQ 可用，默认仍关。
- **RDO 低码率负收益**：proxy 档 −0.7~−2.4 dB，hq 档分化（4K +0.58）。
  默认关维持；若未来启用应按 qp 域门控（如 qp≥64 禁用）。
- **上下文自适应熵编码**（真正的第 5 步主项）：需码流语法扩展
  （上下文模型 + 截断算术/多表 VLC），是独立立项的格式工程。当前
  质量态势（2K 平价、4K −1~3 dB）下预期收益 0.5~1.5 dB，属下一步
  质量战役的主攻方向。

## 战役后产品终态（vs ProRes，同码率档位语义）

- **码率**：同名档位均值 1.00×（P5）。**2026-09-11 修订（ADR-C043）**：
  同码率画质领先（+0.6~+7.3 dB，14 格全正）兑现为码率——六档重定标
  为 ProRes 同档画质锚定（保守 = 最差格等画质比 ×1.05）：proxy
  0.291 / lt 0.941 / standard 1.503 / hq 2.550 / pro444 4.263 /
  extreme 6.288 bpp（文件 −4~24%）；编码 +4~29%，解码实测与码率
  无关（固定成本主导），4K 444 实时回放问题不因此解决；
- **质量**：2K 四档 +0.2~+1.5 dB（追平/反超），4K −0.9~−2.7 dB
  （flat+V2 终版口径，报告 §五）。**2026-09-11 修订**：当前默认口径
  （flat+rans2）码率对齐复测——4K 差距反转（+0.6~+1.5 dB）；原 2K
  口径 +2.0~+2.9 系 h264 解码源（gap 批时 2K ProRes 素材未到，源
  标注勘误见差距分解报告），ProRes HQ 源复测 v2 = +0.9~+4.7 dB。
  原差距来源 = 档位固定 bpp 落点 0.75~0.94×（高纹理素材 ProRes 内容
  自适应多花码率）+ V2→rans2 两代熵演进。"4K 结构性差距"不再成立，
  质量轴无单点大额可动项；**同批补齐等画质码率维**：同画质 Topos
  省 9~25%（422）/ 25~39%（444），全表见
  docs/codec/topos_vs_prores_quality_bitrate_2026-09-11.md。
  **2026-09-11 二次修订（444 家族，ADR-C042）**：pro444/extreme 切
  flat+色度偏移归零并按 prores_ks 4444/XQ 实测重定标（5.585/7.974
  bpp）后，444 家族对齐口径反超（产品 dc0 配置 +5.0~+7.3 dB，
  2K/4K × 10/12bit 六点；同画质省 25~39%），无"高纹理落点亏"问题；
- **编码**：1.5~2.9× 领先（带码率闭环）。**2026-09-11 修订**：
  rans2+flat+444 重定标（ADR-C042）后全档复测——vs prores_ks 同源
  同档 2.7~8.0× 领先；产品路径绝对速度：2K 141~284 fps（5.6~11.4×
  实时@25p）、4K 422 家族 37.6~69.0 fps（1.5~2.8×）、4K 444 家族
  18.5~20.5 fps（0.74~0.82× 实时，唯一低于 25p 的格族）；
  码控贴目标 0.97~1.04×，见
  docs/codec/topos_tier_speed_matrix_2026-09-11.md；
- **解码**：全部产品配置 ≥2× 实时（8K HQ V2 50 fps、4K 77~278、
  2K 229~682）；16t 带宽天花板 7.3×（剖析报告）。**2026-09-11 修订**
  （真实素材 + rans2 + C042 定标 + 444 首次入表）：满配 16t p50——
  2K 六档 81~202 fps（3.2~8.1× 实时）、4K 422 38~51 fps（1.5~2.0×）、
  **4K 444 21~22 fps（0.8~0.9×，低于 25p 回放）**；旧"全部 ≥2×"口径
  在新矩阵不成立（合成素材 + V2 + P4 定标 + 无 444 档的测量）。
  vs ffmpeg prores 解码 0.5~1.0×（速度赢面在编码侧）；杠杆 =
  SIMD IDCT（~15%，位精确风险）与 metal 后端（并行轨道），见
  docs/codec/topos_tier_decode_matrix_2026-09-11.md；

## 遗留清单（按优先级）

1. **V7-R2 order-1 上下文扩展（ADR-C036）已交付**：entropy_mode=7
   （'rans2' 显式可选，默认仍 rans）——lvl|位置/前 lvl 桶 + dc|前块桶
   per-slice 信令，真实素材 qp20-84 较 V7-R 再省 1.2~2.8% payload、
   解码 ~1×、差分逐位一致；天花板测量经两次勘误（L 符号轴粗类化 /
   D1 非因果自条件）后为 +1.2~2.7%，实现拿满（方法论教训见
   topos_ctx_ceiling_2026-09-10.md §6）；
2. **AQ 码率模型 qp≥64 失配已收口（ADR-C039，2026-09-11）**：根因不是
   模型抽象——m7_probe 的 AQ 变体天花板以 fh.qp_base（搜索期间=起点值
   20）为源，qp≥64 候选的偏移带全部回落 63 量化 → 探针高估 bytes、
   搜索冲顶（复现：AQ-on 2K 落 q83/q95、实包 0.50/0.66×T）、最终编码
   正确 → 欠目标。两处钳位源改候选 qp（qp≤63 逐位不变）；回归钉
   判别性验证 + debug/ASan 79/79 + 2K/4K 真实素材修复后贴目标。qp≥64
   域 AQ"不可用"改判"可用"，默认仍关（收益天花板 2.5% 不变）；
3. 上下文自适应熵编码**已交付并过验收门**（ADR-C034：V7-R 位流集成，
   1440p 真实素材体积 qp24 −8.68% / qp48 −9.05%，解码 1.14×/1.19×
   反超 V2；debug+ASan 76/76；A/B 报告 topos_rans_ab_2026-09-10.md）；
   产品默认已切换（ADR-C035：同码率档位落点 qp 低 0~4 档 = 画质严格
   更优；P5 tier 目标 ProRes 锚定与熵无关，sized 自适应）；
4. **444 家族 flat 矩阵验证 + pro444/extreme 码率对齐已完结（ADR-C042，
   2026-09-11）**：用户补齐真实 4:4:4 素材（Apple ProRes 4444/4444XQ
   全片 + Avid DNxHR 444 10/12bit，2K/4K 同母带；DNxHR 解码 chroma
   实测全分辨率细节 U/Y≈0.89，作共享源——XQ 解码 chroma 已被其编码链
   抹平，U/Y 仅 0.16~0.29，作源会把 444 轴难度测虚）。flat 对 Standard
   六个对齐码率点全胜（合成 +0.30~+3.25 dB，Standard 无一胜点），
   色度偏移 +4 归零（dc0 六点全胜 +0.03~+1.75 dB，444 语义=chroma
   保真，与 422 家族 tier 全 0 惯例一致），bpp 重定标 pro444
   4.11→5.585 / extreme 6.76→7.974（prores_ks 4444/XQ 实测锚定，
   ADR-C032 同口径；Apple 自家实占 5.22/7.80 交叉验证）；对齐口径
   444 家族反超 prores_ks +3.4~+6.5 dB——无 422 家族的"高纹理落点
   亏"问题。GBR+444Compact 路径未测（无 GBR 素材，帧头规则限定
   qm2 于 GBR+12bit，产品 tier 未引用），不阻塞本项；
5. 解码扫描循环微优化**已完结（负结果，2026-09-11）**：当前默认
   （rans2）重剖析后两个最优候选——重整化批量化（clz+bswap，等价性
   逐位证明）与融合 u32-LUT（微基准 +23%）——系统级交替 A/B 分别为
   0% 与 −1~−6%（LUT 足迹/重建成本反噬），全部回退零代码入库；
   ~10% 上限估计系采样归因高估。NT-store 延期（本机噪声 floor 高于
   预期收益、需存储路径重构、无产品痛点）。详见
   docs/codec/topos_decode_scan_opt_2026-09-11.md；
6. **解码符号环结构性候选收口（ADR-C041，2026-09-11，负结果）**：
   交错多状态 NO-GO（原型判定性测量：寄存器同驻 4-lane 比单状态慢
   24%；上下文保序设计体积差 ≤0.02% 但无速度收益）；寄存器驻留补丁
   系统级反转（16t −2~5%——编译器 SROA 早已完成，原型基线动态索引
   失真，第三次微基准→系统反转教训入档）。解码符号环在本微架构达
   实用平台，速度轴结构性候选全部关闭；
6. **RDO 按 qp 域门控评估已完结（ADR-C040，2026-09-11，判定否）**：
   收益带实测 = [无损平台悬崖边, qp61]（2K/4K 一致，悬崖边峰值
   +1.4~3.7 dB；方向与战役猜想相反——低 qp 平台域无意义，非
   'qp≥64 禁用'而是'仅 ~52-61 启用'）；产品语境六格 tier 全负
   （−0.5~−4.7 dB：RDO 须 V2，其 ~9% payload 劣势压倒窄带收益，
   ADR-C038 rans2 默认后已无产品路径）；编码开销 +35~74%。默认关
   维持、不实施 native 门；产品化前置 = rans 熵率模型扩展（另立项）；
7. **'rans2' 已转产品默认（ADR-C038，2026-09-11）**：tier 级复验
   hq 同目标字节 +1.05 dB（落点 qp 63→62）、固定 qp 路径 −0.95~−2.16%；
   同批否决死区加宽（P3 前扫频已证 1/4 最优 + spec §7.4 冻结成本倒挂）、
   移除 TC_DZ_DEV 旋钮、勘误 C037 的 tier 域表述（sized 落点 qp54-84
   属有损域）；
8. **16×16 变换试点已完结（ADR-C037，NO-GO）**：精确正交整数混合
   构造（Haar2⊗M8，偶行=DCT-16 真偶行）+ 三方 RD 测量（8×8/混合/
   浮点 DCT-16 参照）。真实调色素材主域（无损平台，flat qp≤44/
   std qp≤32 实测逐位无损）16×16 净损失 9~13%（lvl 族颗粒表示代价
   +10.9% 反超 DC −72%/run −61% 的结构性节省）；有损域混合亦落后
   4~40%；文献 3-6% 收益只在平滑合成低码率域出现（混合 −10~18%）。
   副产物：无损平台发现（flat qp≤44/std qp≤32 逐位无损；crf/低 qp
   路径的优化目标是系数表示熵——sized 档位路径 qp54-84 仍属 RD 域，
   见 ADR-C037 勘误）；
9. **速度轴总计划立项（2026-09-11）**：解码 0.32~0.61× DNxHR +
   4K 444 编/解码 0.9× 实时为仅存短板。旧口径"SIMD IDCT ~15%"勘误
   ——AVX2 融合内核早已存在（ADR-C009 时代交付），真实空间 = rans2
   解码路径缺 V1/V2 独享的融合结构（逐块 sink/memset/单块 IDCT）+
   per-slice LUT 全量重建装配成本 + 编码环逐符号除法，另有编码侧
   首次剖析与 4K 444 16t 扩展性（3.8× vs 8K 7.3×）调查。全部位
   精确、不动位流；符号环结构候选维持 ADR-C041 关闭判定。路线图
   P0 剖析地基 → P1 位精确重构 → P2 4K 444 实时化，见
   docs/codec/topos_speed_optimization_plan_2026-09-11.md。
