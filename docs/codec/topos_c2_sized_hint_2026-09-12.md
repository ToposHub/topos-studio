# C2 落档：sized 搜索 hint 模型强化（2026-09-12）

速度计划 v2 C 轴 C2 项。**结论：已落地并过全部门；qp 轨迹与包字节
差分钉死（码控决策不变），双工作点弦线模型把"换目标后再换回"类
GOP 头搜索从 14 探降到 3 探（与稳态同阶）；单点历史/冷启动场景不
劣化（持平）。**

## 改动（native/topos_codec/src/codec/codec.c + codec.h）

1. `enc_shared` 提示升级为双工作点记忆：`qp_hint/qp_hint_bytes` +
   `qp_hint_prev/qp_hint_prev_bytes`（最近两个相异 (q*, bytes(q*))，
   同 q* 重复只刷新 bytes——稳态零额外状态迁移）；
2. strict 搜索种子（C2 模型开）：两工作点的 log-linear 弦与目标字节
   求交直接得新工作点估计（目标不变时外推项为 0，退化为 M10-6.3A
   裸 hint——稳态行为逐值一致）；单点历史用保守斜率 8 外推；
3. 首跳先验：有弦历史时以弦斜率（clamp 1..16）替代固定 4.0；
4. 搜索成功后从本帧 pts 回填工作点（bytes(q*) 取自实测探针）；
5. dev 开关 `tc_dev_set_qp_hint_model(disable)`（默认启用；关闭回退
   M10-6.3A 语义），与既有 `tc_dev_set_qp_hint` 两级正交。

**正确性论证**：strict 的括号不变量（hi=最大超限、lo=最小命中，
解 q* = lo 或 qp_max best-effort）与探针路径无关——种子/先验只改
路径不改解；预算耗尽/单调破坏均回退 legacy 线性（同解）。
`test_c2_sized_hint` 差分：跨目标/几何 8 步序列，模型开 vs 关的
(qp_used, packet_size, 包字节) 逐值一致。

## 探针计数实测（192×128 合成，V7-R2 strict；iters = 探针 + final）

| 场景 | 模型关 | 模型开 |
|---|---|---|
| 冷启动（qp_base 偏远） | 17 | 16 |
| 稳态（同目标重复） | 3 | 3 |
| 换目标①（单点历史） | 7 | 6 |
| 换回旧目标（弦线） | **14** | **3** |
| 再换新目标（弦线） | 6 | 5 |

4K 444 10bit pro444 口径（合成内容）：冷启动 8 探（321~331ms）、
换目标单点历史 5 探（72~84ms）——与基线持平；弦线场景按上表比例
收敛。**诚实边界**：计划预期"首帧 92→<60ms"的冷启动路径未被本项
改善（无历史可用；曾试无历史先验 4.0→10.0，4K 实测 8→10 探——
过冲括号更宽、插值步更多，已回退并记录）；本项收益集中在**码率
轨迹变化后的搜索**（反馈收敛/用户调码率/多档批转码），弦线使第
二次起的目标变化搜索与稳态同阶。

## 验收（全过）

- debug ctest 81/81（含 golden、test_r6 sized 模式差分、test_oom）；
- asan 定向 10/10（c2/c1/r6/oom/m10/codec）；
- `test_c2_sized_hint`：①差分（qp/size/bytes 逐值一致）②稳态
  iters==3 ③换目标① < 冷启动一半 ④弦线换回 ≤4、再换 ≤5
  ⑤两级开关正交（hint 全禁时模型开关不改输出）。

## 防重开

- 无历史冷启动先验调优（4.0→10.0）：负结果，4K 过冲劣化（见上）；
- 单点历史外推斜率 8：保守值，加大在 4K 单点场景无差异（5 探持平），
  弦线可用后即被替代。
