# RD3-03 1/3 快速路径报告

日期：2026-09-08  
路径：`21×15 → 7×5`，即精确 1/3；源宽高均为奇数，覆盖 8×8 右/下边缘。  
构建：`native/topos_codec/build/perf`，Release，Apple clang 17，x86_64。

## 结果

同一批 6 个源块、每次 1,000,000 轮，先预热 1,000 轮，连续运行 5 次取中位数：

| 路径 | 中位耗时 | 对比 |
| --- | ---: | ---: |
| 通用 sampled（逐样本比例除法 + 散点写回） | 210.338 ms | 基线 |
| RD3-03 固定相位（phase table + 连续行写回） | 127.480 ms | 1.650×，耗时下降 39.39% |

两条路径 checksum 均为 `13993952873578725565`，输出逐位一致。

## 实现范围

- 以源块起点 `% 3` 选择固定局部坐标：`{0,3,6}`、`{2,5}`、`{1,4,7}`；
- 右/下边缘按实际可见 extent 截断，不读取 coded padding；
- sampled IDCT、稀疏块、4 块批提交和 V3 intra 直写共用 1/3 快路；
- 非精确 1/3 几何继续走原有通用映射，旧流兼容语义不变。

可重复命令：

```text
cmake -S native/topos_codec -B native/topos_codec/build/perf \
  -DCMAKE_BUILD_TYPE=Release -DTOPOS_ENABLE_TESTS=ON
cmake --build native/topos_codec/build/perf \
  --target topos_third_path_bench --parallel 4
native/topos_codec/build/perf/topos_third_path_bench 1000000
```

该报告只衡量采样坐标和写回热段，不等同于完整 6K→2K 解码帧率；完整帧收益还取决于熵读取、IDCT、线程调度和 I/O。
