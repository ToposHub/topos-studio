# Topos 产品档位编码速度 + 码率矩阵（2026-09-11）

C032~C042 全部落地后的产品终态测量：六档（proxy/lt/standard/hq/
pro444/extreme）× 2K/4K，产品码控路径（首帧 `tc_frame_encode_sized` +
`ToposRateFeedback` 反馈单遍、rans2 熵、flat 矩阵、444 档含 ADR-C042
重定标与色度偏移归零）。

- 机器：i9-9900K（8C16T），macOS；
- 源：真实素材解码 raw（422 家族 = ProRes 422 HQ 解码 yuv422p10le；
  444 家族 = Avid DNxHR 444 解码 yuv444p10le / yuv444p12le）；
  每格 60 帧（2.4s @25p），首帧 sized 搜索摊入计时（产品路径语义）；
- 计时：perf_counter 只累计 encode 调用（源读取/tobytes/解码回读全部
  剥离；native 内部按 `tc_dev_thread_count()` 切片并行）；每档先做
  一帧不计时预热；
- 参照：ffmpeg prores_ks 同档 profile 同源墙钟（默认线程，含 rawvideo
  I/O）——速度比供量级参考（ffmpeg 侧 I/O 占比小但非零）；
- harness：`native/topos_codec/tools/bench_tier_speed.py`（可复现）；
  证据 JSON：`tools/tierspeed_*_2026-09-11.json`（六份）。

## 观察

1. **码控贴目标**：全部 14 格落地 0.97~1.04×（最差 4K lt 1.039× /
   2K lt 0.969×），qp 轨迹 62~86 域内健康，qp95 守卫全程未触发；
2. **速度全景**：2K 422 家族 141~284 fps（5.6~11.4× 实时）、4K 422
   37.6~69.0 fps（1.5~2.8× 实时）；444 家族样本量 1.5×（三全分辨率
   平面）→ 2K 60~67 fps（2.4~2.7×）、**4K 18.5~20.5 fps（0.74~0.82×
   实时——唯一低于 25p 实时的格族**，24p 工作流约 0.77~0.85×）；
3. **vs prores_ks**：2.7~8.0× 全档领先（同源同 profile 墙钟），旧
   战役口径"编码 1.5~2.9× 领先"大幅过时（V2 熵时代 + 旧矩阵测量），
   本次为 rans2+flat+新定标口径；
4. 码率量级与 ADR-C042 锚定互洽：pro444 2K 288~295 Mbps（Apple
   4444 自家 275.6）、extreme 4K 1661.5 Mbps（Apple XQ 1615.7）；
5. 444 速度为 422 的 ~0.54×（样本 1.5× + rans2 符号量随平面数上量），
   若 4K 444 实时编码成为产品痛点，优化轴在编码侧切片并行/熵统计
   路径（解码侧符号环已达平台，见 ADR-C041）。
