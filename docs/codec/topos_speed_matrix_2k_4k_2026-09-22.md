# Topos 编解码速度矩阵（2K / 4K × 全规格，2026-09-22 v2.1 滤波后刷新）

测速机器：MacPro7,1（Intel x86_64，16 核），macOS 24.3.0，Release native dylib
（`native/topos_codec/build/release`，含 P6 去块 v2.1：门控符号对称性 + 两趟并行 +
缩放交付目标网格滤波），编码/解码均 16 切片线程。**本机重复测量噪声 ±12%**
（同一二进制三轮回读摆动，见 `docs/topos_prores_quality_gain_2026-09-22.md` §5），
故表内差异 <12% 的档位之间不要下结论。

口径（`tools/bench_specs_speed.py`）：

- **编码** = 码流内核 + 产品码控（`ToposRateFeedback` 逐帧 RC，`slice_rows=16`），
  源 = 同分辨率 **ProRes 4444XQ** 裸帧（2K/4K 各 240 帧，25 fps 时间线）；
  产品输出特性位按 `ToposVideoEncoder._output_features` 同规则置位：
  4:2:2 10-bit 全档 **DEBLOCK**，4K `standard`/`hq` 另加 **QPT2**；4:4:4 系无特性位。
- **解码** = 常驻 decoder + 复用输出平面，包已在内存（纯 codec 口径，不含容器读取）。
- `prores_ks` = 同源同帧数的 ffmpeg 软件编码参考（对照"同代损失"的真实产品路径）。
- **×实时** = fps / 25。

## 4. 读数

1. **实时裕量**：时间线 25 fps 下，4K 全档解码 ≥ **1.90×**（最紧的是 4444xq），
   4K 422 档 ≥ 2.44×；编码最紧的是 4K 4444xq **1.40×**（1302.9 Mbps 归档码率），
   4K proxy/standard/hq 分别 6.25×/3.04×/2.61×。2K 侧全部 ≥ 3.62× 编码、≥ 5.72× 解码。
2. **解码的滤波净开销**（同一码流只切 bit2）：低档 **1.9–2.0×**（门控密、要改的
   边界多），高档降到 **1.19–1.38×**。4:4:4 两档没有该位 → 比值 0.96–1.02×，
   这是口径的负对照（证明差异确实来自滤波，不是测量漂移）。
3. **vs ProRes（同源软件编码）**：编码快 **3.16–16.81×**；4K 4444xq 也有 3.88×。
4. **2K→4K 代价**：像素 4×，实测编码慢 2.6–3.0×、解码慢 3.4–3.9×（亚线性，
   与熵编码/变换的并行度有关）。
5. **线程扩展** 6.1–8.4×（16 线程）——滤波并入两趟并行后，解码已无整帧串行段
   （旧口径 2.45× 的串行滤波已消除，见画质文档 §5）。
6. **帧数口径敏感性**（实测对照 `spec_speed_matrix_4k60_coldstart.json`）：多数档位
   在 60 帧与 240 帧两口径下一致在 ±12% 噪声带内（同一档位重新测量本身就会摆动），
   但 **4K netproxy 的编码**在 60 帧口径下明显偏低（**132.3 → 237.6 fps**，RC 首帧
   探针与线程池预热在更短的样本里占比被放大）。跨表引用务必带帧数/线程数口径；
   本表统一 240 帧。解码侧两口径无系统性差异（见 §3 全片口径亦吻合）。

## 5. 与既有报告的关系（不可直接跨表比）

- `docs/codec/topos_codec_speed_matrix_2026-09-15.md`：当轮 2K proxy 码率 15.2 Mbps、
  且 **P6 去块尚未落地**（2026-09-21 才合入），故其解码/编码 fps 与本表不同口径。
- 本表与 `docs/topos_prores_quality_gain_2026-09-22.md` §5 的同源档位一致
  （2K proxy 296–338 → 本表 323.2；4K proxy 85–92 → 86.4），属同一构建的复现。
- 图片链路（`.toos`）速度不在此表：见 `docs/image/topos_image_*_speed_2k_4k_2026-09-07.*`
  与 `docs/image/toos_deblock_verify_2026-09-22.md`。

## 6. 复现

```bash
# 编解码矩阵（本表 §1/§2；--frames-4k 60 可复现 §4.6 的帧数口径对照）
.venv/bin/python tools/bench_specs_speed.py --sizes 2K 4K --frames-2k 240 --frames-4k 240

# 全片稳态纯解码（本表 §3）
.venv/bin/python tools/bench_topos_decode_threads.py \
  --files tests/test_videos/4K_topos_422_Proxy.mov tests/test_videos/4K_topos_422.mov \
          tests/test_videos/4K_topos_422_HQ.mov tests/test_videos/4K_topos_4444.mov \
  --threads 1 16 --reps 3
```

产物：`bench_out/reexport/spec_speed_matrix.json`（本表 §1/§2）、
`bench_out/reexport/spec_speed_matrix_4k60_coldstart.json`（帧数口径对照）、
`bench_out/reexport/decode_threads_{2k,4k}_steady.json`（本表 §3）。
