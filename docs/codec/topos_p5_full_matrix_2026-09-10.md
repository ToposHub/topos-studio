# Topos P5 档位全规格实测矩阵（分辨率 × 档位：码率 / 帧率 / qp / PSNR）

**日期：** 2026-09-10　**机器：** Intel i9-9900K（8C16T）　**定标：** P5
（ADR-C032，ProRes 实测体积对齐）　**码流：** v1.5（qp 域 0..95），
V1 Rice 熵，qm=1，逐帧 sized qp 搜索

**素材：** 真实拍摄 prores422HQ（10-bit 4:2:2，25fps）各取前 120 帧：
1080p = 2K 原生流；2160p = 4K 原生流；540p 由 2K、720p/1440p 由 4K 经
lanczos 缩放派生（`yuv422p10le` 全程无色彩空间转换）。

**口径：** 编码 = 整文件墙钟（含 raw 读盘），16 线程/1 线程
（`TOPOS_SLICE_THREADS`）；解码 = 3 次取中位 → /dev/null；码率 =
文件大小 ×8 ÷ 4.8s；PSNR = 对各自分辨率源 raw 三平面平均（ffmpeg）。
CLI 目标取整 Mbps（产品路径用精确字节目标，无此舍入）。

## 读法与要点

1. **码率贴目标**：全矩阵实测/目标 = 0.87~1.00（整数 Mbps 舍入 + sized
   搜索 qp 粒度 ~19%/档）。同档码率严格随面积线性 ×4/倍频（0.32/1.13/
   1.65/2.66 bpp × 像素 × 25fps）——产品档位语义即"固定 bpp，码率随
   分辨率走"。
2. **qp 落点证明 v1.5 域在干活**：proxy 档全分辨率 qp79~90、lt 62~70
   ——四分之一以上的档位×分辨率组合落在旧 qp63 地板之下（旧定标下这些
   目标不可达，只能超支）。
3. **解码帧率**（16t）：540p 代理档 1520 fps → 2160p HQ 101 fps；
   实时预览余量：25fps 素材最重格（2160p HQ）仍有 4× 实时，代理档
   12~60× 实时。16t/1t 加速比 2.1~6.5×（分辨率越高、码率越低，切片
   并行收益越大）。
4. **编码帧率**（16t）：540p 343~622 fps；1080p 132~194；2160p 37~44。
   单线程全程 9~750 fps（sized 搜索 = 帧内多 pass；产品稳态走单遍
   反馈码控会更快）。
5. **PSNR 跨分辨率不可直接横比**：各分辨率的"源"不同（540p/1080p 出自
   较干净的 2K 素材，720p/1440p/2160p 出自高纹理 4K 素材）——720p 全档
   偏低是素材噪声密度所致，非分辨率效应。同分辨率内档位单调性正常。
   同码率与 ProRes 的质量差见 `topos_prores_real_footage_2026-09-10.md`。

## 6K/8K 扩展（4K 真实素材 lanczos 上采样派生，同口径追加）

保留真实纹理统计，但比原生素材更平滑（上采样低通），PSNR 因此系统性

- **8K 解码实时性（勘误与补充测量）**：本表 8K 行为 V1 Rice 熵、
  2.1 Gbps 超重码流（qp56，产品 hq 目标的 3.8×），25.5 fps 是极端上界
  负载。**产品真实口径（V2 VLC + flat 矩阵、552 Mbps 目标）实测
  50.5 fps（16t）= 2× 实时**；切片布局实验（slice_rows 4/8/16/32 =
  51~408 切片）解码速度差 <2%——多线程天花板是内存带宽而非调度。
- 码率贴目标 0.93~0.99（整数 Mbps + qp 粒度）；qp 80~81/56~65 再证
  v1.5 域覆盖；同档码率严格 ×2.25（4K→6K）/×4（4K→8K）面积线性。

## 复现

```bash
# 派生源（示例 1440p；1080p/2160p 用原生 raw）
ffmpeg -f rawvideo -pixel_format yuv422p10le -video_size 3840x2160 -framerate 25 \
  -i src4k.raw -vf scale=2560:1440:flags=lanczos -pix_fmt yuv422p10le \
  -frames:v 120 -f rawvideo src1440.raw
# 编码（目标 Mbps = target_bpp×W×H×25/1e6 取整；16t/1t 各一遍）
TOPOS_SLICE_THREADS=16 topos_encoder_cli --width 2560 --height 1440 --fps 25 \
  --qm 1 --target-mb 245 --frames 120 --input src1440.raw --output out.mov
# 解码计时（×3 取中位）
TOPOS_SLICE_THREADS={1|16} topos_decoder_cli --input out.mov --output /dev/null
# PSNR：解码至 raw 后 ffmpeg -lavfi psnr 对同分辨率源
```
